# K-SYS-003：位置、Mask 与缓存：同一可见性关系的三种表示

缓存中的内容必须对应模型定义的逻辑位置；mask 决定读取集合，物理布局决定这些内容放在哪里。三者通过显式映射共同实现 attention，不能用张量长度、因果标志或槽号中的任意一个代替其余关系。

## 对象、坐标与共同函数

本章先限定为固定参数、推理态、无 attention dropout 的因果 self-attention。有效分数与 V 有限。普通全注意力允许 query 读取同一请求中截至自身的所有有效 key；模型原生窗口另加窗口下界。cross-attention、双向注意力、树形投机与递归状态需要各自的依赖关系，不能直接继承这个因果集合。

必须分别表达以下对象：

| 符号或状态 | 含义 |
|---|---|
| t、j | 从零开始的逻辑 token 序号，决定因果先后；padding 不必占用逻辑 token 序号 |
| π(t) | 模型位置编码使用的坐标；本章公式采用标量，模型也可能使用多轴坐标 |
| i、u | 当前 Q 的局部行号与 K 张量的局部列号；不天然等于 t、j |
| valid(u)、logical(u) | 列是否有效，以及有效列承载的逻辑位置；未填充容量不能被当作有效历史 |
| locate(l,j) | 第 l 层逻辑位置 j 到物理页、槽和表示元数据的映射 |
| c、A | 所有必要层已提交 KV 的连续终点，以及已确认输入终点，满足 0≤c≤A；已知 token 不等于已有 KV |
| binding、generation | 本次请求授权读取的内容身份，以及对象或尝试代次；合法共享前缀允许不同请求绑定同一不可变对象 |

输入为本层隐藏状态、Q/K/V 投影与 head 映射、位置规则、有效性和可见性规则，以及带身份、位置、表示和完成依赖的旧缓存。输出为各 query 的 attention、新位置的 KV 和相应提交状态。高层 KV 来源于该层输入；不能从原始 token 一次生成所有层 KV。

对 query head h，令 ρ(h) 为所读 KV head，q̄、k̄ 为位置变换前向量，q、k 为实际参加点积的向量。有效 query t 的合法集合为

Aₜ={j：j 属于本请求绑定的有效输入，0≤j≤t}。

普通窗口宽 W≥1，且 W 包含当前 token 时，再要求 j≥max(0,t−W+1)。窗口上下界使用逻辑序号；不能因为 π(t) 不连续或不单调，就改用位置编码坐标比较因果先后。sink/global 等附加规则应按集合并集去重。

对缩放 a、位置偏置 b，定义

zₜⱼₕ=a·qₜₕ·kⱼ,ρ(h)+bₜⱼₕ，

Oₜₕ=Σⱼ∈Aₜ exp(zₜⱼₕ−mₜₕ)Vⱼ,ρ(h) / Σⱼ∈Aₜ exp(zₜⱼₕ−mₜₕ)，

mₜₕ=maxⱼ∈Aₜ zₜⱼₕ。

默认缩放常取 1/√dₖ，但由模型合同固定。不可见位置不进入分子或分母。将分数乘零会让其指数变为 1，并非屏蔽。例如合法与非法位置的分数都为 0、V 分别为 0 和 2，正确输出为 0，乘零后的错误输出为 1。

普通因果 self-attention 的有效 query 应至少看见自身。若出现空集合，先检查缺失当前 KV、有效性或对齐错误。模型或接口确实允许空行时，应明确返回零、错误或其他值；不能计算空最大值，再让全为负无穷的 softmax 自行决定。补齐出来的无效 query 可以绕过归约并输出约定值，但不得推进请求状态。

## 从逻辑关系推导矩阵对齐

假设 Q 行 i 对应 t=q₀+i，K 列 u 对应 j=k₀+u，且两侧都是连续有效区间，则因果条件为

u≤i+q₀−k₀。

左上三角 u≤i 仅在 q₀=k₀ 时表达这个关系。若 Q 是 K 的连续尾部，两者结束于同一逻辑终点，Q 长 L、K 长 S，则 q₀−k₀=S−L，得到右下对齐 u≤i+S−L。右下对齐的合法性来自共同终点，不能仅由 L≠S 推断。

历史已有 5 个有效 token，本轮 Q 长 2，对应位置 5、6，最终有效 K 长 7。两行集合分别为 {0,…,5}、{0,…,6}。左上三角只提供 {0}、{0,1}，shape 完全正确却计算了另一个函数。

若 K 张量前面有 3 个无效 padding 列，有效逻辑位置 j 位于列 u=j+3，则两行的有效可见列分别为 3…8、3…9。即使右下对齐碰巧给出 u≤8、u≤9，也仍需排除列 0…2。π(5)、π(6) 不应仅因为多了 3 列 padding 就自动增加 3。

右 padding、静态预分配尾部、压紧 batch、任意页排列或稀疏保留通常破坏上述连续列假设。此时应先通过列描述符恢复请求归属、有效性和 logical(u)，再应用模型可见性。请求压紧只改变执行行号；共享前缀只改变对象归属与引用；二者都不能重新编号逻辑 token。

固定版本的 [SDPA 说明](../sources/S-SDPA.md) 对非方形因果模式采用左上对齐，布尔 true 表示参与；该版本不允许因果标志与显式 mask 同时设置。[FlashAttention 说明](../sources/S-FA-IMPL.md) 记录 2.1 将非方形因果对齐改为右下。接入时必须把期望集合与实际接口逐行对照。同名 causal 参数不构成函数等价证明。

## RoPE：位置进入数值内容的时刻

对一对通道 (x₀,x₁)，频率 θ 的旋转为

R(pθ)(x₀,x₁)=(x₀cos(pθ)−x₁sin(pθ)，x₀sin(pθ)+x₁cos(pθ))。

对偶数旋转维 dᵣ，将规定的通道对分别旋转，其余通道保持原值。相邻配对与半区配对是不同布局合同，必须与投影输出的排列一致。不能只改一个配对开关而假定同一权重仍实现原函数。

固定频率、配对与坐标规则时，令 qₜ=R(π(t))q̄ₜ、kⱼ=R(π(j))k̄ⱼ。正交关系给出

qₜᵀkⱼ=q̄ₜᵀR(π(j)−π(t))k̄ⱼ。

右侧还可按每对通道直接展开为

cos(δθ)(q̄₀k̄₀+q̄₁k̄₁)+sin(δθ)(q̄₁k̄₀−q̄₀k̄₁)，δ=π(j)−π(t)。

这提供了不复用实际旋转函数的检查参考，也明确了旋转符号。RoPE 给出相对位置内积关系，不保证任意 token 对的 attention 权重随距离单调下降，也不保证任意长上下文质量。

缓存可以保存两种不同对象：

- 已旋转 K：写入时计算 R(π(j))k̄ⱼ；消费时直接读取，不能再次旋转。新 query 仍需按自己的 π(t) 旋转。
- 未旋转 K：写入 k̄ⱼ并保存正确坐标；消费时在临时 tile 或其他受控路径中旋转，再参与点积。必须说明旋转在哪个粒度上复用，不能每次读取时原地旋转共享缓存。

两条路径在相同输入与实数运算中等价。有限精度下，旋转、存储舍入和归约顺序可能产生误差。两种表示不能仅凭 shape 相同直接互换。V 是否带位置变换也由模型规定；本章的普通 RoPE 算例仅旋转 Q/K。

若只改变物理页排列，逻辑位置和 K 数值应保持不变。若希望把坐标 p 改为 p′，且确知底层未旋转向量不变、变换可逆，则在实数中可使用 K′=R新(p′)R旧(p)ᵀK。这个局部恒等式不证明整个多层模型缓存可复用：修改位置规则可能已经改变前层 attention 和高层未旋转 K/V。量化也通常不可逆。没有完整依赖证明时，应重算受影响状态。

对于仅使用固定 RoPE、无其他绝对位置依赖的局部函数，同时给所有 Q/K 坐标增加同一常数会保持相对内积；这可作受限变形检查。只平移新 query、保留旧 K 的坐标，或把窗口槽号当坐标，都不满足该条件。不能把局部平移性质推广成任意模型的前缀搬移许可。

## 增量执行的完整数据流与提交

下面选择每请求最多一轮推进在途、旧已发布状态只读、新块使用独立 staging 的基线。它覆盖全注意力与普通窗口；共享对象采用私有尾区或写时复制。该选择便于说明正确性，具体引擎可以使用具有等价依赖保证的融合路径。

```pseudocode
ADVANCE(request, q)
输入：已确认 token[c:c+q]；逐层参数；位置/可见性/表示合同
      旧已发布视图、对象身份和代次；可用容量与完成依赖
输出：q 行模型结果、新提交终点 c+q，或不推进 c 的失败

核对请求仍有效、无其他推进在途、0≤c≤c+q≤A
若 q=0：返回空结果，不分配、不写入、不改变 c
核对位置范围、表示兼容性及本轮全部必需输入
计算各层各 query 的合法集合和旧历史读取并集
原子取得旧对象读取责任；核对身份、逻辑标签和表示
预留新 staging、目标写区、必要 COW 和 workspace
任一步失败：释放尚未产生物理使用的责任，返回失败

X ← token[c:c+q] 的模型输入表示
for l 从第一层到最后一层：
    按模型顺序，从 X 计算本层 Q、未旋转 K 和 V
    按 π(c+i) 旋转每行 Q
    若缓存合同为已旋转 K：旋转新增 K 一次
    在本层独立 staging 保存全部新增 K/V 及位置、表示元数据
    候选对象 ← 已取得读取权的旧对象 ∪ 本层新 staging
    对每个 query t=c+i：
        从候选中选择恰好属于 A_t 的对象；每个逻辑 key 只加入一次
        核对普通因果有效行包含自身且无缺失 key
        逐合法对象计算分数，求最大值 m
        再累计 exp(score-m) 的质量与对应 V 的加权和
        输出 ← 加权和/质量
    按模型顺序完成输出投影、残差、归一化和其他本层操作
    X ← 本层完整输出，作为下一层输入

等待所有输出与状态生产完成
构造下一轮需要保留的逐层状态与目标映射
复制共享尾页的旧有效槽及其元数据；写入新槽
窗口提交仅保留下一轮合同要求的历史；不修改仍有读者的旧代对象
等待目标写入完成并建立消费者所需可见性
在同一提交点重新核对请求代次，发布全部必要层视图与 c←c+q
释放本轮旧对象责任；物理最后使用完成后才允许回收
返回模型结果；末行结果的来源位置为 c-1

任一生产、复制或写入失败：
    禁止发布新终点和部分状态组合
    停止新的提交，等待已接受的物理读写排空
    归还本轮私有目标与 staging；保留仍有效的旧已提交视图
```

关键不变量是：处理每一层时，旧 KV 来自正确前缀，新 KV 来自当前层输入；每行的旧路径和 staging 路径互斥且并集恰好为 Aₜ；发布前的新长度不对后续消费者可见。一个 kernel 可以提前写某个私有目标，但下一轮不能据此读取尚未共同提交的多层状态。

全注意力保留 [0,c+q) 的 KV。普通窗口为下一步 query p=c+q 至少保留 [max(0,p−W+1),p) 的旧 KV；分配 W 个环形槽是常见存储选择，不能把所需 W−1 个旧位置和分配 W 个槽混成同一概念。

完整 prompt 前缀命中还可能没有末行 logits。若 A=c 且没有可用 logits，位置 c 的 token 尚不存在，不能安排一个零输入的 decode 来解决。普通 causal decoder 可受控重算最后一个已知位置 c−1：每层读取其合法历史，在暂存区计算当前行，并确保位置 c−1 只贡献一次；不追加 token、不推进 c、不改写共享页。缺少窗口历史、其他状态族或合法数值恢复路径时，应回退到受支持检查点。空 prompt 没有位置 −1，必须由输入合同提供 BOS 等合法起点或拒绝。

## 从逻辑 key 到物理地址

以 K、V 分开存储的分页 NHD 布局为例，页长 B 个 token，页表 table[l][b] 给出物理页号。逻辑位置 j 的逻辑页为 floor(j/B)，页内槽为 j mod B。K 地址为

baseK + (((table[l][floor(j/B)]·B+j mod B)·Hkv+h)·dₖ+x)·bK。

其中 x 是 K 通道号，bK 是每元素字节数。V 使用自己的 baseV、dᵥ 和 bV。head 优先、合并容器或量化布局需重新展开地址，不能沿用此式。物理页号不会进入 RoPE。

定位后还要验证该槽的逻辑标签、内容身份、代次和有效范围。页表回答地址，不证明地址中的字节已经完成、属于本次前缀或带有正确量化尺度。共享页可以有不同请求的读票据；同一时刻的写入必须具备独占责任，或采用明确的有序合并合同。

环形映射 j mod W 同样只回答地址。设 W=4，位置 0…4 已生成，则槽 0…3 分别存放 4、1、2、3。新 chunk 为位置 5、6、7：三行需要 {2,3,4,5}、{3,4,5,6}、{4,5,6,7}。若先把整个新块写入 ring，位置 6、7 会覆盖首行仍需的 2、3。

上述 staging 算法先保护旧位置 {2,3,4}，再与新位置 {5,6,7} 组成候选；各行按逻辑集合归约。全部读取完成后，ring 才可成为 {4,5,6,7}。若分数相等、V[j]=j，三行独立参考分别为 3.5、4.5、5.5。这个反例在单线程中也会发生，原因是块内覆盖顺序，不必先归因于设备竞态。

另一种合法方案是逐 token 完成读取后再覆盖，或者使用旧槽版本。它们改变串行依赖、临时容量和同步次数；仅把 q 限制为不大于 W 仍不能保证先批量覆盖是安全的。

## 组合轨迹：左 padding、共享非整页前缀与追加

设页长 B=4，两个请求 A、B 命中同一已发布前缀 [0,5)。物理页 P₀ 保存 0…3，P₁ 只有位置 4 有效，其他槽未初始化。这里允许冻结的非整页前缀共享，但禁止原地追加。

A 本轮输入位置 5、6，B 随后输入内容不同的位置 5。A 的读取快照包含 P₀、P₁；在独立 staging 中产生位置 5、6 的逐层 K/V，按位置 5、6 旋转一次。即使适配器生成带 3 个左 padding 的 K 视图，有效列仍只有位置 0…6，两行集合仍为 0…5、0…6。

A 预留私有页 P₂，复制 P₁ 的位置 4 及其位置、旋转状态和其他解释元数据，再写入新位置 5、6。发布后的 A 页表为 [P₀,P₂]，末页有效长度为 3。B 另建 P₃，复制位置 4 后写入自己的位置 5；其页表为 [P₀,P₃]，末页有效长度为 2。原 P₁ 的有效长度和字节均不改变。

必须等待复制和新增状态写入都完成，才能发布对应页表及终点。A 已完成业务取消但复制仍在读取 P₁ 时，P₁ 的物理读取责任仍在；P₂ 也不能在迟到写入结束前分配给其他请求。B 不应等待 A 的业务结果，但仍依赖自己的对象与生产完成。若任一层失败，A 不发布混合新旧层终点，B 与旧前缀继续有效。

若尾页包含跨 token 的量化组，复制范围可能大于一个有效 token。K 的编码、scale、偏移和组边界必须共同解释。新增值若改变组尺度，不能把旧编码直接配上新尺度；应在私有目标中恢复并重新编码受影响组，或保留高精度尾区。K、V 的分组边界可以不同，必须按逻辑位置对应 score 与 V，不能按两边残余区的相同数组下标盲目拼接。[KV 压缩](../algorithms/kv-compression.md) 展开量化算法；本章要求其恢复后仍满足位置与贡献唯一性。

这个轨迹保持的是规定的模型与数值合同。分组量化、尾部封组时机或 chunk 划分改变舍入后，不能继续要求与未量化参考无条件精确等价；应分别检查表示执行和质量误差。

## 条件化成本：对数、字节、准备与关键路径

令层数为 Nℓ，query heads 为 Hq，KV heads 为 Hkv，K/V 通道分别为 dₖ、dᵥ。在普通非量化、各层同几何的设定下，每个 token 的全层 KV 有效字节为

Ctok=Nℓ·Hkv·(dₖbK+dᵥbV)。

它只计 K/V 内容；位置标签、页表、代次、量化元数据与分配 padding 另计。GQA 减少唯一 KV 容量，但各 query head 仍有自己的点积和归约。

对已有 H 个有效历史、新增 q 行的全因果块，有效 query-key 对数为

E=qH+q(q+1)/2。

每层 QK 与 PV 主乘加约为 2Hq(dₖ+dᵥ)E FLOP，另计 softmax、投影和模型其他部分。普通窗口则 E=Σᵢ₌₀至q−1 min(W,H+i+1)。实现若仍计算完整矩形或覆盖相同 tile，实际运算可能多于这个逻辑数量；mask 元素数 qS 也不等于有效对数。

访存需要指定循环与复用假设。若一次块处理能够让全部 query/head 共享一次 KV 载入，全层内容扫描的理想量可近似为 (H+q)Ctok；若 query tile 大小为 Br 且每个 query tile 重新扫描历史，则请求字节近似增加到 ceil(q/Br)(H+q)Ctok，head 间未复用时还可能更多。它们是给定数据流的逻辑请求字节，不是 DRAM 事务实测。分页间接寻址、cache 命中、事务对齐、量化解码和 padding 会改变实际流量。

六类成本在同一个调用范围内分别列账：

- 计算：Q/K 的新行旋转约为 O(q(Hq+Hkv)dᵣ)；保存未旋转 K 时，还需按历史载入和复用粒度计旋转。频率或正余弦表构建不能隐去。
- 访存：新 KV 至少写 qCtok；COW 复制 k 个有效旧 token 的内容读写约为 2kCtok。若实际整页复制或量化组更大，按真实范围替换 k。完整 gather 还需旧布局读取、新布局写入及 attention 的后续读取。
- 通信：单设备、无卸载的本地追加没有 KV 跨设备传输；主机 metadata 仍可能复制。迁移 D 字节在带宽 β 链路上的数据时间下界为 D/β，另计转换、协议、可见性及必要 collective；独立链路的时间不能机械相加。
- 准备：构造逐行 mask 为 O(qS)，结构化上下界通常只需 O(q) 行参数，加上页索引与有效长度。身份核对、COW 计划、读票据及分派也有成本。只有依赖未变时才能复用计划。
- 同步：输入就绪、层间依赖、复制完成、发布和失败排空进入关键路径。主机读取设备长度可能引入等待；融合调用可减少提交，但不消除数据依赖。
- 驻留：唯一已发布页、私有尾页、staging、workspace、mask/位置表与在途保护页构成同时存活峰值。同一共享页计一次，预留额度不再与其中已物化页面重复相加。

以上组合例取 Nℓ=32、Hkv=8、dₖ=dᵥ=128、bK=bV=2 B，则 Ctok=128 KiB，4-token 页为 512 KiB。A 追加两行需要写入 256 KiB 有效新 KV；复制一个旧有效 token 另产生 256 KiB 内容读写，合计 512 KiB，尚不含 attention 读取、metadata 或 staging。P₂ 的额外分配为 512 KiB，不能只按其三个有效 token 估算。旧 P₁ 仍被前缀或在途读者持有时不能扣除；B 分叉还需自己的私有页。

同例 q=2、H=5，E=13；若 Hq=32，则每层 QK/PV 主乘加为 2·32·256·13=212,992 FLOP。这个量不包括投影，也不是时延预测。若 q=128、S=8192，单个无 head 复制的显式 mask 有 1,048,576 个元素，按每布尔 1 B 为 1 MiB，按 FP32 加性偏置为 4 MiB；广播能否保持视图而不物化要按实际路径核对。

串行路径可写 T=T准备+T复制/转换+T设备+T提交。存在重叠时，应沿生产者到消费者的依赖图取关键路径，并检查带宽等共享资源，不能把所有累计耗时相加，也不能只取最快 kernel 作为完整调用成本。

## 条件改变后保留什么

| 变化 | 可以保留的关系 | 需要调整或放弃的部分 |
|---|---|---|
| 只改变 padding、batch 顺序、物理页排列 | 输入与模型函数、逻辑位置、合法集合 | 重建执行行列和地址映射；检查 inactive 槽及归属 |
| 改变 chunk 划分 | 普通确定性因果模型的逻辑依赖 | staging、历史重读、准备次数及浮点归约；量化封组策略另作合同 |
| 窗口缩小 | 新窗口仍允许的状态内容 | 只在模型定义或质量合同允许时改变函数；等待读者结束再回收 |
| 窗口扩大 | 仍有合法副本的旧位置 | 已覆盖历史无法靠改长度恢复，应重算或取回副本 |
| RoPE 配对、频率、缩放或输入起点改变 | 仍完全不受影响的依赖 | 重新证明整个状态依赖；局部旋转公式不能代替多层证明 |
| raw K 与 rotated K 后端切换 | 已证明相同的未旋转内容与坐标 | 转换、舍入、表示标志和读写路径；量化往返通常不可逆 |
| 只改变布局或迁移设备 | 内容与位置语义 | 元数据、stride、head 排列、ready 依赖与峰值；含 scale 一起转换 |
| 模型、adapter、前缀或外部特征改变 | 无关请求的旧不可变对象 | 旧命中资格通常失效；同 token 数、同 shape 不足以复用 |
| 采用近似裁剪或重要 token 保留 | 被保留对象的身份与位置 | 原全 attention 函数已经改变，增加任务质量参考 |

短历史、小 q 时，显式小 mask 与简单路径可能比复杂计划便宜。长历史时，结构参数或融合 mask 更容易摊薄准备与驻留，但仅在能够准确表达全部可见性时使用。原生窗口降低有效对数并不保证执行 tile 和 DRAM 事务同比减少。未旋转 K 若被多步重复旋转可能不合算；旋转后缓存若带来迁移格式不兼容，也可能使整体成本反转。选择需要相同函数、输入、计时边界与容量约束。

## 竞争解释、负对照与检查边界

先检查具体可见关系，再比较输出。只检查可见对数、shape 或首 token 都可能漏错：两个集合可以大小相等但成员不同；首 token 可能尚未读取迁移或量化后的历史；纯 RoPE 的共同坐标平移还可能掩盖单一 padding 样例的问题。

| 观察 | 竞争解释 | 区分实验及反证后的修正 |
|---|---|---|
| 方形 prefill 正确，增量失败 | 非方形左上对齐；本块位置重置；旧 K 重复旋转 | 固定 H=5、q=2，先比较逐行逻辑集合，再比较原始与旋转后 K；集合错先修 mask，集合对再查位置数值 |
| padding 后结果变化 | 无效列进入分母；位置整体偏移；请求行路由错误 | 同一输入独立、左补齐、混批执行，改变 padding 内 V 为大有限 poison；另核对每个有效 token 的坐标和归属 |
| chunk 跨窗口时失败 | 提前覆盖；当前 key 重复；窗口端点错 | 执行 W=4、[5,8) 轨迹，记录每行位置标签与贡献次数；等分数参考为 3.5、4.5、5.5，分别注入覆盖和重复贡献 |
| 非整页命中后出错 | 尾页漏复制；有效长度扩到未填槽；共享页原地改写 | 新页以 poison 初始化，独立读取旧物理尾槽再复制；检查 A、B 和旧前缀的字节与后续输出，不能用全量重打包自动补好遗漏 |
| 迁移后标签正确但数值错 | raw/rotated 合同不匹配；尺度缺失；head/通道排列错误 | 固定逻辑输入，分别比较位置处理、解码后的 K/V 和逐行输出；若首次差异发生在解码前，修表示而不是放宽输出容差 |
| 只在取消或并发时错 | 早回收；迟到旧写；共享 workspace 覆盖 | 控制最后使用与完成顺序，复用槽后再放行旧事件；需要真实平台验证物理可见性，CPU 次序模型不足以证明设备协议 |
| kernel 更快但完整调用更慢 | mask/gather 准备；COW；同步；额外驻留降低并发 | 固定请求集分别计准备、转换、设备与提交，再放开容量准入；若优势仅来自更多并发，应归为容量收益 |

交付的 tools/check_k_sys_003_full.py 是确定性、离线、只读的 Python 标准库单层 CPU 模型。缓存路径实际维护分页槽或 ring、位置标签、raw/rotated K、无效列、共享非整页尾页的 COW 和物理重排；独立参考直接扫描逻辑序列，用上文相对旋转内积公式计算整行 softmax，不读取被测页表，也不调用被测旋转函数。

检查覆盖空新增、首行、非等长 Q/K、多种切分、非零与非单调位置坐标、左 padding、静态无效列、W=1、q>W、跨页、前缀分叉后继续和重排后继续。负对照实际改变左上对齐、mask 乘零、无效列参与、重复旋转、块内位置重置、槽号旋转、未来 key、重复自身以及提前 ring 覆盖，并要求独立参考或标签不变量拒绝。标签、坐标与身份破坏另有读取拒绝检查。

该模型不包含真实 Transformer 的投影学习、完整多层提交、采样恢复、量化误差、异步对象回收、GPU 原子与可见性或性能。普通高精度路径的分区等价，应在目标模型按约定容差继续验证；低位路径另需正确消费压缩历史的数值和质量实验。检查脚本、输入绑定与实际执行结果见[检查记录](../../docs/evidence/knowledge-workflow-20261028-batch8/K-SYS-003/round-2/check-0.json)。
