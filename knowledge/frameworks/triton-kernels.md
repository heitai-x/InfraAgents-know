# K-FW-007：Triton Kernel：块程序、布局与融合边界

Triton 用块级程序描述张量工作。一个 program instance 确定自己负责的输出 tile，再用地址映射、掩码、归约和片上重用完成这个 tile。性能来自逻辑工作、线程布局、片上驻留和完成依赖的共同选择；一个孤立的 tile 数字不能说明正确性或性能。

## 程序实例、执行域与状态

设 A 为 M×K、B 为 K×N，函数为 C=AB，或逐元素后处理后的 C[m,n]=E((AB)[m,n],m,n)。不读取旧 C；未启用后处理时 E(x,m,n)=x。M、N、K 为非负整数，BM、BN、BK 为正整数。M=0 或 N=0 时没有有效输出；K=0 时乘积为零，但启用的 bias 等后处理仍须应用一次。

program 坐标 p=(pm,pn) 对应输出起点 (m0,n0)=(pm·BM,pn·BN)。grid 为 ⌈M/BM⌉×⌈N/BN⌉，每个 program 独占其 tile 与矩阵有效域的交集。改变 BM、BN、BK 不改变函数，但改变块数、重复读取、尾部浪费和每块资源。

合法执行必须满足：

- 每个有效输出恰好有一个写者；每个输出的 K 归约分段互不重叠且覆盖完整归约域。
- 输入加载、预取和输出写回分别受到真实矩阵边界保护。只掩码最终 store 不能阻止先前的越界读取。
- 补充值必须满足所处运算的代数身份及数值契约。有限输入的 GEMM 可用零补归约尾部；max 和 softmax 不能照搬这一规则。
- 实际 stride、存储偏移、dtype、对齐和索引宽度被生成程序接受。shape 相同不证明两个 view 属于同一合法域。
- 输出存储不重叠；本章算法要求输出与仍会读取的输入不别名。需要原地更新时，应另证写入不会破坏后续输入。
- 寄存器、shared/LDS、线程及同步资源满足目标限制，数值路径符合调用者要求。编译通过不等于具有预期驻留或误差。

状态分三层。逻辑状态包括张量、shape、stride、可见性和位置；数学状态包括累加器以及 attention 的最大值 m、归一化质量 ℓ、未归一化加权和 U；执行状态包括输入槽、完成票据、读者和槽位代次。数学值已经定义，不表示异步生产已经结束；生产完成，也不表示最后消费者已经读完。

## 从地址与掩码恢复完整 GEMM

对普通 strided 张量 X，设存储基址为 base_X，每元素 b_X 字节，存储偏移 o_X 和各轴 stride s_j 均以元素计，则：

addr_X(i)=base_X+b_X·(o_X+Σ_j i_j·s_j)。

A 的两个轴为 m、k，B 为 k、n，C 为 m、n。只有实际 stride 与连续布局相符时才能化简地址。program 的调度次序可以改变 cache 复用，不改变输出元素的归约集合。

下面的 i、j、k 都是局部下标，分别属于 [0,BM)、[0,BN)、[0,BK)。输入有效性使用全局坐标判断；无效分支只产生片上零，不执行输入访问。epilogue 仅在最终有效写回表达式调用一次，其 bias 等额外输入也只在有效分支访问。

```pseudocode
输入：A[M,K]、B[K,N]、独立输出 C[M,N]
      各张量的基址、offset、stride、dtype
      BM>0、BN>0、BK>0，program 坐标 (pm,pn)
      已定义的逐元素 E(x,m,n)，未启用时 E(x,m,n)=x
输出：本 program 独占的有效 C 元素

m0=pm·BM；n0=pn·BN
若 m0>=M 或 n0>=N：返回
对 i∈[0,BM)、j∈[0,BN)：acc[i,j]=0
对 k0=0,BK,2BK,… 且 k0<K：
    对 i∈[0,BM)、k∈[0,BK)：
        若 m0+i<M 且 k0+k<K：
            按 A 的实际 stride 计算地址并加载 A_tile[i,k]=A[m0+i,k0+k]
        否则：A_tile[i,k]=0，不访问 A
    对 k∈[0,BK)、j∈[0,BN)：
        若 k0+k<K 且 n0+j<N：
            按 B 的实际 stride 计算地址并加载 B_tile[k,j]=B[k0+k,n0+j]
        否则：B_tile[k,j]=0，不访问 B
    等待本阶段输入完整就绪，并建立消费者所需可见性
    对 i∈[0,BM)、j∈[0,BN)、k∈[0,BK)：
        acc[i,j]+=A_tile[i,k]·B_tile[k,j]
    本阶段全部输入读者完成后，才允许覆盖其输入缓冲
等待所有 accumulator 更新完成
对 i∈[0,BM)、j∈[0,BN)：
    若 m0+i<M 且 n0+j<N：
        C[m0+i,n0+j]=按输出 dtype 转换(E(acc[i,j],m0+i,n0+j))
```

处理完前 t 个阶段后，有效 acc[i,j] 等于对应输出在 [0,min(t·BK,K)) 上的乘积和，这是循环不变量。输入尾部补零不改变该和；所有阶段完成后才能应用非线性后处理。若沿 K 拆成多个 program，必须先合并部分和，再应用一次 E；对每个部分和加 bias 会重复计入 bias。

设 M=N=5、K=3、BM=BN=4、BK=2，最后输出块的 m0=n0=4，只有局部 i=j=0 是有效输出。第二个 K 阶段只有局部 k=0 有效。A 的加载集合因此只有 A[4,2]，B 只有 B[2,4]；i=1 或 j=1 不得访问输入。错误条件 i<m0+BM、j<n0+BN 在这里会允许 A[5,2]、B[2,5]，即使最终 store 正确掩码也已经违反内存契约。

后处理还需要单独检查函数次数。例如 E(x,m,n)=x+bias[n] 且 bias[n] 非零，先修改 acc 再在 store 再次调用 E 会得到 AB+2·bias。恒等后处理或幂等激活不足以暴露这个错误。

## 逻辑 tile 怎样进入线程、片上布局和流水

逻辑 tile 不等于线程数。编译器可以为同一个 tile 选择不同 lane 片段、矩阵指令布局和临时寄存器。不能由 BM×BN 推出实际线程数，也不能猜测不透明 fragment 的内部 lane 排列。

用一个显式的标量映射说明整条路径，而不把它称为 Triton 固定生成方式。设 A/B/C 为行主序 FP32，CTA 有64线程，输出 tile 为16×32，BK=8。线程 τ=32w+λ，w∈{0,1}，λ∈[0,32)。每线程持有8个 accumulator，对 u∈[0,8)，令：

r=2u+⌊λ/16⌋，c=16w+(λ mod16)。

64×8=512个位置恰好覆盖16×32输出。两个 warp 分别独占16列，每个位置有唯一 accumulator 和写者，无须跨 warp 合并输出。

阶段 j 的 k0=8j。片上输入为行主序 As[16,8]、Bs[8,32]。全体线程协作搬运：As 的线性下标 a=τ+64v，v=0,1，对应 (⌊a/8⌋,a mod8)；Bs 的线性下标 h=τ+64v，v=0,1,2,3，对应 (⌊h/32⌋,h mod32)。每个片上位置也有唯一写者。全局 FP32 字节地址分别为：

- A：base_A+4·((m0+r)K+k0+k)，前提 m0+r<M 且 k0+k<K。
- B：base_B+4·((k0+k)N+n0+c)，前提 k0+k<K 且 n0+c<N。
- C：base_C+4·((m0+r)N+n0+c)，前提 m0+r<M 且 n0+c<N。

地址式在非连续 view 上须恢复为实际 stride 形式。无效输入槽写零，无效输出不写；拥有无效输出的线程仍参加规定的集体同步，不能提前退出破坏其他线程的完成条件。

每线程按 k=0…7 读取 As[r,k]、Bs[k,c]，更新其8个独占 accumulator。对固定 u、k，同一 warp 的两组16 lane 各广播一个 A 值；B 的16个不同字各被两个 lane 读取。在所引 CUDA 标量32-bit bank 模型下，这是相同地址广播，不能算作32个不同地址冲突。协作写片上存储时，单条标量指令的字下标 τ+64v 在同一 warp 内覆盖32个不同 bank。向量化、矩阵装载或改变片上行跨度后必须重新推导。

每阶段输入容量为4·(16·8+8·32)=1,536字节，双缓冲为3 KiB；逻辑 accumulator 共2 KiB，每线程8个FP32值。这些数字不含地址、mask、同步和编译器临时量，也不证明真实寄存器分配。

设输入槽深度为 d，每阶段身份为 (s,g,j)，其中 s=j mod d、g=⌊j/d⌋。一个完整交接顺序如下。

```pseudocode
J=ceil(K/8)
初始化所有 accumulator 和 d 个空闲输入槽
提交(j)：
    确认槽 j mod d 的上一代全部写者和全部读者已结束
    绑定本代身份 (j mod d,floor(j/d),j)，清除旧完成状态
    全体线程按上述划分加载有效输入、写零无效槽
    将全部加载和零填纳入本代完成契约
若 J=0：直接对有效零 accumulator 应用一次 E 并写回，结束
依次提交阶段 0…min(d,J)−1
对 j=0…J−1：
    等待本代全部输入完成，并建立 CTA 范围可见性
    两个 warp 各自消费本阶段，更新独占 accumulator
    等待两个 warp 的最后输入读取都结束
    释放本代输入槽；若 j+d<J，则提交(j+d)
排空已提交工作，等待全部 accumulator 更新结束
每线程仅向有效输出位置应用一次 E 并写回
```

J=1 只消费阶段0；J=2 消费0、1各一次；J=0 不等待未创建票据。复制完成、消费者可见和最后读者结束是三个条件。若矩阵消费改为异步指令，线程发射返回不等于结束读取，释放槽及修改 accumulator 必须使用该指令的完成契约。采用更精细的分离 A/B 槽可以减少等待，但 A 仍要等两个 warp 的全部读者。

这条标量路径给出了逻辑 tile、地址、线程归属、片上布局、消费和写回。改用矩阵指令时，要另证指令形状、dtype、操作数布局、参与线程和完成范围；跨 CUDA/ROCm 也须重做这一映射。公开的程序语义不能替代对目标生成程序的核验。

## 在线 attention 的底数、空状态与完整块程序

对一个 query 行，令可见 key 集合为 A_i，分数 z_ij=a·q_i·k_j+b_ij，概率 p_ij=exp(z_ij)/Σ_{t∈A_i}exp(z_it)，输出 o_i=Σ_{j∈A_i}p_ijv_j。这里 b_ij 是偏置，下面的 b 是指数底数，两者身份不同。不可见位置不进入分子和分母。

本章讨论无 dropout 的推理前向，要求可见分数和参与计算的 V 有限；点积及加偏置后也不能溢出。NaN、正无穷及其他特殊值须拒绝或进入另行定义的路径。L、S 非负，d、dv 为正，L 与 S、d 与 dv 不要求相等。L=0 返回空输出；S=0 或 S>0 但整行不可见时，都采用输出零向量、empty=True、自然 LSE=−∞的接口契约。

对已处理的非空可见集合 T，自然指数状态为：

m=max z，ℓ=Σ exp(z−m)，U=Σ exp(z−m)v。

空状态为 E=(−∞,0,零向量)。最大有效项贡献为1，因此有限域中的非空状态有 ℓ>0。合并两个不重叠非空集合时，令 m新=max(m1,m2)、r1=exp(m1−m新)、r2=exp(m2−m新)，更新 ℓ新=r1ℓ1+r2ℓ2、U新=r1U1+r2U2。这由逐项重标度直接推出。实数域中可交换、可结合，浮点只要求满足声明容差。

若以 b>1 为底维护 y=z/ln b，则状态改为 m_b=max y、ℓ_b=Σ b^(y−m_b)、U_b=Σ b^(y−m_b)v。输出仍为 U_b/ℓ_b；自然 LSE=ln b·m_b+ln ℓ_b。持久化的 log_bΣexp(z)=m_b+log_bℓ_b，不能直接当成自然 LSE。b=2 时尤其要保留这一单位。

```pseudocode
输入：Q[L,d]、K[S,d]、V[S,dv]，scale，偏置 bias，逐行可见集合 A[r]
      底数 b>1，Br>0、Bc>0，可选自然 LSE 输出
输出：O[L,dv]、empty[L] 和请求的 LSE[L]

函数 合并(X1=(m1,ℓ1,U1),X2=(m2,ℓ2,U2))：
    若 ℓ1=0 且 ℓ2=0：返回 (−∞,0,零向量[dv])
    若 ℓ1=0：返回 X2 的副本
    若 ℓ2=0：返回 X1 的副本
    m新=max(m1,m2)
    r1=b^(m1−m新)；r2=b^(m2−m新)
    返回 (m新,r1ℓ1+r2ℓ2,r1U1+r2U2)

lnb=ln(b)
对 q0=0,Br,2Br,… 且 q0<L：
    R=[q0,min(q0+Br,L))；只加载 R 内真实 Q 行
    对 r∈R：X[r]=(−∞,0,零向量[dv])
    对 k0=0,Bc,2Bc,… 且 k0<S：
        J=[k0,min(k0+Bc,S))
        加载 J 内真实 K/V；取得必要偏置与可见性
        对 r∈R：
            Y[r]=(−∞,0,零向量[dv])
            C={j∈J：j∈A[r]}
            若 C 非空：
                对 j∈C：y[j]=(scale·dot(Q[r],K[j])+bias[r,j])/lnb
                mb=max(y[j]，j∈C)
                对 j∈C：w[j]=b^(y[j]−mb)
                ℓb=Σ(j∈C)w[j]；Ub=Σ(j∈C)w[j]·V[j]
                Y[r]=(mb,ℓb,Ub)
            X[r]=合并(X[r],Y[r])
    对 r∈R：
        若 X[r].ℓ=0：
            O[r]=零向量；empty[r]=真；若请求 LSE，则 LSE[r]=−∞
        否则：
            O[r]=X[r].U/X[r].ℓ；empty[r]=假
            若请求自然 LSE，则 LSE[r]=lnb·X[r].m+ln(X[r].ℓ)
```

每块每行都先完整初始化 Y=E，再无条件合并。有效块之后出现空块，X 的三个分量必须保持不变；只设置最大值而复用旧 ℓ、U 会重复计入贡献。全空行不能执行负无穷相减或对零的除法。S=0 没有进入任何局部块，不能单独证明 S>0、跨多个空块的状态推进正确。

尾部同时约束 K/V 加载、分数、指数和 PV 的可见集合。把无效 score 补零并让它进入归一化，会创造不存在的概率质量。需要区分另一种操作：只改变公共平移常数，仍仅对有效项计算分子分母，在实数域中不改变 softmax；但较差平移可能在有限精度下引起下溢。因此“max 值变了”本身不是输出错误的证据。

## 融合边界由消费者和归约域决定

bias、激活、归一化或量化在片上消费中间值，可以减少物化和再次读取。若中间量有 N_int 个元素、每元素 s 字节，完全取消物化的理想节省为2·N_int·s字节。若另一个消费者仍需该中间量，写出必须保留，只能省去本消费者的读取；重算方案还应加回额外计算与输入读取。

GEMM 后的逐元素 bias/激活可在完整累加后消费；另一个分支若要未激活结果，就不能直接覆盖它。跨输出行的大归约则可能超出单 program 所有权，需要部分状态、额外阶段和完成边界。融合不允许改变统计域、激活定义或模型要求的舍入点。

attention 的在线统计量足以合并不重叠 KV 块，因此可以不物化完整分数/概率矩阵；若外部消费者需要完整概率矩阵，这个输出接口就不能被只返回 O、LSE 的路径替代。实现可以把旧 U 先重标度，再直接累加当前 PV，省去独立局部 Ub；若仍使用上述显式 Y 状态，容量账就应保留它。

融合增加活跃临时量和生存区间，可能减少驻留、引入 spill 或布局转换。减少一次 launch 只是收益的一部分；完整 producer→consumer 链及外部活跃分支才是比较范围。

## 条件化成本：计算、交通、同步与驻留

GEMM 的有效主项为2MNK FLOP，稠密 attention 为约2LSd+2LSdv FLOP，偏置、mask、指数、归约和 epilogue 另计。若填充 tile 仍执行完整乘加，G=⌈M/BM⌉⌈N/BN⌉、J=⌈K/BK⌉，GEMM 执行主项可达2G·BM·BN·J·BK；有效 FLOP 与填充工作要分别报告。

GEMM 每输出块每阶段的满 tile 输入请求约为 s_in·(BM·BK+BK·BN)，累加器逻辑容量约为 s_acc·BM·BN。d 级输入缓冲容量主项为 d·s_in·(BM·BK+BK·BN)，这是容量，不是额外读取流量。地址、mask、barrier、转置和 epilogue 临时量另计；尾部掩码可能减少实际元素请求，但不保证按相同比例减少指令或事务。

设 M=128、N=256、K=96，输入FP16、累加FP32。方案A为32×64×32，输出块16个、每块3阶段；每阶段输入6 KiB，双缓冲12 KiB，累加8 KiB。方案B为64×128×32，输出块4个、每块3阶段；每阶段输入12 KiB，双缓冲24 KiB，累加32 KiB。

若每 program 用4个CUDA warp、128线程，均分累计值时分别是每线程16和64个FP32值。这只是逻辑均摊估计；fragment、临时值和编译器复制会改变实际寄存器需求。方案B复用更强，但块数更少且每块资源更大，小矩阵上可能无法填满设备。

无跨 block cache 重用的请求账中，A/B 读取分别为16×3×6=288 KiB和4×3×12=144 KiB。唯一输入 A 为24 KiB、B为48 KiB，共72 KiB。请求字节、唯一数据和实际HBM事务不是同一量，L2复用、合并访问、对齐及调度会改变后者。

attention 采用 query 块在外时，理想化的 K/V 请求主项约为⌈L/Br⌉·S·(d+dv)·s_in，尚未计 cache、偏置和显式 mask。单块的活跃集合包括 Q 的 Br·d、K/V 的 Bc·(d+dv)、分数/概率的 Br·Bc、U 的 Br·dv 及每行统计；混合 dtype 分别换算字节。若同时保存局部 Ub，另加一个 Br·dv；多级缓冲只对实际复制的对象乘级数。不能在算法仍保留对象时从容量式删掉它。

普通输出独占 GEMM 和单程 attention 不需要跨 program 合并输出；CTA 内协作加载和归约仍支付片上通信与同步。split-K 增加并行度，也增加部分状态交换。GEMM 若产生 P 份完整 FP32 部分矩阵，工作区主项为 P·MN·s_acc，写出和重读主项约2P·MN·s_acc，最终输出另计；更细的布局和 cache 会改变实际事务。attention 分区需要传递每行的 m、ℓ、U，而非直接平均归一化输出。

同时驻留 block 受寄存器、shared/LDS、线程、warp/wave 和调度限制。更多输出块可能只是增加排队；更大 tile 又可能减少网格块数、降低驻留并诱发 spill。同步、准备和执行是否重叠应由依赖图决定；max(F/P,D/B)只能给出声明模型下的理想下界，不能把互相重叠的各项时间机械相加。

## 布局、索引和数值路径的适配

固定 CUDA Best Practices 对相应代际的标量32-bit访存给出32字节段模型：32个 lane 读取对齐的相邻字，覆盖128字节、四个段；起点偏移4字节可能跨五个段。邻近 warp 的 cache 复用会改变实际流量，不能把段数直接等同于HBM事务。shared/LDS 布局还要服务矩阵操作数和写回；转置或 swizzle 的收益须减去转换成本。

ROCm 的 wave 宽度、寄存器组织、LDS bank 和矩阵指令契约依架构不同。可移植语言不保证同一配置跨平台最优；不能只替换 num_warps 或将 CUDA 常量改名。保留函数、输出所有权和完成依赖，调整线程映射、布局与缓冲；设备没有某条异步路径时，采用适合目标的加载与同步组织。

元素偏移达到2^31时，有符号32-bit整数不能表示其正值；FP16对应字节位置为2^32字节，即4 GiB。索引应在乘法和累加溢出之前采用足够宽的类型，对已经溢出的地址做 mask 不能恢复原关系。这是整数范围推导，不是全部设备或库的统一索引上限。

合法 view 的存储偏移会改变基址对齐。应比较直接支持 stride、单次重排和改变生产布局的完整成本；声称零拷贝须证明消费者接受原表示。描述符满足 shape 不代表满足布局、对齐或生存期。

FP32 accumulator 不代表整条数值路径均为FP32。QK乘法、指数近似、概率转换、PV、归约树和输出转换各有舍入边界；TF32、reduced-precision reduction 和批量路径也可能改变结果。切换时重新验证容差、argmax、概率分布和任务质量，不能继承教程 provider 的误差阈值。

有限负常数屏蔽只在限定输入域和误差要求下可能成立，不能定义任意极端 logits 或全 mask 行。若实际乘法、累加或底数转换产生非有限中间值，本章有限标量模型的结论不能直接延伸。

## 编译变体、合法域与调优预算

编译缓存复用同一生成程序，合法域排除不支持的表示和资源条件，性能选择比较合法候选。这三个层次不同。autotune key 应保留实际影响合法性或性能的 dtype、shape或桶、stride、mask/偏置模式、目标架构及数值策略；请求ID等无关身份不应制造变体。

候选剪枝是实现选择。若规则把大于当前输入的 tile 全部剪掉，短输入可能没有剩余候选；应补充配置、提供语义正确的padding路径或采用通用后端。tile 大于输入不天然非法，正确加载/归约掩码可以使其合法但浪费。不能把短输入解释成另一个已有长度。

autotune 会多次执行候选。纯计算输出易于覆盖，KV append、scatter、随机状态和计数更新则会改变后续试跑的工作。比较应恢复相同初始状态，或分离可调优计算与一次性提交；否则更快可能来自少做或重复做了不同工作。固定测试配置、搜索候选集合和最终选中配置也不能互相代替。

TVM 的计算/schedule/intrinsic 分离与 Ansor 的结构、参数、成本预测和硬件测量，说明搜索空间不仅是两个tile参数，还包括融合边界、缓存位置、归约划分和布局。成本模型用于安排实验，不能证明合法性或替代目标测量。

设编译与搜索成本C=1.2秒，每次真实调用节省Δt=2微秒，需 N·Δt>C，即超过600,000次同等收益调用才收回时间成本；每decode步32次调用时，对应超过18,750步。这是设定预算，未计维护、驻留、形状不命中或重叠。

小M的decode会浪费大M tile；可以比较更小tile、GEMV、split-K或跨请求合批。长prefill可摊薄启动并提高复用；设备已经饱和时增加分区可能只有额外合并。并发请求、工作区和cache竞争改变后，孤立kernel最优配置也须复核。少见形状、部署寿命短或成熟库已接近瓶颈时，应允许放弃专门调优。

## 诊断：竞争解释、负对照和反证

| 竞争解释 | 可区分预测 | 干预与观测 | 反证后的修正 |
|---|---|---|---|
| 大tile导致网格并行不足 | 小M时差距大，增加输出块后差距缩小 | 固定tile与K，改变M/N，记录完整网格时间和活跃block | 增加块数仍无改善，不能只归因于并行度 |
| 片上容量降低驻留 | 单block可能更快，多block整网格更慢 | 比较单block与整网格，核对寄存器、shared/LDS及驻留台阶 | 驻留未变且无资源限制，应降低该解释权重 |
| spill增加流量 | 有新增local读写，长K也持续支付 | 核验生成程序和local交通，缩短非关键临时量寿命 | 无spill或消除后仍慢，改查布局、同步及并行度 |
| 深流水只增加首尾成本 | 短K较慢，长K差距缩小或反转 | 固定tile扫描阶段数，分辨固定项和稳态斜率 | 长K斜率更坏，首尾不能单独解释 |
| 未形成预期重叠 | 源程序有异步表达，实际等待和空洞未减少 | 查生成指令、完成依赖和时间线 | 等待减少却更慢，应查新增容量、交通或转换 |
| 准备掩盖kernel收益 | kernel更快，完整调用无改善 | 分开首次编译、调优、转换、复用准备和稳态 | 差异全在kernel内部时，准备不能解释 |

改变M/N会改变总工作，实验应比较各自相同输入上的候选差异或合理归一化，不能把不同工作量的绝对时间直接归因。计数器replay也可能改变cache和副作用；正常执行用于确认收益，计数用于解释机制。差异落在独立重复的不确定范围内时保留未知。

正确性诊断先使用独立参考。GEMM参考直接对有效m/n/k求和，不读取tile模型的加载结果；访问模型在每次真实读取时记录逻辑坐标和元素地址，并拒绝跨出逻辑shape的访问，即使那个地址仍落在分配的padding中。分别注入旧A掩码和旧B掩码，避免第一个越界提前终止掩盖另一路错误；再以非零bias核对单次epilogue，并确认双次应用被同一输出比较器拒绝。

attention参考独立遍历整行有效集合，用自然指数稳定softmax。每完成一块，把m、ℓ、U与已处理有效集合的整段统计比较；空块必须保持旧状态。非空长度、visible全部为False、跨多个块的行与S=0分别检查，并对b=2/e都核对零输出、empty=True及自然LSE=−∞。

底数混用有明确函数反例：两个分区的log₂质量为0和2，归一化输出为0和2，正确权重1和4给出1.6；误用自然指数给出约1.7616。负对照应真正进入合并路径，并由独立整行参考拒绝，而不只比较两个指数值。

无效槽负对照也进入真实归约路径：把不可见或尾部槽当成score=0、V=0的项，使它们进入分母，再与只含合法项的参考比较。对全负合法score，这些假项会夺走概率质量。检查另确认在温和有限输入下，仅把公共平移最大值改为0、仍排除无效项时，输出保持参考结果。因此检测到的是错误纳入无效项，不能声称证明了所有“max补零”形式都会改变输出。

## 接入与证据边界

接入教程前应还原实际执行域：head维约束、batch/head/token展平方式、query/KV独立长度、页表、ragged偏移、GQA映射、独立value维及descriptor要求。分页decode、cross-attention等需要扩展索引与状态契约或选择已有后端，不能仅传入形状相似的指针。训练教程保存的LSE和backward状态是否可删除，取决于真实下游消费者；不能删掉分区合并仍需的统计量。

验证从数学输出、合法stride、尾部、空行和副作用进入真实准备、工作区、转换及图捕获，再回到模型和请求流。图固定地址不证明地址内容及生命周期正确。冷编译、搜索与稳态分开；GPU异步调用返回不等于执行完成，用于计时的同步也不能任意破坏正常重叠。保留语义正确的通用后端，并把fallback比例和成本计入结果。

随章检查 tools/check_k_fw_007_full.py 是独立、离线、只读的Python标准库标量模型：执行带stride和偏移的GEMM加载及写回轨迹，与直接矩阵参考比较；核对attention逐块统计、空块、S>0全不可见行、S=0、非整除尾部、b=2/e自然LSE和有限极端分数；检查上述实际注入错误及解析资源账。它不实现或验证本章64线程的真实GPU调度，也不执行QK矩阵指令、低精度转换或autotune副作用隔离。

本轮没有执行该新脚本，不预先声明通过。CPU标量模型不能证明GPU的内存可见性、barrier作用域、异步重叠、fragment映射、spill、实际事务或性能，也不证明模型质量或Agent使用效果。
