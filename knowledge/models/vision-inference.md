# K-MODEL-014：视觉识别与卷积：空间布局、预处理与任务输出

视觉识别的请求从图像字节开始，经过确定的几何和颜色变换、卷积或视觉编码器，再产生分类、检测等任务输出。空间分辨率、布局与预后处理会改变模型函数和资源成本，不能用生成式模型的输入 token 数直接代替。本章把预处理、卷积、残差与固定 BN、分类/检测输出和请求执行连成一条可复算路径；给定 checkpoint 与 processor 之前，不能仅凭模型名称比较两个视觉系统。

## 请求对象、状态与输入契约

设一个请求为 q=(id,g,S,P,M,T)，其中 id 是请求身份，g 是本次执行尝试，S 是不可变图像快照，P 是 processor 契约，M 是模型与权重身份，T 是任务头与后处理契约。S 至少绑定实际字节、解码/方向/颜色规则和内容身份；相同文件名或 locator 不证明内容相同。P 明确规定 resize、crop 或 letterbox、插值、通道顺序、值域、归一化、padding 值及其施加阶段、物理布局。M 绑定卷积结构、批次统计是否固定、残差顺序、激活、池化域和输出宽度。T 绑定类别表、分数阈值、框格式、NMS 规则和坐标映射。

输入张量不能只用 shape 表示。一个逻辑张量可写为 (V,shape,stride,offset,dtype,layout,device,meta)，meta 包括轴语义、图像几何、模型规定的填充、执行容量及量化 scale、别名等。对普通 strided 张量，地址主项为 addr(i)=A+b(o+Σⱼ iⱼsⱼ)，其中 A 是基址，b 是每元素字节，sⱼ 以元素计。NCHW 与 NHWC 的轴顺序不同；即使统一逻辑轴表示，相同逻辑 shape 仍可能对应不同 stride 或分块存储。转换布局需要真实读写，不能把逻辑 view 当作免费物理重排。

请求状态可采用 ACCEPTED、DECODED、PREPROCESSED、TRANSFERRED、RUNNING、POSTPROCESSED、DONE、FAILED、CANCELLED。状态表示逻辑责任，不等同于设备 DMA 或 kernel 已完成。合法实现至少要求：图像维度和通道满足 P；resize/crop 后图像区域非空；布局、dtype、对齐和 stride 被后端接受；批次内每个请求携带自己的几何与执行范围；取消后仍保护在途读写；类别表与坐标格式没有串用。空图像、非法裁剪、无法表示的通道顺序和超出后端容量的 shape 必须拒绝或走明确回退路径，不能静默截断。

视觉 encoder 若采用 patch/attention，应按实际模型处理网格、位置与可见关系；本章的卷积成本公式不适用于全部视觉网络。视觉识别、视觉语言模型的图像编码阶段和图像生成的去噪循环也有不同任务输出与状态。

## 预处理与坐标变换的完整数据流

解码器先处理压缩字节、EXIF 方向、颜色空间和通道顺序。随后 P 把源图像映射到模型张量。以源尺寸 W×H、目标尺寸 Wt×Ht 的 letterbox 为例，理想比例 s=min(Wt/W,Ht/H)。实际 processor 通常还要把缩放尺寸取整为 Wr、Hr，再分配整数 padding p_left、p_right、p_top、p_bottom，满足 Wr+p_left+p_right=Wt、Hr+p_top+p_bottom=Ht。取整方式和奇数差额放在哪一侧属于 P，不能在后处理时重新猜测。

在连续边界坐标下，定义 sx=Wr/W、sy=Hr/H，源到目标的映射为 xt=p_left+sx·x、yt=p_top+sy·y；逆映射为 x=(xt−p_left)/sx、y=(yt−p_top)/sy。未取整的理想情形有 sx=sy=s；取整后两轴比例可能略有不同。中心裁剪则把裁剪偏移并入平移项。几何账本 G 必须保存实际采用的尺寸、偏移和坐标约定。

框的连续边界坐标与像素采样坐标应分开。以零基目标像素下标 j 为例，一种半像素双线性约定为 u=(j−p_left+0.5)/sx−0.5，纵轴同理，再从 floor(u)、floor(v) 及相邻四点加权采样。边缘 clamp、antialias、align_corners 或其他约定必须由 P 固定。最近邻、双线性、双三次和带 antialias 的 resize 是不同函数；只写 resize 名称不足以恢复张量。

归一化写成逐通道仿射 v_c=a_c·p_c+b_c；若 a_c=1/std_c、b_c=−mean_c/std_c，就必须说明 p_c 的原始值域和通道轴。padding 若在原始像素域加入，也要经过归一化；若直接在归一化张量域加入，则使用该域规定的值。两者不能混用。量化模型还要执行明确的舍入、zero point 与饱和，不能把浮点参考值直接当作量化码。

```pseudocode
算法 PreprocessImage(S, P)
输入：不可变图像字节 S；完整 processor 契约 P
输出：模型张量 X、实际坐标变换 G、图像几何元数据；或明确失败
1 解码 S，处理方向、颜色、通道；空图或非法编码失败
2 按 P 计算整数缩放尺寸、裁剪或 letterbox 偏移
   校验源和目标尺寸为正，缩放因子有限且大于零
3 对目标每个位置 (j,i)：
   若属于缩放图像：按 P 的采样坐标与插值求各通道像素
   否则：按 P 的阶段规定取得模型 padding 值
   按 P 依次执行颜色/值域仿射、dtype 转换及必要的量化舍入和饱和
   写入目标布局的实际地址；记录该位置的几何来源
4 保存实际 sx、sy、裁剪/填充偏移及正逆变换 G
5 校验输出 shape、stride、有限值策略和布局转换完成
   返回 X、G、元数据；失败不发布半成品张量
```

这里必须区分两种 padding。第一种是 P 规定的 letterbox 或其他模型输入填充：它已经属于 X 的逻辑输入域。checkpoint 原本在整个特征图上做全局平均池化，就应保留那个域及分母；若模型明确规定 masked pooling，才按它的掩码规则执行。记录“哪些位置来自源图像”有助于坐标还原，但不会自动授权排除其余位置。设固定 processor 产生单通道 X=[1,0]，模型为恒等 1×1 卷积后对两个位置做平均，参考结果是 (1+0)/2=1/2。按源图像区域只保留第一个位置会得到 1，已经改变相同图像、processor 和权重下的函数。

第二种是执行器为了聚批、分桶或对齐，在完整 X 之外额外分配的槽。这些槽不属于原模型的逻辑输入。容量足够只证明存得下；能否不读取它们、屏蔽它们或调整池化分母，需要证明整个改写与独立执行等价。特别地，执行有效域包含 P 原本规定的 padding，不能把源图像区域掩码直接当作执行掩码。上述 X 若额外补成 [1,0,0,0]，在恒等卷积这一特例中，按原逻辑前两个位置求平均仍为 1/2；对四个位置求平均为 1/4，按源像素只取第一个则为 1。这个特例不能证明一般卷积网络只需末端 masked pooling。

预处理成本包括解码、颜色转换、重采样、归一化、布局转换和临时缓冲。以目标像素数 Nt=Wt·Ht、通道 C 计，写出至少 Nt·C 个元素，其中包含 P 规定的 padding。双线性每个输出最多读取四个源点，但 cache、向量化和边界处理决定实际事务。解码图、浮点临时图和设备张量若同时存活，驻留按各唯一副本求和；执行器额外槽的初始化、搬运与后续计算另计。

## 卷积：定义、合法形状与完整算法

本章采用深度学习中常见的不翻转核的互相关定义。设 batch 为 B，输入通道 Cin，输出通道 Cout，卷积核 Kh×Kw，组数 G，输出空间 Hout×Wout。要求 G 为正整数，Cin 与 Cout 都能被 G 整除；第 g 组使用输入通道 [g·Cin/G,(g+1)·Cin/G) 和输出通道 [g·Cout/G,(g+1)·Cout/G)。下面使用对称零边界，输出尺寸为 Hout=floor((H+2pH−dH(Kh−1)−1)/sH)+1，Wout 同理。s、d 为正整数，p 为非负整数；非对称 padding 应用两侧之和替换 2p，并在索引中使用前侧偏移。

stride、padding、dilation 和边界模式决定函数及形状，不是可以事后修补的性能参数。卷积算子自身的零边界表示域外不读取 X；它与 processor 已写入 X 的 letterbox 值不同。若 Hout 或 Wout 非正，本章程序返回空输出；实际接口也可明确拒绝，但不能进入非法索引读取。空输出不能直接交给要求非空域的平均池化。

乘加数为 B·Hout·Wout·Cout·(Cin/G)·Kh·Kw；一次乘加计两次浮点操作时 FLOPs 为其两倍。权重元素数为 Cout·(Cin/G)·Kh·Kw。逻辑输入、输出与权重字节分别按元素数乘 dtype 字节计；实际事务取决于布局、对齐、cache、tiling 与重复加载。G=1 的 1×1 卷积可视为 M=B·Hout·Wout、K=Cin、N=Cout 的矩阵乘法，stride 大于 1 时还要按原定义选择输入位置。

```pseudocode
算法 ConvForward(X, W, bias, stride, pad, dilation, G)
输入：X[B,Cin,H,Win]、W[Cout,Cin/G,Kh,Kw]，可选 bias[Cout]
输出：Y[B,Cout,Hout,Wout]；采用不翻转核的互相关和对称零边界
1 校验整数参数、通道组、权重 shape、输入存储范围及数值契约
   按公式计算 Hout、Wout；任一非正则返回空输出
2 对 b、co、oy、ox 的每个有效组合：
     acc←0；g←co div (Cout/G)
     对 cl=0…Cin/G−1，ky=0…Kh−1，kx=0…Kw−1：
        ci←g·(Cin/G)+cl
        iy←oy·stride_h−pad_h+ky·dilation_h
        ix←ox·stride_w−pad_w+kx·dilation_w
        若 0≤iy<H 且 0≤ix<Win：
           acc←acc+X[b,ci,iy,ix]·W[co,cl,ky,kx]
        否则：不读取 X，使用本算子的零边界
     若 bias 存在：acc←acc+bias[co]
     Y[b,co,oy,ox]←按输出 dtype 转换(acc)
3 全部有效输出写完后返回 Y
```

正确性不变量是：输出位置只归约声明感受野中的输入；输入与输出通道属于同一组；bias 对每个输出恰好加一次；边界判断先于读取。显式 im2col 将每个输出位置的 (Cin/G)·Kh·Kw 个输入窗口写成矩阵行，再执行 GEMM。若一次物化全部组，展开元素总数为 B·Hout·Wout·Cin·Kh·Kw；若逐组物化，峰值可降为 B·Hout·Wout·(Cin/G)·Kh·Kw，总写读与所有组的计算仍要列账。隐式 GEMM 不写完整展开矩阵，却增加索引和边界处理。Winograd/FFT 的变换、工作区、数值误差与适用形状必须单独核对，不能因为核为 3×3 就假定 backend 已选择某条路线。

按组映射时，M=B·Hout·Wout、K=(Cin/G)·Kh·Kw、N=Cout/G。行 m 解码为 b=m div (Hout·Wout)、oy=(m mod (Hout·Wout)) div Wout、ox=m mod Wout；归约下标 k 解码为 cl=k div (Kh·Kw)、ky=(k mod (Kh·Kw)) div Kw、kx=k mod Kw。由这些坐标和原 stride/pad/dilation 求 X 的实际地址；矩阵列 n 对应 co=g·N+n。展开矩阵的逻辑元素 A[m,k] 是该输入值或域外零，权重矩阵 B[k,n]=W[g·N+n,cl,ky,kx]。这给出了从卷积窗口到矩阵元素及张量地址的完整对应。

```pseudocode
算法 GroupedTiledConv 的矩阵阶段
输入：上述按组定义的 A、B；正 tile 尺寸 Mt、Nt、Kt
输出：原卷积布局下的 Y
1 对每组 g 和每个输出 tile (m0,n0) 指定唯一写者，acc 全部置零
2 对 k0=0,Kt,… 且 k0<K：
   按 m、k 解码和真实输入地址形成 A_tile，越界位置补数学零
   按 k、n 读取 B_tile，矩阵尾部补数学零
   协作实现须等待本阶段全部输入对消费者可见
   acc←acc+A_tile·B_tile，沿 K 累加而不重复 bias/激活
   本阶段所有读取结束后才允许覆盖输入 tile
3 全部 K 段结束，对有效 m、n 加一次 bias 并执行合法 epilogue
4 将 m、n 还原为 b、co、oy、ox，按输出 stride 写回一次
```

该伪代码定义逻辑所有权、存储交接与归约顺序，不指定某款 GPU 的 lane/fragment 映射。采用具体矩阵指令时，还须由目标接口确定线程参与、布局、对齐、装载与完成语义。Mt×Nt 个累加器的容量主项为 Mt·Nt·s_acc，输入与权重 tile 另需 (Mt·Kt+Kt·Nt)·s 字节；双缓冲增加输入驻留。片上资源不足时应缩小 tile、改变融合边界或放弃该映射。

沿 K 分块后，前 t 块的 accumulator 等于相应已完成归约段的部分和。split-K 则产生同一输出的多个部分结果，必须先合并，再应用一次 bias 和非线性。若有 P 份完整部分矩阵，工作区主项为 P·M·N·s_acc，写出与重读约为 2P·M·N·s_acc，最终输出另计；跨设备还增加通信与完成依赖。并行度收益必须超过新增成本，没有对全部形状都最优的固定 tile 或分区数。

depthwise 的一个特例为 G=Cin=Cout、每通道一个核；也可有多个输出通道对应每个输入通道。其乘加较少，但每个输出参与的归约更短，往往更容易受访存、启动和布局转换限制。把它当普通 dense GEMM 可能引入零填充和无用计算，不能从 FLOPs 比例直接推出时间比例。将普通卷积改成 depthwise 或深度可分离结构通常改变模型函数，需要相应权重和质量评估。

## 残差、归一化与合法融合

ResNet v1 的残差块把 F(x) 与 x 或投影 W_s·x 相加，再按 checkpoint 规定顺序激活。F(x) 与 shortcut 必须有相同空间形状和通道解释；降采样位置、通道补零 shortcut 与 1×1 投影 shortcut 是模型定义的一部分，不能只根据 block 名称猜测。若先原地覆盖 x 再读取 shortcut，F 虽然算对，加法却使用了被覆盖的值。

固定推理统计的 BatchNorm 是按通道的仿射变换。对卷积 z=W*x+b，令 a=γ/√(variance+ε)，可构造 W′=a·W、b′=a·(b−mean)+β，从而在实数算术上使 BN(W*x+b)=W′*x+b′。该合并要求 mean、variance、γ、β、ε 固定，且折叠常量在目标 dtype 中可表示；浮点折叠仍可能改变中间舍入。若运行中计算 batch 统计，不能使用同一组常量。量化 scale、zero point、bias、舍入与饱和位置也要重新核对。

```pseudocode
算法 FoldFixedBatchNorm(W, b, gamma, beta, mean, variance, epsilon)
输入：卷积参数及固定推理 BN 参数；缺省卷积 bias 视为零
输出：折叠后的 W′、b′；或拒绝
1 校验参数 shape、有限性及 BN 原始合法域
2 要求每通道 variance+epsilon>0；否则拒绝或走明确例外路径
3 对每个输出通道 co：
     a←gamma[co]/√(variance[co]+epsilon)
     W′[co,…]←a·W[co,…]
     b′[co]←a·(b[co]−mean[co])+beta[co]
4 按目标 dtype 转换；检查溢出，记录转换与舍入边界后返回
```

```pseudocode
算法 ResidualV1(x, F, shortcut, activation)
输入：x；shortcut 是 identity 或模型规定的投影/通道补零分支
输出：按 checkpoint 顺序得到的残差输出
1 r←F(x)，保留原 x 到 shortcut 消费完成
2 s←shortcut(x)
3 校验 r 与 s 的空间形状、通道解释及 dtype 合同
4 y←r+s
5 返回 activation(y)
```

融合卷积、bias、固定 BN 和激活可减少中间写读；把残差加法也融合进来，还要满足另一输入的生命周期、布局和 dtype。若一个 N 元素中间量本来需要写出后再读入，理想可节省约 2N·s 字节；另有消费者时不能直接删掉写出。更多融合可能增加寄存器、工作区、spill 或限制库调用，不能保证端到端单调变快。融合改变归约或舍入次序时，应分别验证允许误差和任务质量。

固定 BN 虽不跨请求计算统计，其常数偏置仍可使执行器额外槽变成非零；卷积 bias 也有同样问题。因此“额外槽最初补零”不构成后续层可以忽略它们的证明。原模型明确采用动态统计时，聚批还可能改变统计域，此时连请求之间的数学独立性都需要重新判断。

## 分类、检测、坐标还原与 NMS

分类路径通常经过特征提取、pooling 和分类头，返回类别分数及其映射。对模型规定的非空特征域 Ω，逐通道全局平均为 h_c=Σ_(u,v)∈Ω Z[c,u,v]/|Ω|。Ω 必须来自 checkpoint 的池化定义；不能由源图像掩码、物理桶尺寸或“值恰好为零”临时决定。单标签 softmax、多标签 sigmoid、top-k 和阈值策略遵循任务定义。类别表版本、类别顺序和输出索引属于结果身份；top-k 同分时应有确定规则。分类正确不能代替检测定位正确。

ResNet v1 附录 A–C 给出一个具体历史检测路线：整图共享卷积特征、RPN 产生候选、RoI pooling 后接区域计算，最终分类与框回归；可加入 box refinement、NMS 和多尺度。其 proposal 数、NMS 阈值和测试尺度是论文设定，不是所有检测器的默认值，也不是全部检测架构的必经步骤。

框用连续坐标 [x1,y1,x2,y2] 表示时，面积 area(b)=max(0,x2−x1)·max(0,y2−y1)。交集面积为 max(0,min(x2)−max(x1))·max(0,min(y2)−max(y1))，IoU=交集/(area(A)+area(B)−交集)。这里的 min/max 分别在两个框的同名坐标间求值。负宽度、零面积框、NaN 分数和非有限坐标应按任务契约拒绝或过滤；不得把非法框静默当成正常候选。

检测结果从目标坐标回到原图时使用预处理保存的实际 G；resize 两轴比例、letterbox 偏移、crop 平移、坐标轴顺序和边界是否包含末端必须统一。本章以下示例选择“逆变换、裁剪到原图、过滤非正面积框、再 NMS”，并保留原始候选索引。其他顺序可以属于另一合法任务契约，但与本参考比较前必须相容。

```pseudocode
算法 NMS(boxes, scores, classes, iou_threshold, class_aware)
输入：已还原、裁剪、过滤的正面积框，有限分数与类别；原始索引
输出：保留框的原始索引序列
1 校验数组等长，阈值在 [0,1]，坐标与分数有限
2 按 (−score,原始索引) 排序，得到 order
3 suppressed←全 false；keep←空
4 对 order 中每个尚未抑制的 i：
     keep 追加 i 的原始索引
     对 order 中 i 之后的每个尚未抑制的 j：
       若 class_aware 且类别不同：跳过
       intersection←连续坐标交集面积
       union←area(i)+area(j)−intersection
       iou←intersection/union
       若 iou>iou_threshold：suppressed[j]←true
5 返回 keep；空输入返回空序列
```

阈值等号由任务明确：本章示例严格大于才抑制。若契约规定大于等于，必须显式替换并重测。先裁剪再算 IoU 与先 NMS 再裁剪可能给出不同集合；跨类别框是否互相抑制、同分顺序、refinement 与 box voting 的位置也属于输出契约。检测指标应按任务规定报告 AP/mAP 及 IoU 条件，不能只比较框数量或分类标签。

后处理成本包括候选数 P 的排序 O(P log P)、最坏 O(P²) 的成对 IoU 比较、RoI 采样与区域计算、坐标变换和结果驻留。若物化成对 IoU 矩阵，还需 O(P²) 存储；逐项比较可以避免这个矩阵。多尺度或 refinement 增加候选与区域工作。NMS 可能成为 CPU 瓶颈，候选数大的请求也会拖长尾部。

## 请求执行、聚批与资源放置

CPU 解码/预处理、设备搬运、加速器执行、后处理可以分阶段聚批，但批次项必须携带图像 ID、G、完整模型输入域和输出归属。一个阶段 batch 大小最优，不意味着完整请求适合等待同样大的批。按分辨率分桶可减少执行器额外槽与编译变体，但超出容量应明确换路径、扩容或拒绝，不能静默裁掉对象。

设 F 是原模型程序，E 把完整 processor 输出嵌入桶，F̂ 是改写后的桶程序，R 取回请求输出。合法改写要求在声明输入域内 R(F̂(E(X))) 与 F(X) 满足规定的数学或数值关系。这个条件包含全部层、统计域、坐标和输出身份。末端 pooling 分母相同只是其中一部分。若未证明等价，可保留同完整逻辑 shape 聚批，或回退独立执行；不能把 masked pooling 当作通用修复。

边界传播可用单通道一维卷积完整展开：原逻辑输入 x=[1]，两层都使用核 [1,1,1]、stride=1、每侧算子零边界一格、无 bias。独立执行第一层为 [1]，第二层仍为 [1]，全局平均为 1。执行器扩到 [1,0] 后，第一层得到 [1,1]，额外位置已吸收原输入；第二层得到 [2,2]，额外位置的值又传播回原位置。即使最终只取原位置并以 1 作分母，结果仍为 2。这里首次分歧在第一层额外位置，首次进入原逻辑域的分歧在第二层；仅检查第一层原位置会漏掉错误。

对于这个固定 stride=1、保持宽度、局部零边界的程序，逐层把结果裁到原逻辑宽度，再为下一层重建零边界，可以恢复独立函数。也可以在每层把逻辑域外位置归零并阻止消费者把它们当成模型内位置。一般网络还要按实际 stride、padding、dilation、pooling 和分支推导每层逻辑域及边界规则，不能始终沿用输入掩码。若原逻辑输入本身含 letterbox，它仍必须留在每层原模型计算中；按源像素掩码归零会再次改变函数。“感受野接触过有效像素”也不能作为域定义，否则会把额外槽重新纳入。

异步流水中，输入图像缓冲、转换后张量、模型工作区、候选区和输出各有最后消费者。取消只移除客户端结果需求，不代表设备已停止读写。图捕获和编译分桶管理有限分辨率与 proposal 容量时，还要核对指针、形状、逻辑域和本请求身份；最后读者结束前不能复用缓冲。

成本应分阶段列账：解码和重采样是主机计算；布局转换与 H2D 是访存/通信；卷积包括乘加、权重读取、片上驻留和协作同步；NMS 随候选变化；等待聚批是队列成本；编译、调优和权重打包是准备成本。逐层屏蔽额外域还可能增加启动与写入，或限制融合。若桶程序实际计算全部物理 H×W，就按这个范围付费，不能因最终丢弃部分输出而扣除计算。

固定权重打包或编译花费 T_p，每次匹配调用节省 Δt，实际复用 R 次时，严格摊销要求 R·Δt>T_p；形状未命中、重编译和新驻留另计。端到端时间由依赖关键路径与共享资源决定，不能把可重叠阶段耗时直接相加。小 batch、多分辨率或后处理主导时，更简单路径与短等待可能优于大 batch；大 batch、固定分辨率时，布局稳定与执行摊销可能更明显。

## C12-C：视觉识别与检测的完整验证场景

设定固定 checkpoint、224×224 单裁剪分类契约，并考察其中一层 B=1、56×56、Cin=Cout=64、3×3、G=1、stride=1、保持空间尺寸的卷积。乘加数为 56²×64×64×9=115,605,504；FP16 输出元素为 56²×64=200,704，字节数为 401,408。显式 im2col 为 56²×(64×9)=1,806,336 个元素，FP16 下为 3,612,672 字节，约为原输入的 9 倍，尚未计 GEMM 工作区。换成 depthwise 是不同模型函数，其乘加为 56²×64×9=1,806,336，不能在保持既有模型的优化比较中直接替换。

候选 A 保持统一布局并用库卷积；候选 B 使用有目标 shape 依据的编译/融合路径。两者以相同图像字节、processor 和权重执行，先比较解码后像素、预处理张量、卷积边界、残差输出与最终 logits，再比较固定测试集 top-1/top-5。测试纯色、单像素脉冲、分组通道、非连续 stride、极小图、不同宽高比和混合批，定位插值、边界、组映射及布局错误。非法组参数应拒绝，不能用错误数值代替合法性检查。

聚批检查分别固定两层契约：先在 processor 不变时只改变执行桶容量，比较独立执行与改写全链路；再明确改变 processor 的 letterbox 设置，此时承认输入函数发生变化，不能要求原输出保持不变。用 [1,0] 的恒等卷积加平均确认模型填充仍属于池化域，再用两层 [1,1,1] 核反例确认末端裁切和分母调整不足。若逐层原逻辑域一致而 logits 仍有微小差异，应继续检查归约、融合和精度，不把差异自动归因于 padding。

检测子场景固定完整任务头及 resize、letterbox、框裁剪和 NMS 规则。用可手算矩形验证 IoU：A=[0,0,2,2]、B=[1,0,3,2]，连续坐标交集 2、并集 6，IoU=1/3。阈值为 1/3 且严格大于才抑制时，B 保留；大于等于的错误路径会抑制 B。分别检查空检测、同分框、跨类别框、模型填充附近的框、裁剪边界、零面积框和 proposal 容量超限，再测规定的 AP/mAP，不能只对照框数量。

性能报告完整图像/s、端到端 p95/p99、解码/搬运/模型/后处理时间与峰值内存；冷编译、预热和稳定态分开。降低分辨率、减少 proposals 或改为单裁剪若带来收益，应同时报告质量与任务定义变化。

## 诊断：竞争解释与区分实验

同一最终误差可能来自预处理、布局、组映射、额外槽传播、残差覆盖、BN、NMS 顺序或舍入。先固定图像字节和权重，按需导出解码像素、预处理张量、每层原逻辑域及额外域、残差分支、logits、框坐标与最终输出，再做一次只改变一个条件的实验。观测缓冲与主机读取会增加通信、同步及驻留，诊断运行和性能运行应分别计时。

| 观察 | 竞争解释 | 区分实验与反证修正 |
|---|---|---|
| 单像素脉冲位置偏移 | resize 采样约定、整数 padding 分配或 stride 读错 | 固定源像素，改变目标尺寸和奇数 padding；预处理已错则修 G/采样，首次卷积后才错则查卷积索引 |
| 单独正确，扩大执行桶后错误 | 额外槽进入统计域、卷积边界回流、批行错位或数值路径变化 | 保持完整 processor 输出不变，只改桶容量；逐层比较原逻辑域与额外域。末端分母错只解释归约差异，第二层边缘已错则必须修全链路边界或回退 |
| 加入源图像掩码后分类分数改变 | 错误排除模型 letterbox，或模型原本确有 masked pooling | 固定 [1,0] 与原始池化合同；普通平均参考为 1/2。输出 1 时修复对模型域的改动，不能把它当作精度改善 |
| 卷积整体偏置或缩放 | 权重轴、组映射、重复 bias 或 BN 折叠错 | 固定小权重逐输出参考；改变 K 分块不应重复 bias；折叠与未折叠按相容数值路径比较 |
| 通道块边界错误 | 分组索引或通道重排错 | 不同组使用可区分输入与权重；检查输出只读本组，shape 相同仍须数值对照 |
| dilation 输出尺寸正确却数值错 | 形状公式正确，实际采样间距被忽略 | 保持正确输出 shape，只在采样路径注入 dilation=1；与独立参考比较同一位置，排除仅凭 shape 检出故障 |
| shortcut 分支错误 | 原 x 被覆盖、布局或 dtype 不符 | 保留原 x 的参考对照先覆盖再相加路径；修生命周期，不能放宽容差掩盖固定差异 |
| NMS 边界框被误抑制 | 比较符号、裁剪顺序或类别策略不同 | 固定 IoU 等于阈值；另固定 raw IoU=1/3、裁剪后 IoU=2/3 的框对，阈值取 1/2 区分顺序 |
| 框位置对而类别错 | 类别表身份或阈值配置错 | 固定框，只改变类别表顺序及分数阈值，分别核对映射和筛选 |
| 卷积时间下降，总时间上升 | 布局转换、逐层屏蔽、启动、NMS、排队或驻留成为主项 | 记录完整阶段和实际 dispatch；新增成本抵消局部收益时撤回单一卷积加速解释 |

负对照必须经过实际被检路径。可分别省略 letterbox 逆映射偏移、忽略组索引、在保持输出尺寸时忽略 dilation、BN 漏减 mean、先覆盖 residual 输入、把 NMS 比较改为大于等于。padding 检查应把错误的源像素池化和仅末端屏蔽路径真正执行后交给同一比较器拒绝；仅检查存在掩码或输出 shape 相同没有判别力。

随章 tools/check_k_model_014_full.py 的判定域为确定性整数、有理数和顺序小模型：逐输出卷积对照按输入贡献散射的参考；固定期望补充形状与边界；BN 对照未折叠仿射；letterbox 对照中心位置与逆变换；NMS 对照明确保留集合。padding 部分区分源图像位置、完整模型域和额外执行槽，以固定 1/2 参考检出错误池化，并用两层边界回流反例及小域枚举检查逐层隔离的适用条件。

这些机制检查不执行图像解码、真实像素插值、完整 checkpoint 或目标 CPU/GPU kernel，不模拟 FP16/FP8 舍入、真实 HBM 事务、线程竞争、异步可见性与库 dispatch，也不证明模型质量或性能。逐层隔离的枚举只覆盖固定宽度、stride=1、零边界的一维两层卷积；真实网络的变尺寸层、动态统计、分支和池化仍需按其合同验证。
