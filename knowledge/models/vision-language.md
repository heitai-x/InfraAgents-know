# K-MODEL-008：视觉语言模型：Patch、模态桥接与联合位置

VLM 的输入由媒体内容、processor、视觉编码器、桥接器、文本模板和位置规则共同定义。图片张数、文本字符数或媒体 locator 都不能单独决定视觉 token 数、KV 容量或缓存命中。本章以 Qwen2.5-VL v1 报告为结构锚点，展开视觉到语言的数据流、生成状态和条件化成本；报告没有确定的 checkpoint 细节保留为显式契约参数。

## 输入对象、边界与合法状态

设请求包含有序媒体 m_1,…,m_k 和消息 M，固定 processor 契约 P、模型契约 C。模型契约 C 与 attention 的 query 张量 q 使用不同符号。讨论推理态；dropout、数值表示、归约允许误差和确定性要求均须固定。

- s_i 是不可变媒体快照，绑定内容身份、字节范围、解码、方向、色彩和源时间信息。相同 locator 不证明内容相同。
- X_i 是预处理像素或视频张量；G_i=(T_i,h_i,w_i) 是时空 patch 网格，携带有效范围和行到空间坐标的映射。
- F_i 是视觉 encoder 输出；Z_i 是空间合并和 projector 后的语言侧特征。二者有不同宽度、token 数和生命期。
- S 是最终模型输入行序列。文本行引用 token ID，视觉行引用 Z 的具体行，保留的特殊 token 也占实际位置。placeholder 是组装依据；除非模型确实保留该特殊行，展开视觉段之后不能再重复计一个 placeholder。
- Π 是每行位置；A 是逐层、逐 head 的合法可见关系。padding、媒体隔离、因果关系和位置推进都属于模型函数。

生成过程中另记录三个边界。n=|S| 是已知输入行数，包括已采样并提交的生成 token；c 是所有 decoder 层均已完成、一致提交 KV 的连续前缀长度；ℓ 是可选的原始末行 logits，绑定完整前缀身份和输出位置 c−1。只有 c=n 且 ℓ 属于当前边界，才能用它选择下一个 token。已输出 token 不等于已有其 KV：采样后通常 n=c+1。

请求可以经历 ACCEPTED → MEDIA_READY → PREPROCESSED → ENCODED → MERGED → PACKED → PREFIX_READY → DECODING → DONE。特征命中可以跳过计算，但必须恢复正确身份和几何。失败态包括 INVALID_MEDIA、INVALID_GEOMETRY、INVALID_LAYOUT、IDENTITY_MISMATCH、CAPACITY 和 CANCELLED。PREFIX_READY 只说明某个完整前缀可用，不保证已有可采样 logits。

合法性要求如下。

1. 媒体顺序、placeholder 绑定、Z 段和最终输入行一一对应。批次压紧不能交换两张图的特征。
2. processor、网格、merge、位置、权重和数值表示来自同一固定契约。高宽能被 28 整除只是报告中的几何条件之一，不能证明任意实现接受该输入。
3. 精确复用保持实际依赖闭包。形状、locator 或文本长度相同均不足；近似复用另需误差和质量契约。
4. 特征或 KV 仅在必要层、元数据及完成依赖齐备后发布。已发布共享区只读；取消不等于物理访问完成，全部引用和在途访问结束后才可回收。
5. decoder 追加复用要求旧前缀表示对新增后缀稳定。标准因果 self-attention 具备这一依赖结构；若新增输入改变旧行位置、可见集合或非逐行统计，必须重新判断。
6. 无媒体可以走文本路径。无输入行时由模板合法加入 BOS/生成提示，或返回 EMPTY_INPUT，不能对不存在的末行采样。输出预算为零时结束，不为生成补算 logits。

## 几何账本：Patch、窗口与空间合并

Qwen2.5-VL 报告说明：输入高宽 resize 到 28 的倍数，patch 边长和步长为 14；视觉 encoder 有 32 层，其中 4 层全注意力，其余使用最大 112×112、即 8×8 patch 的窗口，小区域不补齐到最大窗口。表中全注意力 block 标号为 {7,15,23,31}，执行时按固定模型确认编号对应关系。桥接器将空间相邻的四个 patch 特征拼接，经两层 MLP 投到语言宽度。7B 配置的视觉宽度为 1280，merger 输出为 3584，decoder 有 28 层、4 个 KV heads、head size 128。

静态图、无额外 crop 时，h=H/14，w=W/14，N_p=hw。2×2 空间合并要求 h、w 均为偶数，N_v=N_p/4。高宽为 28 的倍数使分组可整除。448×672 对应 32×48=1536 个 patch、384 个视觉输入行。若全部非视觉行共 512 行，则输入共 896 行；512 必须已经包含实际保留的特殊 token。

设窗口集合为 W，每窗有效 patch 数 a_u≤64，全注意力层数 L_f，窗口层数 L_w，则每个 head 的成对 score 计数为

C_pair=L_f N_p²+L_w Σ_{u∈W}a_u²。

按空间原点开始、不补齐尾窗的矩形分窗，448×672 有 24 个完整窗口，因此 C_pair=4×1536²+28×24×64²=12,189,696。32 层全 dense 则为 75,497,472，约为前者的 6.19 倍。这是成对工作计数，不是时延比。尾窗按真实 a_u 计数；固定模型采用不同划分时须替换 W。

每边分辨率翻倍使 N_p、N_v 增为四倍，全注意力项增为十六倍，固定最大窗口的窗口项大致增为四倍。四个全注意力层仍保留二次项。图像只有一个窗口时，两种层的可见集合可能相同，不产生渐近收益。

视频还需要帧选择、时间分组和时间位置。报告说明动态 FPS、连续两帧成组及绝对时间对齐。若固定实现每两帧形成一个时间片，再做 2×2 空间合并，且采样帧数 T 为偶数、空间形状固定，则 N_v=(T/2)hw/4。奇数尾帧、时间 patch 的数值构造、跨时间注意力范围必须由 C 确定，不能从静态图公式猜测。报告评测的每视频最多 768 帧、24,576 个 video tokens 是评测设置，并非所有服务的通用上限。

## 联合位置、可见性与前缀身份

RoPE 对二维通道对 (x_0,x_1) 使用位置相关角 θ，产生 (x_0 cosθ−x_1 sinθ,x_0 sinθ+x_1 cosθ)。多轴方案还须指定每个旋转通道对使用哪个轴、频率、尺度和布局。视觉 encoder 的 2D-RoPE 与语言 decoder 的 MRoPE 是两处变换，不能直接共用一套未经核对的编号。

Qwen 报告中的 MRoPE 分为时间、高、宽三个分量。文本三个分量相同，在该模型中等价于一维 RoPE；图像时间分量恒定，高宽随空间位置变化；视频时间分量与绝对时间对齐。精确时间戳比例、取整、通道划分及图像之后文本的位置推进规则，须由固定 checkpoint 契约补足。

以合并后 2×2 图像网格为结构示意，位置可写成 (t_0,0,0)、(t_0,0,1)、(t_0,1,0)、(t_0,1,1)。这表达轴关系，不规定整个 prompt 的绝对起点。换成 (0,0,0)、(1,1,1)、(2,2,2)、(3,3,3)，虽然仍有四行，却改变模型函数。原 patch 网格与合并后网格也不能混用。

对 query 行 i、head h，令 J_{i,h} 为合法 key 行集合，ρ(h) 为 query head 到 KV head 的映射，d_k 为 key 宽度，b 为模型分数偏置：

s_{i,j,h}=q_{i,h}·k_{j,ρ(h)}/√d_k+b(i,j,h)，j∈J_{i,h}；

p_{i,j,h}=exp(s_{i,j,h}−m)/Σ_{j′∈J_{i,h}}exp(s_{i,j′,h}−m)，其中 m=max_{j∈J_{i,h}}s_{i,j,h}；

o_{i,h}=Σ_{j∈J_{i,h}}p_{i,j,h}v_{j,ρ(h)}。

不可见位置不进入分母。将 score 乘零不能保证概率为零。非空 query 遇到空可见集合时，应拒绝或执行模型明确规定的空行值，不能计算未定义的 softmax。

缓存按依赖分层。

- source_key：不可变内容、解码/方向/色彩、resize/crop/插值、归一化、帧选择及时间、patch/merge 和输入几何。
- feature_key：source_key 加 encoder、merger/projector 的权重、精度、布局及输出表示。
- prefix_key：有序特征身份、实际文本及特殊 token、视觉行绑定、模板、Π、A、decoder/adapter、KV 表示和数值契约。

原始 logits 或末隐藏状态另绑定对应前缀边界、输出头和隐藏状态所处阶段。保存末端归一化之前的隐藏状态，需要执行 FinalNorm 和 head；保存之后的隐藏状态只执行 head，不能重复归一化。经过 temperature、惩罚或 grammar 处理的概率不能当作通用原始 logits。采样状态和 RNG 归当前请求所有。

## 逐层计算：从像素到末行 logits

C 必须确定 patch 内元素顺序、权重及 bias、head 几何、窗口划分、位置变换、归一化和残差顺序、FFN、merger 归一化位置及输出头。以下展开一个明确的 pre-norm 残差程序。它是参数化算法，不能据此宣称报告已经确定所有 Qwen checkpoint 的逐条执行次序。选定模型采用 post-norm、额外门控或不同层程序时，须替换相应计算，不能只换权重。

逐行 RMSNorm 可写为 Norm(x)_a=γ_a x_a/√(Σ_b x_b²/d+ε)。SwiGLU 形式的 FFN 为 [SiLU(xW_g+b_g)⊙(xW_u+b_u)]W_d+b_d，其中 SiLU(z)=z/(1+exp(−z))。宽度、bias、ε 和计算精度由 C 固定。

```pseudocode
ALGORITHM VisionAndMerge(X, G, C)
输入：确定性预处理张量 X；有效网格 G；完整视觉与 merger 契约 C
输出：F、Z 及每行媒体/时间/空间绑定；或契约错误

1. 按 C 的时空 patch 范围及内部顺序，从 X 取得向量 u_j。
   x_j←u_j W_patch+b_patch；保留 j↔(媒体,时间片,行,列) 的双向映射。
2. 对视觉层 l=0,…,L_v−1：
   a_j←Norm_l,attn(x_j)
   q_j←a_j W_l,q+b_l,q；k_j←a_j W_l,k+b_l,k；v_j←a_j W_l,v+b_l,v
   拆分 heads，对 q、k 应用 C 的视觉位置变换；不擅自旋转 v。
   若为窗口层：
      从坐标构建有效窗口索引 I_u；每个有效 patch 恰好属于一窗。
      按 I_u 聚集 q/k/v，保持原位置及媒体归属。
      每窗、每 query、每 head 按正文公式求 o，J 为该窗允许行。
      通过逆映射将 o 写回原 patch j。
   否则：
      在 C 规定的全注意力范围求 o；媒体和时间边界仍受 C 约束。
   y_j←x_j+ConcatHeads(o_j)W_l,o+b_l,o
   x_j←y_j+FFN_l(Norm_l,ffn(y_j))
   本层全部必要行完成后，x 才成为下一层输入。
3. F←C 规定的末端归一化或恒等变换(x)。
4. 对每个时间片及合并后空间位置 (r,c)：
   按固定顺序取 F[2r,2c]、F[2r,2c+1]、F[2r+1,2c]、F[2r+1,2c+1]。
   在 C 指定位置执行 merger 归一化，拼接得到宽度 4d_v 的 u。
   z←Act_M(uW_M1+b_M1)W_M2+b_M2，输出宽度 d_l。
   按 C 的输出顺序记录 z 和合并后坐标。
5. 验证覆盖、顺序、N_v 和表示；生产及元数据完成后才可发布 Z。
```

相邻四个序列行未必是相邻 2×2 patch。行主序 2×4 网格的左侧组为 [0,1,4,5]，不是 [0,1,2,3]。窗口重排、空间合并和 placeholder 展开是三个映射，应分别核对。

decoder 新段的每层 q/k/v 来自该层新行隐藏状态；历史 KV 来自历史行在同一层的投影。当前新增 K/V 必须参加本次 attention，仅读取旧缓存会漏掉自位置和本段已经可见的行。

```pseudocode
ALGORITHM ConsumeDecoder(S[a:b], Π, A, KV[:a], C, generation)
输入：已知连续行 a…b−1；全部层已提交的只读历史 [0,a)；固定契约 C
输出：完整新 KV 前缀 [0,b)、位置 b−1 的原始 logits；或失败

1. 要求 0≤a<b；核对输入、历史身份和每层共同边界 a。
   预留全部层新增区，必要时复制共享尾页，建立私有写入空间。
   x←文本 embedding 或绑定的视觉 Z；执行 C 规定的输入变换。
2. 对 decoder 层 l=0,…,L_dec−1：
   u←Norm_l,attn(x)
   q←SplitHeads(uW_l,q+b_l,q)
   k_new←SplitHeads(uW_l,k+b_l,k)；v_new←SplitHeads(uW_l,v+b_l,v)
   对 q、k_new 按 Π 和 C 应用位置变换；旧 k 已变换时不重复旋转。
   读取视图←本层历史 KV[:a] 与本次暂存 k_new/v_new 的逻辑拼接。
   对每个新 query i 和 head h：
      J←A_l,i,h 与读取视图有效行的交集。
      因果模型中本段仅允许 j≤i，不让未来行进入 softmax。
      按正文的 score、稳定 softmax 和加权 v 公式求 o_i,h。
   y←x+ConcatHeads(o)W_l,o+b_l,o
   x←y+FFN_l(Norm_l,ffn(y))
   保存本层新增 KV、位置及表示元数据，尚不对外发布新边界。
3. h_last←FinalNorm_C(x 的最后有效行)
   logits←h_last W_vocab+b_vocab。
4. 汇合全部层 KV、布局转换及必要传输的完成依赖。
   若失败、取消或 generation 失效：不推进已提交边界，排空在途访问后回收暂存。
   否则一致提交全部层的新视图和边界 b，绑定末行输出后返回。
```

逻辑拼接可以由连续数组、页表或分块视图表达，不要求复制完整历史。本次新增 KV 仅供本次执行读取；其他消费者仍读取已发布版本。仅完成第一层不能推进请求边界，否则可能混用新旧层。

上述完整展开的是将 Z 插入 decoder self-attention 的 projector 路径，也是 Qwen2.5-VL 报告的结构。另一条 cross-attention 路径中，query 来自 decoder，源 K/V 来自视觉表示及对应层投影；固定源和投影时可构建一次、多次读取，每次 q、QK、softmax、PV 仍存在。源 cross-KV 与目标 self-KV 是两套状态，具体读取、身份和源更新边界见[交叉注意力缓存](../algorithms/cross-attention-cache.md)。不能通过替换缓存类型把 projector checkpoint 改成 cross-attention 模型。

## 请求主路径与完整 KV 命中后的生成

完整 KV 命中而没有 logits 是合法状态。若只按 n−c 选择工作，此时得到零，合法请求可能永久停滞。因果前缀长度 n>0 时，可使用全部层 [0,n−1) 的历史，重新消费最后一个已知输入行。重算从该行的文本 embedding 或原始 Z 开始，不能把末层隐藏状态当第一层输入。

原共享 KV[:n] 保持只读。逻辑截到 n−1，重算末行写入私有区；若与共享前缀共用物理尾页，复制必要旧槽或使用等价的独占布局。完成后选择新视图，长度仍是 n。直接向 KV[:n] 再追加末输入会产生 n+1 个 KV，既重复输入又改变归一化。原始末行不可恢复，或缓存缺少重算所需历史时，应退回更短可恢复前缀或完整 prefill。滑动窗口、量化组共享尺度等表示还须核对截取和恢复条件。

正确性可按层归纳：旧前缀依赖对后缀稳定，故截取历史与冷 forward 一致；末行第一层输入、位置及合法集合一致，则该层输出和新 KV 一致，再作为下一层输入。浮点归约和批形态可能导致数值差异，应按固定误差契约比较，不能直接宣称逐位一致。

```pseudocode
ALGORITHM RunVLM(r, P, C, FeatureCache, PrefixCache)
输入：有序媒体、消息、输出预算、采样及终止规则
输出：带请求和代次的输出事件、终止原因；或明确失败

1. 分配请求代次 g；取得不可变媒体快照及经验证内容身份。
   locator 未证明内容稳定时先取得并验证字节；失败返回 INVALID_MEDIA。
2. 对每个媒体查询由内容及 P/C 确定的完整 feature 身份：
   ready 条目的身份、自描述网格、顺序、表示均匹配时，恢复 Z 及绑定。
   否则执行确定性 Preprocess、验证几何，再执行 VisionAndMerge。
   若必须先预处理才能确定完整身份，则先预处理，成本账保留这项工作。
   发布前验证输入身份、全部生产完成和有效覆盖。
3. 按模板和媒体绑定构造 S、Π、A；验证段数、数量、顺序和上下文限额。
   无输入行则执行 C 的合法起始规则，不能形成合法输入则返回 EMPTY_INPUT。
   输出预算为零时提交 DONE。
4. 选择身份匹配、依赖稳定的最长完整层公共前缀，令 c 为边界。
   n←|S|；恢复只读 KV[:c]；ℓ←无。
   若 c=n 且缓存保存当前边界末输出：
      raw logits 直接作为 ℓ；隐藏状态按其归一化阶段执行必要 norm/head 得到 ℓ。
5. 请求仍活跃时选择一个后继：
   若取消或超时，转步骤 8。
   若 c<n：按合法块大小调用 ConsumeDecoder 消费 S[c:n]。
      每块完整提交后推进 c；只在 c=n 时接受末行 ℓ，不从中间块采样。
   否则若 ℓ 缺失：要求 n>0，取得全部层 [0,n−1) 历史并隔离写区。
      ConsumeDecoder 重算 S[n−1:n]，选择完整新视图及 ℓ；n、c 仍为 n。
   否则：保留当前边界 ℓ，进入采样，不重复消费末输入。
6. 对 ℓ 应用当前请求的合法 token 约束、惩罚和采样规则。
   无合法候选则明确失败；否则按当前 RNG 选择 y。
   原子提交 y、采样状态及输出序号；S 追加 y，按 C 推进位置。
   n←n+1；ℓ←无；c 不变。y 已生成，但尚无它的 KV。
   经增量 detokenization 和 stop 检测发布稳定内容，不重复发送旧事件。
7. y 为 EOS、达到输出预算或满足 stop 时提交 DONE，转步骤 8；
   否则回步骤 5，消费 y，计算它的 KV 和预测下一个 token 的 logits。
8. 停止新调度及输出提交，撤销未提交预留，保留已提交共享版本。
   在途媒体、DMA、kernel、KV 写入和读者排空后回收私有资源。
   迟到结果按 (请求,g) 丢弃，不得写入新代次槽位。
```

三种首 token 分支都有后继：部分命中消费后缀；完整命中有末输出直接采样；完整命中无末输出安全重算。EOS 或预算结束时可以保留 c=n−1 的终态，无须为不再预测的最后 token 补算 KV。保存 logits、隐藏状态或仅保存 KV 都是选择，取舍来自恢复成本和驻留费用。

## 条件化成本与资源账

设视觉宽度 d_v、语言宽度 d_l、视觉 head 数 H_v、key/value 宽度 d_k，元素字节 b_v、b_l。N_t 为全部非视觉输入行，N_o 为输出预留行，N=N_t+N_v。

视觉 attention 的 QK、PV 合计约为 2H_v d_k C_pair 次乘加；一次乘加计两次 FLOP 时为 4H_v d_k C_pair FLOPs。另有投影、位置变换、归一化、softmax 和 FFN。常规同宽 Q/K/V/O 投影约为每层 4N_p d_v² 次乘加，SwiGLU 三个线性层约为 3N_p d_v f_v，f_v 是中间宽度。merger 隐藏宽度 h_m 未由供应报告确定，其两层线性部分为 N_v(4d_v h_m+h_m d_l) 次乘加。合并减少 decoder 行数，不减少 encoder 已处理的 patch 数。

窗口聚集及还原若都物化为宽度 d_v 的独立缓冲，两次转换合计约涉及 4N_p d_v b_v 字节的读写，另计 q/k/v、残差及中间状态。融合索引读取可能消除部分物化，但必须保持映射。全 score 物化需要与 H_v N_p² 成比例的存储；分窗或分块归约可以降低峰值，成对计算计数不能直接当成常驻容量。

因果 decoder 冷 prefill，每层每 query head 有 N(N+1)/2 个可见对。已有稳定历史 c、新增 q 行时，新 query 对数为 qc+q(q+1)/2，不是 q²。完整命中无 logits 的末行恢复只有一个 query，却逐层读取 n 行 KV，还要执行单行投影、FFN、输出头、写区隔离和提交。

每 token 全层 KV 字节为

B_kv=2L_dec H_kv d_head b_kv。

7B、BF16 且忽略元数据时，B_kv=2×28×4×128×2=57,344 字节=56 KiB/token。896 行输入为 49 MiB；加 256 行预留为 63 MiB/request；8 请求该项为 504 MiB。共享前缀物理字节只计一份，私有尾部另计。页尾、隔离时的新旧尾页、量化元数据和工作区不包含在主项中。

448×672 算例的 patch 特征为 1536×1280×2=3.75 MiB，Z 为 384×3584×2=2.625 MiB，FP32 三通道像素为 3,612,672 字节，约 3.445 MiB。三者同时存活约 9.820 MiB；20 份 Z 为 52.5 MiB。F 不再需要时可以释放；仅缓存 Z 时不能把全部 F 也算成永久缓存。以上不含权重、层中间量、媒体解码缓冲、工作区和对齐，不是整模型峰值显存。

保存 raw logits 每前缀需要 V b_logits 字节，保存末隐藏状态约需 d_l b_hidden 字节。报告词表宽度为 151646；FP32 logits 约 0.579 MiB/前缀，7B 的 BF16 末隐藏状态为 7168 字节。隐藏状态方案仍需输出头计算，其线性部分约为 d_l V 次乘加；具体数值表示不能只按容量决定。无末输出方案另有恢复时私有尾部的瞬时容量。

cross 路径分别计算目标 self-KV 和各 cross 层源 K/V，源长度、层集合和 head 几何可能不同，不能直接套用 N_v B_kv。跨请求共享还要计唯一副本、访问位置和恢复传输。

## 主机路径、队列与组合轨迹

媒体获取、解码、方向/色彩、resize/crop、归一化、连续化、pinned staging、H2D、视觉计算、merge、prefill、采样和首内容发送可能位于不同执行域。CPU 提交完成不代表 DMA 或 GPU 完成。小 metadata 可能受提交和同步次数主导，大像素或 Z 更接近带宽问题；共享主存或链路上的阶段不能各自同时获得孤立测得的全部带宽。

| 阶段 | 队列计量及就绪条件 | 风险 |
|---|---|---|
| 媒体 | 字节、像素、帧数、解码工作；内容快照可验证 | 主机阻塞、locator 内容变化 |
| 视觉 | patch、视觉行、F/Z 字节；processor 和几何确定 | 分辨率长尾、布局转换、特征积压 |
| 语言 | 实际输入行、KV 字节及身份；Z、Π、A 一致可读 | prefill 干扰 decode、KV 驻留、热点、命中无 logits |

视觉批可按网格分桶，decoder 按实际 token 工作聚批。强行 padding 不同长宽比可能增加计算。阶段间携带请求、代次、媒体顺序、网格、行映射、身份及完成依赖。视觉无限领先会积累 Z；增加主机 worker 不能消除已饱和的视觉 encoder。准入覆盖新增 KV、F/Z、工作区、在途缓冲和共享尾页隔离。已选驱逐但仍被引用或 DMA 使用的对象不能算作现在可用容量。

串行设定中，媒体获取 20 ms、预处理 15 ms、视觉 encoder 35 ms、桥接 5 ms、语言 prefill 60 ms、队列合计 25 ms、首内容发送 5 ms，冷路径为 165 ms。若 feature 查询/恢复共 8 ms，且内容身份与自描述条目允许预处理之前命中，省去预处理、视觉及桥接 55 ms，则为 118 ms。必须先预处理再查完整身份时为 133 ms。只有不可变内容登记允许跳过媒体获取时，才可再减 20 ms。这些是串行设定值，不是 CPU/GPU 实测。

完整 prefix hit 有 raw logits 时可省主体 prefill；无末输出时需加 T_tail。维持 118 ms 例中其他项目，假设前缀查找无额外费用、亲和路由增加 30 ms 排队，则分别为 88 ms 和 88 ms+T_tail；实际前缀查找、恢复、采样及同步另计。流水可以跨请求重叠，但单请求依赖、共享带宽及首尾排空仍存在，不能任意取阶段最大值代替 TTFT。

沿一次组合轨迹检查状态。

1. A 的 448×672 图片形成 384 行 Z，与 512 个非视觉行构成 896 行 prompt。feature 和全层 896 行 KV 已发布，不保存末输出。
2. B 使用同图但修改图片之后的问题。feature 可以命中；prefix 仅复用实际行、位置和可见性都相同的公共范围，不能复用 A 的完整 KV。
3. C 使用与 A 完全相同的 prompt，初态 n=c=896、ℓ 缺失。每层取 [0,895) 只读历史，隔离私有末行，必要时复制尾页有效槽。重算位置 895 后长度仍为 896。
4. C 选择并提交 y_1 后 n=897、c=896，y_1 尚无 KV。继续生成须消费位置 896 的 y_1，使 c=897，再选择 y_2；y_1 已终止时无须消费。
5. 在末行 kernel 已提交后取消 C，只撤销后续提交资格。A 的共享版本继续有效，C 的复制源引用及私有目的保护到最后访问结束，迟到结果不能发布到新代次。

该轨迹把特征与前缀身份、logits 恢复、共享写隔离、采样及回收接到同一边界。仅有命中率无法判断正确性或收益。

## 条件变化后的保留、调整与放弃

| 条件变化 | 可保留 | 调整或放弃的原因 |
|---|---|---|
| 同媒体、改后置问题 | 身份一致的 Z | prefix 从首个不同实际行起失效，还须核对位置与 mask |
| 改前置文本或模板 | 媒体及可能相同的 Z | decoder 输入、位置和前缀依赖改变 |
| 改 resize/crop/插值/方向/色彩 | 原媒体 | X 改变，相关 F/Z 和 KV 失效 |
| 提高空间分辨率 | 权重 | 重算 N_p/N_v、窗口边界、全注意力项和 KV |
| 改抽帧、时间戳、时间分组 | 原视频 | 时间输入、位置和特征身份改变 |
| 改 encoder/merger/adapter/表示 | 不受影响的原始输入 | 沿实际依赖闭包失效，不按文件名推断 |
| 完整 KV 命中但无末输出 | 可恢复的合法历史 | 增加末行恢复，不能直接跳到采样 |
| 高频完整命中 | 正确缓存内容 | 比较 logits、隐藏状态和重算的容量及恢复成本 |
| 特征恢复比重算贵 | 内容身份 | 改放置、限制缓存或重算，命中不保证加速 |
| batch 或并发增大 | 单请求函数 | 重算 padding、工作区、KV 峰值、等待和公平性 |
| 容量逼近上限 | 已发布合法版本 | 等待、拒绝、驱逐或重算；降分辨率改变质量 |
| projector 换 cross 模型 | 可证明相容的原始对象 | 桥接函数和两套 KV 改变，不是纯缓存优化 |

高命中、内容稳定且视觉阶段支配成本时，Z 缓存可能有效；高分辨率低重用时，预处理、视觉计算与准入更直接。prefix 亲和排队超过省下的计算时，重算或复制热点可能更快。主机 resize 支配 TTFT 时扩大 decoder batch 不解决该阶段；长历史 KV 读取支配 ITL 时，仅优化视觉 encoder 不改善稳态 decode。

## 区分实验、负对照与验证范围

先记录同一请求的内容验证、预处理、H2D、视觉、merge、prefill、末行恢复、采样和输出事件，区分排队与执行。以下设备和任务实验是设计，尚非实测结论。

| 观察 | 竞争解释 | 区分改变及预测 |
|---|---|---|
| 完整命中后无首 token | 无 logits 分支遗漏、容量等待、ready 未完成 | 固定 KV，只改变是否保存末输出；遗漏分支在 c=n、ℓ 缺失时没有后继 |
| logits 不同或 KV 多一行 | 重复末输入、位置错、共享写覆盖 | 对照完整 forward 的 logits 和全层 KV；安全恢复长度为 n，重复追加为 n+1 |
| 视觉结果错位 | 未还原窗口、连续四行误作 2×2、媒体交换 | 用可区分 2×4 patch 网格及两图，分别检查空间与媒体绑定 |
| TTFT 高 | 主机、H2D、视觉、prefill、排队 | 固定文本改分辨率，固定图像改文本长度，同时记录阶段字节和事件 |
| feature hit 无加速 | 仍取媒体、未跳预处理、恢复贵、prefix miss | 分别改变内容登记、Z 恢复和 prefix 复用，收益应落在对应阶段 |
| 窗口注意力没更快 | 单窗小图、全层二次项、布局或 launch 开销 | 跨窗口边界改变几何，对照成对计数、转换流量和视觉时间 |
| 缓存后质量下降 | 内容碰撞、processor 或 MRoPE 错 | 同 locator 换内容、同形状换 crop、压平位置，正确身份应拒绝 |
| 取消后污染或泄漏 | 在途未排空、代次错、共享写 | 在 H2D、视觉和末行恢复期间取消，保持邻居继续读取 |

负对照应经过实际推进或映射路径。遗漏无 logits 恢复时，让调度选择真实返回无动作，再由“有预算、未取消的合法请求必须有后继”不变量检测；不能在故障分支主动抛异常后把异常当成已经检出停滞。重复追加由边界和完整 forward 对照检出。遗漏当前 KV、窗口逆映射或空间分组则由独立可见集合、坐标参考及数值结果检出。

配套 stdlib 检查使用确定性 CPU 小模型：两层 pre-norm、两个 query heads 共用一个 KV head、三轴旋转、稳定 attention、残差、门控 FFN 和输出头。dense 全序列参考显式构造合法集合；缓存路径用历史 KV 和在线 softmax 累积，比较所有层 KV 与 logits。视觉 dense mask 参考对照窗口聚集和逆映射；坐标字典参考对照空间 merge。生成覆盖所有部分前缀、完整命中有/无 logits、归一化前隐藏状态缓存、单行、末行为视觉行、零预算和 EOS。共享线性、归一化及投影原语不属于两路独立验证范围。

该脚本交付后仍需按本轮确切字节执行和独立审阅。历史版本的批准不自动覆盖本轮修改。检查不是 Qwen 权重或 processor 的兼容性基准，不验证精确 MRoPE 接口、视频尾帧、随机采样、grammar、跨 token stop、物理写时复制、异步取消、DMA、GPU 可见性或性能。

视觉质量另需 OCR 内容与区域、计数、图文绑定和定位标注。定位先将模型坐标经 resize/crop 逆变换回原图，再算 IoU 或点命中。纯文本回归和语言流畅不能替代视觉正确。性能报告区分冷/热、feature/prefix hit、末输出保存方式、各阶段排队、峰值、TTFT/ITL，并注明媒体获取和首内容发送是否包含。CPU 模型、目标设备结果与 Agent 使用效果分别成立。
