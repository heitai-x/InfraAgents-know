# InfraAgents 专家知识库

这套知识用于帮助 Agent 还原模型与系统的工作方式，从任务条件推导架构并实现完整服务。正文以计算依赖、状态表示、资源成本和跨机制组合为主，包含公式、布局、状态关系、数值算例和源码映射。

从 [系统设计推导](system-semantics/design-synthesis.md) 阅读四种完整场景，再由 [设计入口](DESIGN.md) 进入当前任务涉及的机制。[主题索引](INDEX.md) 列出全部 73 个专题，[问题入口](DIAGNOSIS.md) 从实际行为回到对应机制，[覆盖矩阵](COVERAGE.md) 将 VibeSys 参考集的 73 个文件逐项对应到本库。

本分支保留完整 base，不绑定某个模型的知识截止日期。时间约束内容由独立分支承载；选择规则见 [使用说明](../docs/USAGE.md)。

## 知识的组织

模型结构决定状态；算法选择决定状态如何更新、复用和分配；硬件与框架决定这些关系怎样执行；负载和协议决定用户体验。八类目录保留这些阅读角度，每个专题通过关联链接连接其他层。

正文不限定行数，也不使用统一短卡。基础机制可以用代数展开，缓存适合布局和生命周期，平台适合数据流，引擎索引将机制连接到固定版本源码。诊断与验证从机制的可观察结果自然导出。

## 当前内容

算法 15、模型 12、硬件 9、框架 10、引擎 5、工具 6、负载 6、系统语义 10。覆盖文本、MoE、MLA、SSM/混合、视觉语言、语音、图像/视频扩散和全模态，以及 CUDA、ROCm、Metal、Trainium、CPU。范围是模型推理系统的设计与构建；训练与集群运维并非本轮参考集的主题。

内容独立撰写，VibeSys 提供覆盖基线与比较对象。原论文、官方文档和固定版本源码在 [来源登记](SOURCES.md) 中逐项标明。正文算例是可复算的推导；原微型 CUDA 案例只支持其中明确引用的观测。扩写后的完整专题统一作为来源知识 seed，旧版与原证据保留。

## RSI 如何继续积累

规划读取完整相关章节并推导设计，代码执行将关系落实为目标系统，诊断检查模型语义与机制预测，进化把新增理解写回受影响的章节。修订精确替换或新增二级章节，未受影响的公式、表格与论证保留。争议或弃用保留完整原文，后续任务继续修正理解。

知识正文只使用非代码表达；实现、命令和原始 trace 留在工程或运行产物中。目录、版本和证据维护支持知识积累。内容标准见 [写作约定](templates/entry.md)，运行接口见 [RSI 使用](../docs/12-knowledge-rsi.md)。

正文与“来源与推导”构成本地阅读链：来源条目提供已核对的机制、定义和本库推导关系，原始网址仅作出处元数据。运行中的来源说明随知识快照保存，无需通过 WebSearch 补全本文。

完整源资料已实际归档：论文PDF、网页正文与图片、固定版本源码均可本地读取。来源说明同时链接原文与全文文本，详见 [完整原文索引](../references/index.html)。
