# K-MODEL-003：MoE 的激活计算量与驻留代价分开判断

状态：一手来源种子，未在本项目实测。版本：1。

## 核心认识

稀疏专家模型只激活部分专家，但总权重驻留、路由不均衡及通信仍可能主导资源需求。

## 适用条件

已明确专家数、路由方式、token 分发和专家放置的 MoE 模型。不同模型的选择与合并语义须按原定义。

## 机制与取舍

每个 token 的专家选择可以不同，因此平均激活量不能解释最忙设备。跨设备分发还依赖通信与同步组织。

## 诊断线索

按专家和设备查看 token 数、等待、分发及合并阶段，核对 token 返回后是否仍对应原请求与位置。

## 验证依据

覆盖分布不均的输入并对照参考路由和合并结果，检查最慢 rank 对整步耗时的影响。

## 反例与边界

激活参数少不等于只需要同等大小显存；平均负载均衡也可能隐藏单次批次热点。
