# K-TOOLS-002：从时间线摘要回到原始事件

状态：一手来源种子，未在本项目实测。版本：1。

## 核心认识

聚合热点用于选择调查入口，具体因果解释需要原始区间、进程身份及相关调用的证据。

## 适用条件

拥有原生时间线或 SQLite 导出，采集范围、时间轴和可用信号已记录。

## 机制与取舍

累计 kernel 时间、主机 API 时间和端到端时间可能重叠。一个关联编号只在其正确作用域内有意义；窗口外的提交也可能对应窗口内设备事件。

## 诊断线索

先检查缺表、未完成区间与过滤窗口，再查身份、时间戳和多个关联候选。检查摘要时保留继续读取原始行与查询的方法。

## 验证依据

对小窗口重算并回查原始事件，与原生统计核对次数及口径；用未插桩结果判断采集是否改变被研究的行为。

## 反例与边界

排队时间不必然是坏事；单进程未覆盖区间不是整台 GPU 空闲，关联也不自动建立完整关键路径。
