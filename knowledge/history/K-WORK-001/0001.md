# K-WORK-001：TTFT、TPOT 与流式响应的事件定义

状态：一手来源种子，未在本项目实测。版本：1。

## 核心认识

性能指标必须绑定起止事件和统计单位；一个网络响应块不一定只含一个 token。

## 适用条件

文本生成或流式输出服务，客户端与服务端的时间口径、token 计数和结束规则已明确。

## 机制与取舍

首个响应、首个有效 token、逐响应间隔、按 token 归一的时间和整个请求时间是不同量。汇总每请求结果和汇总每 token 结果也会赋予长请求不同权重。

## 诊断线索

检查首个空块、多个 token 合并发送、缓冲刷新及最后一个响应的处理，区分生成停顿与网络发送停顿。

## 验证依据

保存原始事件时间与 token 数，按事先定义重算分位数，并说明采样边界、单位和失败请求处理。

## 反例与边界

不能把音频块延迟直接称为文本 TTFT，也不能只用总耗时除输出数替代所有逐步延迟约束。
