# K-ALG-022：非前缀上下文复用：依赖、位置与选择性重算

同一段文本在两个请求中出现，只能证明输入内容重复。它在某层产生的状态还取决于可见上文、位置规则、模型与 adapter，以及数值表示。非前缀复用需要先判断这些依赖是否保持一致，再决定采用精确恢复、位置变换、选择性重算还是完整 prefill。

## 一段文本有多种可以缓存的对象

分词结果、独立文档 embedding、检索结果、decoder 的逐层 KV 和最终回答，依赖范围不同。固定 tokenizer 下的文档 token 可以独立保存，但拼接后的分词边界仍须核对；独立编码的文档 embedding 可以按其编码函数复用。这些性质不能传递为 decoder KV 的独立可组合性。

固定一次前向的条件记为 η，包括模型及权重、adapter、实际 token 序列、位置编码、可见性、前处理与数值合同。令 x[0:N) 为已知输入，第 i 层位置 j 的输入隐藏状态为 h_i[j]。对普通因果 decoder，attention 可以读取位置 0…j；窗口、外部特征和递归状态改变了依赖图时，应使用模型自己的可见集合与恢复合同。

将输入写为 A、B、Q，分别表示两段材料和查询。普通逐位置前处理与 RoPE 模型中，第一层旋转前 Q/K/V 可以只依赖当前位置的 embedding；经过该层 attention 后，B 的隐藏状态已经吸收允许看到的 A。第二层及更深层 B 的 K/V 因而通常依赖 A。把 B 放到同长的 C 后面，即使 token 和位置相同，也不能推出其深层 KV 相同。

需要区分三种目标：同一完整函数的数值一致；某个明确误差合同；任务质量达到阈值。实数等价也不自动保证浮点逐位一致。选择性重算通常属于需要任务质量验证的近似，不能用少数回答相同证明任意输入精确。

本章融合算法的输入包括 η、实际拼接后的 token、片段版本与顺序、缓存覆盖、原位置与目标位置、缓存表示、强制计算位置和选择预算。输出是当前请求的逐层 fused KV、保留行的隐藏输出或末行 logits、每层选择集合和就绪责任。缓存独立构建时若增加了 BOS、模板或分隔符，这些 token 也属于依赖，不能仅靠删除描述中的长度消除其影响。

## 精确复用需要满足依赖条件

精确前缀复用要求 η、完整前缀、位置与数值合同一致，并且后续执行需要的所有状态都已完成。混合模型还需要递归检查点与窗口状态对应同一个恢复位置。索引命中、物理范围存在、数据已到达和消费者可读取是不同事实。

若参考模型明确隔离片段之间的可见性，独立片段状态才可能在该函数下精确组合。人为关闭跨片段 attention 改变了参考函数。对原有全因果模型直接拼接独立片段 KV，只能作为近似候选。

RoPE 修正的是位置坐标。对一个二维通道对，定义

R(φ)=[[cosφ,−sinφ],[sinφ,cosφ]]，

R_{Θ,p}=blockdiag(R(pθ₁),…,R(pθ_{d/2}))。

若旋转前 key k 确实相同，则旧位置 p 的 K_p 可变换到目标位置 p′：

K_{p′}=R_{Θ,p′}R_{Θ,p}ᵀK_p。

固定频率时也可直接旋转角度差 p′−p。对于 q_a=R_{Θ,a}q、K_b=R_{Θ,b}k，有

q_aᵀK_b=qᵀR_{Θ,b−a}k。

每个二维对的展开包含两个部分：同维乘积之和乘 cosφ，以及 (q₂k₁−q₁k₂)sinφ。省掉后一项会改变函数。令 q=(1,0)、k=(0,1)，query 旋转 π/2、key 不旋转，正确点积为 1；只对分量乘 cos 得到 0。只测范数也不能证明旋转方向和相对内积正确，因为反向旋转同样保持范数。

位置搬移需要相同的频率、缩放、旋转维度和通道配对布局。普通 RoPE 不因此要求旋转 V。旋转前隐藏状态因上文改变时，搬移旧 K 不能生成新隐藏状态，旧 V 也可能已经错误。若频率依赖当前长度，不能无条件使用固定角度差公式。量化 K 还需要明确解码、旋转及可能的重新编码；正交关系不会消除表示误差。

| 路线 | 合法前提与结果 |
|---|---|
| 精确前缀复用 | 依赖、表示和恢复点一致，取得同一后续计算所需状态 |
| 隔离片段组合 | 参考函数本身禁止相应跨片段依赖，组合只对该函数成立 |
| RoPE 搬移 | 旋转前向量与位置合同一致，只恢复坐标关系 |
| 选择性重算 | 部分行有合法隐藏输入，其余位置有可读缓存；结果按近似合同验证 |
| 直接全 KV reuse | 保留独立片段状态，缺少的跨片段依赖必须作为近似损失评估 |

## 选择性重算如何连接缓存与当前输入

CacheBlend 固定 v1 的部分更新机制是：当前层仅计算选中行的 Q/K/V，其余 K/V 沿用缓存；选中 query 仍与该层全部合法可见 K/V 做整体 attention，再计算这些行的下一层隐藏输出。减少的是 query 行与逐位置网络计算，并没有将合法 key 集合缩成选中集合。

令 C 为有合法独立缓存的位置，U 为查询、未命中材料及其他必须新算的位置，C 与 U 不重叠，二者覆盖输入。固定强制集合 M，要求 U⊆M，且需要生成时末行 N−1∈M。第 i 层选择集合为 S_i，保持 M⊆S_i 和 S_{i+1}⊆S_i。已经丢弃的行缺少下一层新隐藏输入，不能凭一个索引重新加入；扩张需要另行保存或补算依赖。

选择信号必须在线产生。特别是只用普通 embedding 与逐位置前处理的首层，位置校正后的新旧 K/V 可以完全相同，而首层 attention 输出已经不同。此时按首层 KV 偏差筛选，会按任意平局顺序丢掉尚未观察到的深层依赖。

下面给出一个明确的渐进筛选实例。前 e 层完整计算所有位置，再开始缩小；对上述结构，e 至少取 2 才可能从 K/V 看见首层 attention 引入的变化。e=2 只解决信号产生的时序，不保证足以识别任务关键行。更深探测、不同信号或保持全量都是可选方案；应依据模型与质量验证选择，不能把论文示意中的首层观察直接作为普遍保证。

比较偏差前先把旧 K 转到目标位置并使用同一表示单位。一个具体评分是 d_i[j]=||K新_i[j]−K旧_i[j]||₂²+||V新_i[j]−V旧_i[j]||₂²，沿该 token 的全部 KV head 和通道归约。本例使用未加权平方和；不同尺度、量化或模型可能需要其他评分，不能将其当作任务重要性的定理。强制位置没有旧缓存时，不参与偏差排序。

```pseudocode
输入：η、x[0:N)、缓存位置 C、新算位置 U、固定强制集合 M
      H 层缓存与原目标位置映射、探测层数 e、后续总行预算 k_i
输出：私有 fused KV、选择轨迹及所需输出，或明确失败

核对所有依赖、缓存范围、格式与权限；要求 H≥1、1≤e≤H
生成任务要求合法非空输入及 N−1∈M；仅恢复空状态可返回空结果
要求 C 与 U 不重叠且覆盖输入，U⊆M；初始化 S_1←{0,…,N−1}
取得公共源读保护，预留私有输出、转换与在途缓冲；不足则不提交

对 i=1…H：
    等待本层缓存实际到达、转换完成并对本层消费者可见
    将 C 的旧 K 按声明合同校正到目标位置；旧 V 按其表示读取
    对 j∈S_i：取得 h_i[j]
        首层来自实际 embedding；其他层来自上一层为同一位置计算的输出
    按模型真实顺序做前处理、Q/K/V 投影和位置操作
    建立私有本层 K/V：S_i 用新值，C 中其余位置用校正后的旧值
    核对每个合法 key 位置均有 K 和 V，且无缓存空洞
    对 j∈S_i：
        对模型规定的全部可见 key 计算分数
        在完整可见集合上归一化，计算 PV 和该层剩余网络
        保留 h_{i+1}[j]，使下一层输入可得
    若 i<H：
        若 i<e：S_{i+1}←S_i
        否则：
            要求 |M|≤k_{i+1}≤|S_i|；预算不足不能删除强制位置
            对 S_i∩C 中非强制位置计算 d_i
            按偏差递减、同分按逻辑位置递增排列候选
            S_{i+1}←M 加入前 k_{i+1}−|M| 个候选
全部必要层、输出和描述完成后，复核请求提交资格，再共同发布
失败或取消：不发布部分融合快照；停止新提交，排空已有读写后释放私有责任
```

预算 k_i 表示包含 M 的总行数。如果产品只给材料重算比例，应先换算为材料候选数，再加查询和未命中行，不能让两种分母混用。偏差全零时，上述平局规则仍可执行，但只能得到一个确定候选，不能声称选择具有质量依据；可提高探测深度、扩大集合或回到全量。

当每层 S_i 都是全体位置时，所有旧缓存均被新值替换，算法退化为同一数值合同下的完整 prefill。这是重要参考边界。单 token 输入没有跨片段依赖；全新输入使 M 覆盖全部位置，无法靠本算法省掉其逐位置计算。完整命中 KV 但没有末行 logits 时，必须保留安全的末行计算路径；仅恢复 KV 不会自动给出下一 token 的分布。

高偏差不必意味着高任务重要性。否定词、跨材料实体对应和一个关键数字都可能在数值偏差较小时改变答案。嵌套保证输入依赖可执行，不保证缩小集合后误差单调改善，也不保证提高某一层预算就能恢复此前已经丢弃的行。

## 多层缓存的状态与所有权

独立片段缓存与某次请求的融合结果是不同对象。公共 B 表示在其原始构建条件下得到的状态；A→B→Q 的融合结果还依赖 A、顺序、目标位置、探测与选择轨迹。将后者覆盖回公共 B，会污染下一次 C→B→Q。若确需缓存组合结果，应使用完整组合身份，并保留其近似策略身份，防止精确前缀路径误读。

从逻辑到物理的路径应完整：先由全局位置 j 找到片段及片段内偏移，再由源页表定位旧 K/V、尺度和有效范围；目标位置决定 RoPE 与因果 mask；私有目标页表决定写入地址。不能把压紧后的第几个 query 当作原始绝对位置。选中位置可能是 {1,5,9}，它们仍分别使用位置 1、5、9 的可见集合，而不是长度三的局部三角 mask。

可以完整复制每层缓存到私有目标后覆盖选中行，也可以用只读公共页加私有补丁映射。前者多付整层复制与驻留，后者要求消费者理解混合映射，并对页内部分修改做 COW 或等价隔离。两种路径都不能让公共页承担请求特定的旋转或部分更新写入。

| 事件 | 仍然有效的对象和责任 | 下一步 |
|---|---|---|
| 取得 B | 公共源的身份、代次、范围及读保护有效；私有目标尚不可消费 | 加载与位置转换 |
| 第 i 层融合完成 | 本层私有 K/V 完整，S_i 的输出可供下一层使用；其他层尚未完成 | 计算选择并等待下一层数据 |
| 下一层加载途中取消 | 公共 B 不变，旧已提交请求快照仍有效；已提交 I/O、转换和设备读写仍持有范围 | 停止新工作，保持在途缓冲直到排空 |
| 排空后回收或全部成功发布 | 取消路径释放私有责任；成功路径共同发布完整 fused 视图和输出 | 按最后实际使用结束源保护 |

目录引用、请求映射、实际异步读者和构建写者是不同拥有责任。逻辑请求结束不能替代最后物理访问完成；迟到通知按原对象和原分配代次结算。代次检查不能阻止已经发出的旧 DMA 写入新对象，因此物理范围必须先排空再复用。

KV 量化会改变偏差排序，历史裁剪会改变合法可读集合，片段融合又引入上文近似。分别通过三种机制不能证明组合质量通过。裁剪后如果本算法所需 key 已不存在，应按新近似函数评价或恢复缺失状态，不能继续声称只省了投影计算。

## 计算与传输要分别记账

令 H 为层数，N 为全部输入长度，第 i 层选择 r_i=|S_i| 行。对普通因果 attention，定义 E_i=Σ_{j∈S_i}(j+1)，它是每个 query head 的合法 query-key 对数。选择靠前和靠后的相同行数会产生不同工作量，r_iN 只是一个上界。

对 H_q 个 query head、key 宽 d_K、value 宽 d_V，QK 与 PV 的主项约为 2H_q(d_K+d_V)E_i FLOP，另有 softmax 与归约。投影、输出映射与 MLP 的逐位置计算大致随 r_i 增长，但小矩阵效率、固定权重读取和提交成本不会自动同比下降。前 e 层全算的成本必须计入，不能把所有层都按最终比例折算。

旧缓存加载量主要取决于 C，而非 r_i。唯一 KV 字节、各 query 块的逻辑请求和实际 HBM 事务是三个量；分块重读、GQA 共享、cache 命中与不规则 gather 会改变它们。完整复制私有目标还要增加旧布局读与目标写；位置旋转至少读取并生成涉及的 K。偏差计算要读取新旧 K/V；排序可用 O(r_i log r_i) 的直接实现，选择索引、布局与稳定平局处理也有准备成本。

对同宽高精度 KV，一个 N token 序列的有效容量为

D=2HNH_kvds 字节；

不同宽度时为 D=HNH_kv(d_K+d_V)s，其中 s 是每元素字节数，H_kv 是 KV head 数。物理复制、TP/PP 落点、量化参数、页尾与元数据另计。H=32、N=8192、H_kv=8、d=128、s=2 时为 1 GiB；仅有 3072 个缓存 token 时为 384 MiB。材料重算比例下降不等于完整 fused KV 容量下降。

对上述 8192 token 设定，每层完整 KV 是 32 MiB。若私有融合输出保留全部 32 层，需要 1 GiB；另建两个完整层的 staging 缓冲又需 64 MiB。只有实际让 staging 与目标范围共用，并证明最后读者结束后的复用次序，才能扣掉这部分。公共缓存、请求映射与读者指向同一物理页时只计一份；主存与显存中的不同副本则分别计量。

公共片段预计算还要支付离线 prefill、序列化、校验和存储。按独立片段长度 n_c 计算，attention 工作与 Σn_c² 有关；后续复用次数决定准备成本能否摊销。为了不同格式保存多份缓存，会增加离线计算和驻留，不能只报告在线命中收益。

加载与计算可以流水，但依赖和资源必须成立。令 a_i 为第 i 层加载及进入可消费表示的时间，c_i 为本层计算与下一层选择时间。独立串行加载器、独立计算器和足够缓冲下，设 A₀=C₀=0，则

A_i=A_{i−1}+a_i，C_i=max(A_i,C_{i−1})+c_i。

完整理想时间为 C_H。各层相同时才简化为 a+c+(H−1)max(a,c)。H=4、a=6 ms、c=2 ms 时为 26 ms，串行 32 ms；c=9 ms 时为 42 ms，串行 60 ms。加载不能隐藏比自身更慢的稳态计算，即使 c≤a 也仍有启动与收尾。探测层完整计算使 c_i 不同，应使用递推式。

若同一 SSD、PCIe、DRAM、HBM 或设备执行资源发生竞争，a_i、c_i 会受并发影响；缓冲不足还会阻塞加载器。只把两段独占测量取最大值，不能证明真实重叠。跨卡执行还要计入选中隐藏行的必要 collective、选择集合一致性和实际 KV 分片传输；普通单卡公式不能证明这些成本随比例线性缩小。

| 成本 | 本路径需要计入的内容 |
|---|---|
| 计算 | 探测、部分投影与 MLP、完整可见 attention、偏差、排序和位置变换 |
| 访存 | 缓存读取、私有复制、gather/scatter、尺度和索引、临时隐藏输出 |
| 通信 | 存储或远端载荷、辅助参数、控制消息及并行执行需要的通信 |
| 准备 | 独立片段预计算、身份检查、布局转换、预算规划与选择校准 |
| 同步 | 保护与准入、层数据可见、上一层输出完成、共同发布与取消排空 |
| 驻留 | 公共副本、完整 fused 输出、旧读者、在途缓冲、索引和工作区的物理并集 |

## 条件改变后的方案反转

候选应从同一输入与身份已经确定时，计到同一质量合同下的首个输出。精确前缀恢复、非前缀融合和完整 prefill 都要包含查询后缀及其对历史的 attention。检索与重排已经完成时可比较模型侧 TTFT；声称用户端 TTFT 则还要计入此前的 RAG 阶段。

| 条件变化 | 保留的关系 | 调整或放弃依据 |
|---|---|---|
| 前缀完整相同 | 因果依赖允许精确复用 | 核对末行输出、共同恢复点与就绪性 |
| 同片段换前序或换顺序 | 文本仍相同 | 深层状态依赖改变，重新融合或全算 |
| 仅目标位置改变 | 固定 RoPE 合同下可搬移坐标 | 旋转前状态不同仍须处理上文误差 |
| 首层偏差全零 | 评分计算可以正确而无区分力 | 推迟筛选、换信号或保留全量 |
| 查询或未命中材料增多 | 强制集合不能删除 | 总行预算与成本下界增加，可能失去收益 |
| 带宽下降、缓存变远 | 原合法状态仍可恢复 | 加载与排队可能超过重算，重新比较完整关键路径 |
| 模型、adapter、位置缩放改变 | 旧制品仍有原身份 | 建立新身份或重算，不能只换描述 |
| 量化、裁剪或布局改变 | 原逻辑位置仍须正确绑定 | 重校准排序、组合质量与消费者成本 |
| 跨材料依赖或答案精度要求增强 | 部分更新仍可执行 | 扩大探测与重算；质量不达标则放弃近似 |

材料短、精确前缀命中高、设备完整重算快或离线制品复用很少时，融合的加载和准备可能超过节省的计算。长材料、非前缀复用高、传输可与计算重叠且质量允许时，选择性重算才有潜在优势。论文经验比例不能作为本章默认保证；选择反转应由相同质量约束下的完整成本决定。

## 区分实验、负对照与验证边界

先固定 η、材料、顺序与查询，建立完整 prefill 参考。分别检查独立片段、位置校正、逐层融合及最终 logits，定位首次分歧。覆盖 A→B 与同长 C→B、A→B 与 B→A、位置偏移、否定修改、跨片段指代、不同 adapter、缓存缺失和加载失败。固定输入比较数值，另做真实自回归及任务质量评估，避免将两路已经生成不同 token 后的全部差异归为同输入执行误差。

选择策略实验固定实际总预算与强制集合，比较确定性随机选择、偏差选择、离线 oracle 和完整重算。oracle 使用完整逐层状态，不能进入部署路径。若随机与偏差选择表现相同，当前信号不足以解释收益；若 KV 偏差下降而答案退化，应修改任务重要性假设，而非继续用局部偏差宣布质量通过。首层零偏差、第二层非零偏差的受控例子，可以直接检查筛选是否早于信号产生。

| 观察 | 竞争解释 | 区分实验与反证后的修正 |
|---|---|---|
| 全量选择仍与参考不同 | 位置、mask、逻辑映射或融合写入错误 | 固定全体 S_i，对照全部层 K/V 与输出，先修执行 |
| 缩小集合后错误 | 上文近似、筛选信号弱或强制行被删 | 分别提高探测深度、保持预算换策略、强制保留输出行 |
| 相同行数耗时不同 | query 绝对位置、gather 或 kernel 效率不同 | 固定行数改变位置分布，记录 E_i、事务与完整调用时间 |
| 高命中却 TTFT 不降 | 未真正跳过计算、加载/转换主导或查询阶段主导 | 分别记录完成行数及各阶段，固定材料改变查询长度或存储位置 |
| 单独加载和计算快，融合慢 | 共享资源竞争、缓冲阻塞或选择同步 | 固定字节与集合，改变重叠和缓冲，检查时间线及峰值 |
| 仅并发请求出错 | 公共页被改写、描述错位或提前回收 | 固定数值路径，隔离写区并延迟旧读者，核对实际消费身份 |

负对照必须确实违反目标条件。例如 S₁={0,4}、S₂={1,4} 在保留强制位置 4 的同时引入新行 1，违反嵌套；S₁={0,4}、S₂={0} 则保持嵌套却删除强制位置 4。相反，S₁={0,1,2,4}、S₂={1,4} 且每层强制集合都是 {4}，是合法输入，不能期待校验器报错。必须同时测试合法输入被接受和违规输入被拒绝，避免把测试构造错误误报为算法失败。

随章检查交付为 tools/check_k_alg_022_full.py。它用独立稠密公式对照标量部分更新模型的全量边界，检查未选中 key 仍参与 attention、缺少跨片段更新会改变深层输出、首层与第二层信号差异、选择嵌套及强制集合。另检查 RoPE、容量、理想流水与嵌套数组的私有写入。刻意删除校验规则的变体会接受对应违规输入，用来验证负对照具有区分力。各项观察只在实际断言完成后打印，不能提前打印 PASS。

这些是确定性 CPU 标量、集合和事件模型，不是 Transformer 模型或 GPU kernel 实测；不证明目标设备内存可见性、异步排空、HBM 事务、真实通信、任务质量或 Agent 使用效果。Python 脚本是否真正执行，以协调者执行记录为准。本轮作者实际运行的是对应机制的内存 JavaScript 模型，不将其表述为交付 Python 已通过。
