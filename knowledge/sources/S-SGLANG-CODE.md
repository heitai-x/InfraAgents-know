## 来源支持的机制与算法

Radix 匹配同时依据 token 序列和附加命名空间；不同命名空间不共享路径。按页处理时，匹配长度先按该实现的页粒度收缩。匹配落在边内部可切分节点，插入也可细化共享边界。活跃路径的引用会改变受保护与可淘汰容量。

```pseudocode
以 token 前缀和命名空间查找最长匹配，必要时切分边
沿将消费的路径增加保护，使仍在使用的祖先状态不可被淘汰
计算并插入新状态，在共享和分叉处维持 token 到物理状态的对应
请求结束后沿路径撤销其保护
需要容量时从可淘汰叶子按策略回收；祖先成为无子节点且无保护后才进入候选
```

引用保护、物理状态分配和逻辑匹配是独立责任。它展示树的一种组织方式，不证明所有模型都能仅凭最长 token 前缀恢复，也不要求其他实现采用树。
