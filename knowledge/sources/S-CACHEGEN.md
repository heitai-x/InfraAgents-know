## 适用边界

固定 v1 的 TTFT 排除检索选择阶段，编码在离线完成；量化有损而熵编码无损，不能称整条管线无损。其在线估计假设已知带宽/RTT、简化网络模型，未覆盖强带宽波动；自由文本生成与超大模型未充分评估。缓存恢复后仍需计算新 query 对历史的 attention，Cprocess 仅依赖 prompt 长度的经验式不是通用成本函数。多文档独立KV不能因此被视为精确可拼接。概率分布的共享范围在设计段和实现段表述不同，具体格式必须明确实际编码模型和版本；正文不采用简化背景中的近常数 decode 或 token 一字节假设。
