| [K-WORK-008：弹性服务：启动延迟、可用容量与排空](elastic-serving.md) | v1 · seed | 扩缩容要以实际就绪容量和启动/排空延迟解释队列；冷启动流量、故障余量与状态所有权决定策略是否可行。 |
