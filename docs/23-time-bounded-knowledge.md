# 时间边界与知识分支

main 保存完整 base，未激活模型时间 profile。它保留原始来源版本与其适用范围，不能把这个分支当作某个模型训练截止日前的材料。

[gpt-6-astra-2026-04-30 分支](https://github.com/heitai-x/InfraAgents-know/tree/gpt-6-astra-2026-04-30)承载按内容整理后的日期版本：73 个专题、76 项固定来源。原严格过滤只开放少数专题的旧报告，不作为这个新版本的结果。

日期版本的预置外部来源遵守知识与模型上限的交集。论文使用实际归档修订版的日期；固定源码使用提交时间；厂商资料使用版本化归档及其日期依据。抓取、编辑和运行观察时间分别记录。

Git 提交时间是版本时间证据，不是独立的公开分发时间证明；知识截止日期也不能证明某条内容实际进入了模型训练。新版本的具体决定和编辑差异保存在该分支的 VERSION.json 和 docs/evidence/ 中。

新运行观察仍保留实际 observed_at，经独立复核后可以形成 learned 修订；它不被倒写为预置 base，也不允许引入被当前时间视图排除的外部来源。具体使用与验证命令见 [使用说明](USAGE.md)。
