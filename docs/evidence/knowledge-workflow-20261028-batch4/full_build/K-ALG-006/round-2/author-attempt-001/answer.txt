{"chapter":"# K-ALG-006：投机解码：分布保持、状态提交与收益模型\n\n投机解码用较便宜的候选生成过程提出多个 token，再由目标模型并行验证；真正推进服务状态的是被确认的前缀，而不是所有被写入过临时缓冲的 token。它把若干串行 decode 步换成一次更宽的验证，但增加草稿、无效验证、状态回滚和驻留成本。本章围绕三个问题展开：候选在什么条件下保持目标分布；接受边界怎样跨 KV、递归状态、随机与语法状态共同提交；哪些成本关系决定应保留、调整或关闭投机。\n\n## 问题、定义与不变量\n\n设已确认前缀为 x_{<t}，目标模型在给定前缀下的下一 token 分布为 p_t(u)=P_Mp(u|x_{<t})，草稿为 q_t(u)。一次投机回合给定候选数 γ≥1，草稿依次产生 x_1,...,x_γ，目标模型计算 p_1,...,p_{γ+1}。这里 p_i 是 x_i 之前的条件分布，p_{γ+1} 是全部候选之后的 bonus 分布。回合输出 y=[x_1,...,x_n,t]，n 为接受前缀长度，t 在拒绝位置由修正分布产生，或在全部接受时由 bonus 分布产生。n∈{0,...,γ}，所以每回合至少输出一个 token。\n\n状态至少包含四项长度。known 表示已确认可见 token 序列及长度 L；kv_boundary 表示所有必要层已完成写入且可作为历史读取的 token 数 K；allocated 表示已预留的页、候选行、mask、workspace 与快照容量 A；RNG、grammar、输出游标、模型与 adapter 版本、请求代次构成不可分割的提交状态。三者满足容量意义下的 A≥已保留物理对象，逻辑意义下 K≤L；bonus token 可能已经 known，但尚未作为输入，因此没有自己的 KV 或递归状态。把输出 token 数直接当新增 KV 数，是一步偏移错误的常见来源。\n\n本回合输入是：目标与草稿模型句柄、已确认前缀与上述状态、候选数 γ、采样变换、草稿来源和在线预算。输出是：确认 token 序列、提交后的状态、被拒绝候选的回收范围，以及本轮接受长度与成本观测。\n\n需要保持的不变量是：\n\n- 随机采样下输出 token 的分布与直接使用目标分布一致；greedy 下与目标逐位比较规则一致。\n- 只有已确认候选和修正/bonus token 进入可见历史；被拒绝候选的 KV、分支状态、grammar 与 RNG 轨迹不得成为后续前缀。\n- p_i 与 q_i 使用同一条件前缀、模型/adapter 版本、精度和实际采样变换；候选自己的 KV 由后续目标前向产生，不能拿来替代它之前的条件分布。\n- KV、递归状态、grammar、RNG 和输出在同一个接受边界提交或回滚；物理页可延迟回收，但逻辑可见范围立即截断。\n- 异步读者结束前不得覆盖候选或历史状态；取消不能把已拒绝候选重新当作正式历史。\n\n设计轴包括草稿来源、候选结构、验证规则、深度与宽度策略和回滚机制。小模型、特征预测、n-gram 或 prompt lookup 都是合法候选来源；链与树是候选结构；greedy 与随机接受是不同语义；固定 γ、按近期接受分布调整、按 batch 占用关闭都属于运行点选择。\n\n## 两类合法语义与支持集\n\n随机采样先把 temperature、惩罚、top-k、top-p、grammar mask 等变换作用到实际分布上。设 p、q 已经是最终用于抽样的归一化条件分布。草稿候选 x 的接受概率为 a(x)=min(1,p(x)/q(x))，接受质量 q(x)a(x)=min(q(x),p(x))。若拒绝，则从正剩余质量抽样：p'(x)=max(0,p(x)-q(x))/(1-β)，其中 β=Σ_u min(p(u),q(u))，1-β 是总拒绝质量。\n\n合法性要求 q 在 p 的正支持上也有正概率，或明确把目标分布限制到 q 的支持并报告输出语义变化。若 p(x)>0 而 q(x)=0，x 永远不会被提出，接受公式没有有限比值，最终分布会缺失这部分质量。仅把非法位置用 mask 乘零也不等于正确处理支持集；应使用明确的合法集合和归一化。若 q 是只在候选集合上归一化的提议分布，也必须把目标在候选集合之外的剩余质量交给拒绝分支，不能把候选集合当成整个词表。\n\n正确性可由质量守恒直接看出。接受分支给 x 的质量是 min(q(x),p(x))；拒绝分支给 x 的质量是 (1-β)·max(0,p(x)-q(x))/(1-β)=max(0,p(x)-q(x))。两者相加为 p(x)。当 β=1 时拒绝概率为零，残余分布虽未定义但不会被使用。\n\ngreedy 不走随机接受。目标对每个候选位置给出 argmax；草稿 token 与目标 argmax 相同则接受，首次不同则输出该位置的目标 argmax、丢弃其后候选；全部相同则从 p_{γ+1} 取 argmax 作为 bonus。平局规则、temperature=0 的定义和禁用 token 处理必须与目标采样契约一致，不能把除以零的 temperature 当随机公式。\n\n分布等价不等于相同 seed 下逐 token 相同。草稿采样、接受随机数和修正采样会改变随机数消耗路径；普通 seed 固定只控制特定执行路径。可复现性设计应把请求随机流绑定请求身份与逻辑位置，但跨版本、平台和全部算法路径的逐位一致仍不能由 seed 保证。\n\n## 链式回合：完整算法与状态提交\n\n以下伪代码把一轮链式投机写成可独立实现的状态机。它假定回合开始时 prefix 已作为输入处理、kv_boundary 等于 prefix 长度；若实现把上一轮 bonus 并入本轮验证前向预计算，必须显式记录该预计算的临时与可见边界，不能无条件套用最后的等式。\n\n```pseudocode\n算法 链式投机解码一轮\n输入：目标模型 Mp，草稿模型 Mq，已确认前缀 prefix，状态 S，候选数 γ≥1，采样变换 T\n输出：本轮确认输出、提交后的状态 S'、临时对象回收范围\n\n初始化：\n  从 S 读取 known、kv_boundary、容量记录、RNG、grammar、输出游标\n  校验 0 ≤ kv_boundary ≤ known 长度\n  建立本轮临时记录：candidates、q_dists、target_dists、accept_uniforms 为空\n\n草稿阶段：\n  draft_prefix ← prefix\n  对 i=1..γ：\n    q_i ← T_q(Mq(draft_prefix)) 的全词表条件分布\n    校验 q_i 归一化，并校验 q_i 对目标分布的支持覆盖关系\n    x_i ← 按 q_i 抽样，并推进临时 RNG\n    记录 (x_i,q_i) 到 candidates/q_dists\n    draft_prefix ← draft_prefix + [x_i]\n  草稿完成证据须覆盖 γ 个候选及其必要状态；未完成则放弃本轮，不提交\n\n目标验证阶段：\n  对 i=1..γ+1：\n    p_i ← T_p(Mp(prefix + [x_1..x_{i-1}])) 的下一 token 分布\n  可并行计算这些条件；记录每个 p_i 的条件前缀与目标前向覆盖范围\n  p_i 是 x_i 之前的分布，不是 x_i 自己的 KV；p_{γ+1} 是最后一个候选之后的 bonus 分布\n  任一验证失败或覆盖不全时回滚临时区，不发布部分确认结果\n\n接受与修正：\n  n ← 0\n  对 i=1..γ：\n    r_i ← 独立均匀随机数，与候选和此前接受事件独立\n    a_i ← min(1, p_i(x_i)/q_i(x_i))，q_i(x_i)=0 时按合法性失败处理\n    若 r_i ≤ a_i：n ← n+1\n    否则：停止扫描\n  若 n<γ：\n    R_i ← 归一化 max(0, p_{n+1} - q_{n+1})\n    t ← 按 R_i 抽样\n  否则：\n    t ← 按 p_{γ+1} 抽样\n  本轮输出 ← [x_1..x_n] + [t]\n\n状态提交：\n  新 known ← prefix + 本轮输出\n  新 kv_boundary ← 旧 kv_boundary + n\n  校验 新 kv_boundary = 新 known 长度 - 1（bonus 尚未作为输入）\n  将 x_1..x_n 的逻辑 KV/递归状态标为可见；t 只标为已知，尚无 KV\n  将 RNG、grammar、输出游标推进到同一接受边界\n  拒绝候选 x_{n+1}..x_γ 标记为临时；物理页/缓冲等待最后读取结束后回收\n  按实际保留容量更新 A；未接受候选不得成为共享前缀\n  返回 S'\n```\n\n接受长度 n 同时决定四件事：输出 token 数 n+1；可见 KV 新增 n；grammar/RNG 推进到 n 个接受候选及 bonus；被拒绝候选的回收范围从 n+1 到 γ。若 n=0，修正 token 占一个位置，KV 没有新增候选，bonus/修正 token 仍待下一次输入；若 n=γ，全部候选的 KV 已在前向中计算，bonus 仍没有 KV。\n\n以一个设定轨迹说明一步偏移。设已确认前缀长 m=5，γ=3，目标验证处理了 x_5,x_6,x_7 三个候选，最终只接受 n=2，并从 p_7 的修正/bonus 位置取得 t。提交后 known 长 8，位置 5、6 是接受候选，位置 7 是 t；可见 kv_boundary 为 7，即前缀加两个接受候选。被拒绝的 x_7 虽然可能已经物理写入 KV，也不能进入下一轮可见历史。若把 kv_boundary 写成 8，系统会认为 t 已有 KV 而跳过它的输入；若把三个候选全提交，下一轮会读到错误分支。\n\nappend-only KV 的逻辑回滚可以缩短有效长度，但物理页只有在最后一个读者结束后才能复用；共享前缀使用写时复制时，拒绝分支不能原地污染共享页。递归模型或混合状态不能仅把计数器改小：需要接受边界快照、可恢复检查点或从较早状态重放。滑动窗口若已经覆盖旧槽，还需要窗口快照或足够早的重放起点。grammar 解析栈、RNG 子序列和输出缓冲必须与同一边界一起提交；只回滚 KV 而保留拒绝分支的 grammar 状态，会在语义上读入不存在的前缀。\n\n异步执行中，拒绝事件只改变逻辑可见性，不自动终止已提交的验证前向。调度器必须等目标验证的真实完成证据覆盖必要层、候选状态和输出范围，再发布接受结果；取消后的旧完成不能重新获得提交权。\n\n## 树形候选：逐层协议与可见性\n\n树形验证把多个候选位置放进一次目标前向，但每个节点只能看到确认前缀和自己的祖先，不能看到兄弟分支。设节点 v 的父路径为 A(v)，则其目标条件分布是 P_Mp(·|prefix+A(v))；兄弟节点属于不同分支，物理行连续不表示它们可以互相可见。链式候选是每个深度只有一个孩子的退化树。\n\n一次目标前向可把前缀与候选行组织成 Q，KV 是确认前缀和祖先路径的并集。链式 mask 使第 i 行只看到前缀与 x_1..x_{i-1}；树形 mask 只允许祖先。权重读取可被多个候选行共享，但 Q 行数、K/V 读取范围、mask 与 workspace 随节点数增长，接受边界决定哪些候选行可以写回可见 KV。树的候选数量、目标前向数和已确认输出长度是不同指标。\n\n树形验证不能只对每个子节点独立按 min(1,p_v/q_v) 接受后任取一条。每一层都需要带剩余质量的分布协议：候选集合之外的 target 质量不能丢失，拒绝后要从当前父路径下的正剩余质量抽样；否则任意 top-k 树或兄弟选择会改变目标分布。层间协议还必须规定候选顺序、并列候选和质量归一化，不能把链式 p/q 规则直接套到任意树再挑一条获批分支。一个安全的描述是：在每一层把该层候选组织成一个归一化的提议分布 q，按接受/拒绝规则推进；若拒绝，则从该父路径下的正剩余质量抽样并终止该分支。具体树实现还需证明其遍历与归一化顺序满足这个逐层关系。\n\n```pseudocode\n算法 树形验证的可见集与提交边界\n输入：确认前缀 prefix，节点集合 V，父指针 parent，接受路径 path，节点到 Q 行的映射 row\n输出：每个节点的可见祖先集合、目标前向覆盖关系、提交和拒绝集合\n\n初始化：\n  对每个节点 v∈V，visible(v) ← {prefix}\n  对每个节点 v∈V，visible(v) ← visible(v) ∪ path_to(v) 的祖先 token\n  校验 parent(v) 在 prefix 或 V 中，且不存在环\n  校验每个 Q 行只对应一个节点或确认前缀位置\n\n目标验证：\n  用 visible(v) 构造该行的 attention 可见集\n  对每个 v，计算 p_v ← Mp 在 prefix+path_to(parent(v)) 下的下一 token 分布\n  校验 p_v 的条件前缀与 visible(v) 一致\n  兄弟节点不得出现在 visible(v) 中；祖先节点必须出现\n\n接受与提交：\n  按层执行带剩余质量的接受/修正协议，得到接受路径 path 和每层输出\n  新 known ← prefix + 接受路径 + [bonus]\n  新 kv_boundary ← 旧 kv_boundary + 接受路径中已作为输入的节点数\n  将接受路径上的 KV/递归状态标为可见\n  将兄弟节点、未选中节点及其后代标为临时；等待最后读取后回收\n  将 RNG、grammar、输出游标推进到同一接受边界\n  返回新状态与回收范围\n```\n\n树形候选的状态也必须被分支化。每个树节点携带父指针、逻辑 token 路径、草稿分布、grammar/RNG 分支和必要特征；只保留被接受路径，其他路径的 KV、特征和 mask 等待最后读者结束后回收。若多个分支共享不可变前缀，可以共享只读页；可变 grammar 栈、随机状态和输出游标不能共用。\n\n## 草稿来源、分支状态与 EAGLE 边界\n\nEAGLE v1 的草稿在目标模型第二顶层特征上自回归，并把提前一步的已采样 token 与特征一起输入，以处理下一特征依赖采样结果的不确定性；它用树 attention 在一次目标前向中验证多个节点，并在每层递归执行投机采样与修正。这里的草稿表示改变的是候选生成成本和准确性，不取消目标验证、接受/修正与共同提交的要求。EAGLE 论文报告的链式接受率不能直接当树形产出率；树提高接受长度时也会增加每次前向处理的 token、无效验证和资源。\n\n其他草稿来源是同一设计轴上的不同点。独立小模型可用较小权重近似目标，但有加载、驻留和跨设备传输成本；n-gram 或 prompt lookup 把草稿成本降到查表，前提是输出中存在可从上文复制的片段，接受率随任务变化；特征预测减少草稿前向，却仍要为目标验证准备候选和状态。MoE 目标在验证多个候选时可能需要更多专家权重，专家并集会改变看似相同的候选数下的成本。\n\n草稿分支的状态也必须被分支化。每个树节点携带父指针、逻辑 token 路径、草稿分布、grammar/RNG 分支和必要特征；只保留被接受路径，其他路径的 KV、特征和 mask 等待最后读者结束后回收。若多个分支共享不可变前缀，可以共享只读页；可变 grammar 栈、随机状态和输出游标不能共用。\n\n## 条件化成本与收益公式\n\n设一轮草稿成本为 D(γ)，目标验证成本为 V(γ)，提交、回滚、调度与图处理成本为 H(γ)，该轮平均确认输出为 E[L] 个 token。单位确认 token 成本约为 (D+V+H)/E[L]。只有在同一请求集合、同一 batch 条件、同一质量与 SLO 下，它低于普通目标 decode 的有效单位成本，投机才有收益。\n\nE[L] 不一定由单个接受率决定。一般地，回合输出长度为 n+1，因此 E[L]=1+Σ_{i=1}^{γ} P(前 i 个候选都被接受)。若错误地假设各位置独立同分布且接受率为 α，则 E[L]=1+α+...+α^γ=(1-α^{γ+1})/(1-α)；α=1 时取极限 γ+1。真实接受事件有条件相关性，应测接受长度分布或逐层接受概率，不能只报一个平均接受率。\n\n在更简化的墙钟模型中，若一次目标验证约等于一次普通目标步，草稿每步成本为目标步的 c 倍，则加速比可写成 S(α,γ,c)=(1+α+...+α^γ)/(1+cγ)。更一般地，若验证成本随 γ 变为 v(γ)，应使用 S=E[L]/(cγ+v(γ)+h(γ))。论文的 α>c 条件说明在该模型中存在某个 γ 使 γ=1 已有收益，但不证明任意更大的 γ 都更好；γ 必须按实测的草稿、验证、管理和接受分布选择。\n\n墙钟收益与算术量收益不是同一件事。并行验证增加目标前向的 query 行数；在 i.i.d. 简化模型下，若草稿每 token 算术量为目标的 c_hat 倍，总算术量期望增加因子约为 ((1-α)(γ c_hat+γ+1))/(1-α^{γ+1})。它可能大于一，而墙钟仍因权重读取摊薄而改善；反过来，额外算术也可能在目标已经饱和时直接变成更慢。\n\n设定算例：普通每 token 10 个时间单位；γ=4，一轮草稿 8、验证 13、管理 3、平均产出 3，则每 token 约 8，理想吞吐提高 25%。同一个投机配置在 batch 扩大后普通 decode 已降为每 token 6，则 24/3=8 反而更慢；若该配置平均产出只有 4，则 24/4=6 仅打平。这个算例是合成计算，不是硬件测量。\n\n成本要按类别列在同一候选上：\n\n| 类别 | 投机回合新增 | 可能减少 | 条件与边界 |\n|---|---|---|---|\n| 计算 | 草稿 γ 步、目标 γ+1 个条件行、attention 与树 mask | 和提交边界必须表达真实范围；预留容量不是已确认输出，不能被调度器当成可复用历史。\n\n在线策略可按近期接受长度分布调整 γ，把额外验证预算给高收益请求，并在低接受率、目标 batch 已充分利用或草稿占用关键资源时关闭投机。固定 γ 不是越大越好；γ 增加会提高候选覆盖，也会增加无效验证、mask、快照和拒绝回收。多请求共享目标设备时，还要比较整体 RNG/grammar/输出状态继续；之前写入但被拒绝的候选不能重新成为历史。恢复过程要重算或读取共同状态位置，不能只恢复 token 长度而遗漏递归状态、窗口或 grammar。跨设备迁移时，提交权与最后源副本释放必须按恢复协议处理。\n\n## 诊断：竞争解释与区分实验\n\n先固定逻辑输入、总工作量、质量标准和计时范围，再比较投机开关或不同 γ。主机时间戳与设备完成需要可靠关联；累计
