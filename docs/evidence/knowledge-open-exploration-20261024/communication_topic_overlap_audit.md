## 明确归并方案

1. 在 **HW003 主机准备、DMA 与流水缓冲** 内修订既有流水段，把三阶段作为不计 D2H 的特例，并将四阶段有限批公式、填充/排空和例子放在同一处；避免旧 3/2/8 与新 3/2/8/1 平行重复解释。
2. 在 HW003 的缓冲池段增加各池生存期与 `ceil(L/P)` 关系；在共享带宽段增加按同一资源合计字节的 `Q/B` 下界。以八批、两个输入槽、两个输出槽、34 MiB 及 15.625 ms 为一个联合反例。
3. FW003 已完整解释顺序与存活期、多个消费者和回收，不因新增 API 名称而再次扩写。HW003 只保留 DMA 源保护、D2H 后主机读取等具体边界并链接 FW003。统一/映射内存、NUMA、计算放置、计时分别链接 HW013/HW009/SYS019、ALG020、SYS001。
4. 清理本轮 HW003 自身追加段与原段的重复：选择触发放开头；小 metadata/大对象选择回到“何时减少传输次数更有效”；API 生产/消费表只保留直接服务于原主题的内容，不再导向撤销的新章。
5. 机制可以在空工程、局部原型或已有引擎中探索；局部、集成与系统说明是不同结论的证据范围，不是固定研发先后或进入探索的门槛。
