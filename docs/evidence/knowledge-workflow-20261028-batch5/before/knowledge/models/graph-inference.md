# K-MODEL-016：图模型推理：邻居依赖、采样与不规则执行

图模型推理由目标节点向外展开计算依赖，再把邻居特征逐层聚合到目标。请求数量相同，不代表边数、特征读取量或计算量相同；节点度分布、重复邻居与图的版本直接影响执行。

## 图、特征和聚合器组成输入函数

模型输入至少包括节点/边身份、方向与类型、特征 schema 和版本、邻域定义、采样规则及模型参数。一个节点 ID 不能脱离图命名空间解释，特征更新也不能与旧邻接快照任意混配。若任务有时间边界，只允许看到该时点之前的数据，未来边进入缓存同样是输入错误。

GraphSAGE 固定论文给出递归机制：第 k 层对选定邻居的第 k−1 层表示聚合，再与自身表示拼接，经线性变换、激活和规定的归一化得到新表示。均值、max-pooling 和 LSTM 聚合是不同模型；均值/逐元素 max 对邻居排列具有数学不变性，LSTM 聚合依赖顺序，随机排列只是其训练/执行约定，不能把它当作严格集合不变算子。

自身节点是否纳入邻域、是拼接还是一同平均、空邻域怎样定义、归一化零向量如何处理，都需要从实际模型确定。GraphSAGE 的均值拼接与 GCN 风格的统一均值也不同，不能仅凭二者都“聚合邻居”替换权重接口。

## 依赖展开与特征收集

给定目标集合 B_K，反向确定每层所需集合 B_{k−1}=B_k∪N_k(B_k)，再从第 0 层向前计算。一个中间节点的第 k 层表示只有在其全部被选择的第 k−1 层依赖就绪后才能生成。仅沿目标节点收集最外层邻居，忽略自身分支所需的中间表示，会得到不完整的计算图。

同一层、同一图/特征版本、同一采样定义下，重复节点的特征读取可以去重，并通过映射恢复每条边的消费关系。对于边权、平行边或按出现次数聚合的函数，去重读取不等于去重语义。跨层表示也不能只按节点 ID 合并，因为它们包含的邻域深度不同。

CSR/邻接列表等表示决定边遍历与行定位成本。收集节点后可重排为更连续的特征访问，并记录反向映射；聚合结果仍需回到正确目标。CPU 采样、GPU gather/聚合与远端特征读取可以流水，但边索引、特征、当前批映射和临时输出均需明确在途所有权。

## 采样是质量与资源之间的选择

全邻域执行给定图和参数的确定函数；固定 fanout 限制读取与工作量，通常改变结果。一个无偏的邻居均值估计，经过激活、归一化和多层递归后也不自动产生无偏预测，更不保证与全邻域分类相同。必须把采样近似与低精度实现误差分开评价。

邻居不足 fanout 时，有放回、无放回、padding 或全取等不同策略。用重复节点补齐会改变均值的权重，除非有配套计数/屏蔽规则。采样种子和邻居遍历顺序要可追溯；复用采样结果可减少开销，但减少随机覆盖并绑定图版本。

GraphSAGE v1 的实验还对度数做了预处理截断，其报告的效率和质量不能直接理解为在任意完整原图上的保证。论文的表达能力证明是存在某些参数的结论，也不构成一个给定 checkpoint 在采样图上保持质量的证明。

## 算术、带宽和分片账

若每层最大采样数为 s_k，则依赖集合有上界 |B_{k−1}|≤|B_k|(1+s_k)。这个上界包含自身路径；重复邻居和低度节点会使实际集合更小。实际采样边数、唯一节点数、缓存命中与读取字节应分别记录，不能只报告目标 batch。

输入特征字节约为 U d₀ s，其中 U 为本批实际读取的唯一节点数；缓存行、索引、通信封装和远端访问会增加流量。均值聚合主要随采样边数×输入维度增长，线性层则随需计算节点数×输入/输出维度增长。先聚合再线性或先线性再聚合，只在函数、线性性和数值条件允许时等价；存在非线性、边特定权重或不同自身变换时不能任意交换。

按节点分片能将其特征和邻接放在一起，但跨分区边引入远端特征读取。复制边界特征可减少通信并增加容量与失效维护；度数或热点偏斜会让均匀节点数的分片仍极不均衡。缓存完整多层 embedding 还依赖其邻域，当边或底层特征更新时，影响可沿层数传播；只更新被直接修改节点的最终结果未必足够。

## C12-E：采样图推理的完整验证场景

设定两层模型，输出目标 B₂=64；输出层每节点取至多 10 个邻居，输入层为其所需节点各取至多 5 个邻居。包含自身分支时，|B₁|≤64×11=704，|B₀|≤704×6=4,224；最多采样边数为 64×10+704×5=4,160。若输入为 128 维 FP32，最外层唯一特征读取上界是 4,224×128×4=2,162,688 字节，即 2.0625 MiB，另有邻接、映射、层间表示和输出。共享邻居可以降低实际值，但必须由本批去重统计确认。

候选 A 在图和特征可容纳时做全邻域、按层批处理；候选 B 做有明确规则的固定 fanout 采样，并把特征收集与 GPU 执行流水。A 可作为给定图函数的数值参考，B 是质量约束下的近似候选，不能用相同输出要求把合法采样差异误判为 kernel bug，也不能忽略它对任务质量的影响。

先验证同一冻结采样子图在单线程参考与优化实现上的结果。独立一层算例规定自身 x_v=2、邻居值 4 和 8，均值聚合得 6；拼接后使用权重 (1,1)、ReLU，归一化之前结果为 8。只采样邻居 4 时为 6，清楚显示采样改变函数。若模型还含归一化，应继续执行并分别比较前后值，不能借最终归一化掩盖中间聚合错误。

覆盖孤立节点、重复边、自环、入边/出边反转、零特征、邻居不足、共享邻居、超高度节点、多个图同名 ID、图更新中的请求以及远端特征缺失。对均值/max 模型做邻居排列不变测试；对 LSTM 聚合则固定其顺序契约。采样质量用多种种子和图分布测节点分类 F1/accuracy 或任务指定指标，报告均值与波动，并与全邻域和训练时预处理相匹配的参考分别比较。

性能从请求进入到所有目标结果返回，拆分采样、ID 路由、特征获取、搬运、聚合、线性计算和结果重排，同时报告目标节点/s、实际边/s、字节与 p99。缓存热启动、重复查询和全冷特征应分开。图较小且更新少时，全图预计算/按层执行可能更有效；节点零散、图很大或时限较紧时，采样与局部缓存才可能获益。更新频率和质量要求提高时，缓存及采样策略都需要重新选择。
