# K-ALG-005：量化：误差传播、分组尺度与执行格式

量化把数值映射、分组元数据、数据布局和执行内核一起改变；收益由减少的字节与新增的变换成本共同决定。一个可复现的量化契约必须回答：整数码怎样重建；哪些元素共享参数；参数何时建立和冻结；补偿时使用的重建值是否就是最终制品解出的值；尾部怎样参与归约；内核实际消费什么表示。本章的算例、资源账和伪代码是模型层推导，不是目标 GPU 或 CPU 内核实测。

## 数值定义、状态和两种偏移

设待量化标量为 x，步长 s＞0，码域为整数区间 [q_min,q_max]。本章默认舍入 R(t)＝floor(t＋1/2)，即最近整数，半整数向 ＋∞ 取整。舍入身份和发生位置属于编码契约；仅写“最近舍入”不足以确定码。

实数偏移模式 REAL 使用 (s,b)：

q＝clip(R((x−b)/s),q_min,q_max)，x̂＝b＋s q。

整数零点模式 ZERO 使用码域内的整数 z：

q＝clip(R(x/s)＋z,q_min,q_max)，x̂＝s(q−z)。

任意实数偏移只有在 −b/s 是码域内整数时，才能改写为本章要求的整数零点。即使 b＝−s z，两种编码次序也只有在 R(t＋z)＝R(t)＋z 时才等价。默认规则满足整数平移不变性；最近偶数舍入不满足。取 s＝1、z＝1、x＝0.5：先舍入再加 z 得到 1，先加 z 再最近偶数舍入得到 2。既有码流的重建只依赖解码规则；未来重新编码是否等价，还依赖舍入位置。迁移时不能忽略这个区别。

输入包括张量、形状、分组轴、组大小、码域、位宽、有符号性、舍入、裁剪策略、模式、布局和格式版本。输出包括码流、每组 scale 与零点或实数偏移、组身份、有效长度、尾部掩码和布局版本。静态参数属于冻结制品；动态参数属于当前调用或 token 的状态，必须随该次产生的码共同交给消费者。

常数组不能把 max−min＝0 直接代入步长公式。REAL 可选合法码 q_c，令 s＝1、b＝c−q_c，使常数 c 精确重建。ZERO 可按明确规则选正尺度和整数零点；本章后面的有符号对称构造对全零组使用 s＝1、z＝0。非零常数组也按该构造处理，不产生零步长。NaN、Inf、尺度下溢为零和尺度溢出都应触发拒绝或明确的高精度例外，不能静默生成任意码。

不饱和且采用最近舍入时，单元素绝对误差至多 s/2；这个界不覆盖裁剪和实际浮点计算的额外误差。REAL 的重建区间为 [b＋s q_min,b＋s q_max]；ZERO 对应 [s(q_min−z),s(q_max−z)]。区间外的误差可远大于 s/2。

在线性层 y＝Wx 中，若权重和激活都量化，则 ŷ−y＝ΔW x＋WΔx＋ΔWΔx，其中 ΔW＝Ŵ−W、Δx＝x̂−x。因此权重自身的均方误差不是层输出误差的完整目标。attention 的 Q/K 误差先改变 logits，再经过 softmax，不能按位宽比例直接推算最终输出误差。

## 合法性：分组、填充和执行布局

合法实现必须同时保持数值含义和索引身份。

- s 有限且严格为正；ZERO 的 z 是码域内整数。码域、位宽和有符号解释一致。例如 signed INT4 码域为 [−8,7]，nibble 0xF 表示 −1。包含 [−8,8] 的 17 个码不能称作 INT4。
- 分组覆盖每个有效元素恰好一次。轴、组号、尾组有效长度和元数据排列共同定义映射。组大小不必整除维度，尾部不能从相邻组借用参数。
- ZERO 中，代表实数零且会被消费的填充码为 z，因为 s(z−z)＝0。REAL 只有在 −b/s 是合法整数时才有精确零码；否则无效位置必须被屏蔽，或采用另有定义的中性处理。近零码不是精确中性填充。
- 打包协议包括低位顺序、符号扩展、行跨度、组表顺序、预转置、对齐、有效长度和版本。重排权重必须同步重排参数或保留明确映射。
- 参数最终存储精度参与数值契约。若 scale 写入 FP16，应先得到实际可存储的 scale，再用它编码和计算补偿；不能补偿时用未舍入尺度，导出时才换成另一个尺度。存储后不再有限正值时应拒绝该配置。
- 通道变换 Wx＝(WD)(D⁻¹x) 要求 D 可逆，并补偿同一激活的所有消费者。只修改 Q/K/V 中的一条边或残差分支的一部分，会改变量化前的函数。跨非线性移动尺度需要另外证明。
- FP8 必须区分 E4M3/E5M2、缩放粒度、amax 来源、饱和和非有限值处理，以及存储、乘法、累加和输出精度。能存某种 dtype 不证明目标 shape 有对应的高效计算路径。
- GPTQ 的二次模型要求所用 H 对称正定，因子对角元有限且为正。Cholesky 失败时应调整阻尼或数值精度，或放弃该层配置；不能继续消费无效因子。

组大小、对称或非对称、动态或静态尺度，以及敏感层是否保持高精度属于选择空间。满足数值契约只是合法条件；实际 dispatch、质量和服务成本决定方案是否适用。

## QPACK：从组参数到可独立解码的制品

QPACK 将参数建立与元素编码分开。参数表先完整建立并冻结，随后所有元素使用同一张表。下列流程允许不同参数选择策略，但它们都必须交付明确的参数表。

```pseudocode
算法 QPACK
输入：张量 X、形状、组划分、码域、模式、舍入 R、裁剪策略 C、布局 L
输出：packed codes、冻结参数表 P、有效长度或掩码、布局版本

1 校验组覆盖、码域、有符号性、模式、舍入身份与布局
2 对每个非空有效组 g：
    从该组全部有效值与 C 求候选参数；常数组按明确规则处理
    REAL 保存 (s_g,b_g)；ZERO 保存 (s_g,z_g)
    将参数转换为制品实际存储精度，重新校验其合法性
    记录组身份、轴、有效长度和模式
3 冻结完整参数表 P；之后不再以单个元素重估参数
4 对每个有效元素 x_i，从 P 读取所属组参数：
    REAL：q_i ← clip(R((x_i−b_g)/s_g),q_min,q_max)
    ZERO：q_i ← clip(R(x_i/s_g)＋z_g,q_min,q_max)
5 按 L 打包 q_i，不改变其整数值或组身份
    ZERO 的中性填充使用 z_g
    REAL 没有精确零码时，将填充标为无效并在消费前排除
6 返回码流、原样保存的 P、有效长度或掩码与布局版本
```

独立解码器按模式分别使用 b_g＋s_g q_i 或 s_g(q_i−z_g)，不调用目标内核。它只解码有效位置，或显式执行约定的中性填充规则。给定组参数之后，编码和解码没有“再拟合尺度”的步骤。

REAL 网格 lo＝−2、hi＝6、16 级时，s＝8/15，零的码坐标为 3.75。最近码 4 解出 2/15，乘以 15 会向点积额外贡献 2；将其称为零填充会改变结果。相反，ZERO 的 s＝0.5、z＝3 中，填码 3 精确解出零，增加任意有限权重的填充项都不改变归约。

## GPTQ-LAYER：冻结分组网格与二次误差补偿

采用 W₀∈R^{d_out×d_in}、X∈R^{d_in×m}，令每个输出行沿输入列进行量化。GPTQ 固定来源版本为 2210.17323v2；其层目标为减小 ‖(W₀−Ŵ)X‖²。加入阻尼后使用 H＝2XXᵀ＋λI，对应每行误差 e 的二次目标 eᵀHe/2，即层输出误差加 λ‖e‖²/2。阻尼用于稳定近似，它也改变所优化的二次模型。

本章交付一种完整的固定网格方案。它采用论文 §3“量化前固定网格”的前提，再将网格细化为逐行输入维分组；不声称复现论文中“按最新补偿权重确定分组参数”的另一种选择或其质量数字。

设 G 为正整数。元素 W₀[r,j] 的组身份为 (r,g)，g＝floor(j/G)，该组覆盖 j∈[gG,min((g＋1)G,d_in))。参数表 P 的形状是 d_out×ceil(d_in/G)，不同输出行具有自己的参数。组身份基于逻辑输入列，本节处理顺序固定为原列顺序，不隐含 act-order 置换。若另行引入列置换，必须同步变换 X、H、码和组映射，并明确分组是在原列还是置换后列上建立。

一种可直接重建的参数准备方式是：对 signed b_w bit、b_w≥2，q_min＝−2^{b_w−1}、q_max＝2^{b_w−1}−1，逐组计算 a_{r,g}＝max|W₀[r,j]|。若 a＝0，取 s＝1；否则取 s＝a/q_max；取 z＝0。这是有符号对称网格，负端多出的一个码不要求必须使用。使用其他裁剪或非对称策略也可以，但进入补偿循环前必须交付同样完整、合法且冻结的 P。

参数生命周期为：从未经本轮补偿的完整 W₀ 建立所有组 → 转成最终存储精度并校验 → 冻结 P → 逐列只读 P → 原样随 Q 导出。P 可以作为显式输入，也可以由上述准备过程产生。工作权重 WW 的变化只影响待编码值，不改变 P。一个组可以跨多个计算块 B，块边界不产生新组，也不重置参数。

令 C 为满足 CCᵀ＝H⁻¹ 的下三角 Cholesky 因子，U＝Cᵀ，则 U 为上三角且 UᵀU＝H⁻¹。更新使用 U 的行和对角元，不能用 chol(H) 替代。以下 Q 存整数码；重建矩阵 Ŵ 与工作区 WW 是不同对象。

```pseudocode
算法 GPTQ-LAYER-FROZEN
输入：W₀、校准 X、正块宽 B、阻尼 λ、正组长 G、码域、舍入 R
      已冻结 ZERO 参数表 P[r,g]＝(s_{r,g},z_{r,g})
输出：整数码 Q、原样保存的 P、有效形状与组映射

1 校验 B/G、W₀/X 的形状、有限值及 P 的完整覆盖和存储精度
  d_in＝0 或 d_out＝0 时返回对应空制品，不调用空矩阵分解
2 H ← 2XXᵀ＋λI；校验并构造 Hinv ← H⁻¹
3 C ← 下三角 chol(Hinv)；U ← Cᵀ，使 UᵀU＝Hinv
4 WW ← W₀ 的工作副本；Q 初始化为未写状态
5 for i＝0,B,2B,… 且 i＜d_in：
6   end ← min(i＋B,d_in)；w ← end−i
7   E ← 0^{d_out×w}
8   for j＝i,…,end−1：
9     g ← floor(j/G)
10    对每个输出行 r：
        (s,z) ← P[r,g]，只读，不建立或覆盖组参数
        q ← clip(R(WW[r,j]/s)＋z,q_min,q_max)
        Q[r,j] ← q；h ← s(q−z)
        E[r,j−i] ← (WW[r,j]−h)/U[j,j]
11    WW[:,j:end] ← WW[:,j:end] − E[:,j−i] · U[j,j:end]
12  若 end＜d_in：
      WW[:,end:] ← WW[:,end:] − E · U[i:end,end:]
13 校验每个有效码写入恰好一次；按组解码 Q 与 P 得到 Ŵ
14 仅对整数 Q 做布局打包，原样保存 P、组映射和有效长度
   禁止对 WW 或 Ŵ 再调用会重新拟合参数的 QPACK 准备阶段
15 返回制品；WW、E、H 和 U 均为可释放准备工作区
```

第 11 步的列误差乘行向量是外积；第 12 步矩阵形状分别为 d_out×w 和 w×(d_in−end)。短末块仅分配有效宽度 w。处理本块列 j 时，该列已包含此前所有误差补偿；本块以外的列尚欠本块 E 所代表的延迟更新，直到第 12 步才物化。因此不能在内层循环中随意从块外 WW 读取“最新完整组”来估计尺度。本方案在循环前已冻结 P，完全不依赖这份未物化状态。

关键不变量是：第 10 步用于补偿的 h，等于最终 Q[r,j] 与最终 P[r,floor(j/G)] 的独立解码值。固定一列之后，后续仅调整尚未量化列；不会更改该列的码或重新解释其参数。跨块共享一组时仍使用同一条 P 记录。实数算术中改变 B 只改变延迟更新的组织；浮点归约差异仍可能在舍入边界改变码，不能据此保证跨实现逐位相同。

针对参数覆盖的反例：W₀＝[1,4]、H＝I、G＝2、INT2 码域 [−2,1]、z＝0。完整组先取 a＝4，冻结 s＝4，得到 Q＝[0,1]，补偿和最终解码都是 [0,4]。若错误地每列重估，第一列用 s＝1 得码 1、补偿值 1；第二列用 s＝4 得码 1、补偿值 4。最终只保存 s＝4 时，[1,1] 解出 [4,4]，已违反不变量。逐列保存两个尺度会改变所声明的 G＝2 分组，不能充当修复。

本方案禁止已消费组参数重新估计。若确有需求，必须从受影响组第一次固定码之前的检查点恢复工作权重、码和误差状态，使用新参数重新量化并重放后续补偿；仅替换参数或只重编码旧列而不撤销旧补偿都不一致。这里不交付这种动态网格变体。

还需区分正确因子和错误分解对象。H＝[[2,0.4],[0.4,1]] 时，正确 U 的首行比 U[0,1]/U[0,0]＝−0.4。固定首列重建误差 −0.3，剩余误差最优为 0.12，使 eᵀHe 从 0.18 降至 0.1656；误用 H 的上三角 Cholesky 得行比 0.2，剩余误差 −0.06，目标变成 0.198。补偿是在固定当前量化决定后优化剩余连续变量，不保证每次新增离散约束后总误差下降，也不保证最终整数制品是全局最优。

独立参考可每次从 W₀ 和已固定前缀重新解受约束二次问题。对固定前缀 P_col 和剩余列 F，最优工作值为 W₀,F＋H_FF⁻¹H_F,P_col(W₀,P_col−Ŵ_P_col)。在其第一列上按同一冻结网格选择最近重建值，再扩大前缀。这条参考直接求解 H 的主子系统，不复用被测 U 的行更新，可检验补偿方向、短块和组跨块后的码与重建值。

## 校准以及 GPTQ、AWQ、SmoothQuant 的选择边界

校准固定 tokenizer、输入模板、有效长度、模态、adapter 和前处理，采集目标层实际接收的激活。高精度模型输入便于隔离单层误差，已部分量化模型输入反映上游误差传播；两者可能产生不同 H 和制品。GPTQ v2 的实验路线按 Transformer block 处理，再用量化后的 block 产生后续 block 输入。这是一条具体路线，不要求所有方法采用同样流程。

短通用文本未必覆盖长上下文、稀疏专家、视觉特征和真实 decode 位置。校准集、选择 clipping 或敏感层的验证集、最终任务测试集应分开。m＝0 时正阻尼仍可构造可逆矩阵，但没有输入分布证据；不能把分解成功解释为校准充分。

AWQ v1 用激活统计保护重要输入通道。令 D＝diag(d)，量化前 Wx＝(WD)(D⁻¹x)。其搜索目标是减小量化后的层输出差异，候选尺度形如 d＝s_X^α s_W^{−β}，其中 s_X 来自平均激活幅度，s_W 来自组内归一化后的权重幅度，可搜索 α、β 和 clipping。它最终仍可量化全部目标权重，不要求永久保留最重要的 1% 为 FP16。候选确定后仍需明确其分组参数表和执行格式；算法名不替代这些字段。论文的分布鲁棒性观察不证明不存在校准过拟合。

SmoothQuant v1 的目标是让权重与激活共同适合 W8A8。按本章布局可取 d_j＝max|X_j|^α/max|W_:,j|^{1−α}，将激活的部分量化困难转到权重。零统计通道需要正尺度的单独规则，不能直接执行除零。α 太大可能使权重难以量化，太小则保留激活困难。O1/O2/O3 分别使用 per-token 动态、per-tensor 动态、per-tensor 静态激活量化。通道等价变换发生在量化前；之后的舍入仍有损。

这三类方法改变的对象不同：GPTQ 用输入二次模型补偿尚未固定的权重；AWQ 搜索有利于低位权重量化的通道变换；SmoothQuant 平衡权重与激活的量化难度。它们可以在证明轴、消费者和状态一致后组合，不能直接把各自论文的质量或速度收益相乘。

## 成本账：容量、流量、计算、准备、通信和同步

设 N 个权值、每组至多 G 个值、每值 b_w bit、每组参数合计 m_p 字节。不计对齐、尾部和索引时，码流约 N b_w/8 字节，参数约 (N/G)m_p 字节，有效位宽约 b_w＋8m_p/G。逐输出行分组的准确组数为 d_out·ceil(d_in/G)，不能把整张矩阵展平后只做一次向上取整。

设 4096×4096、4 bit、G＝128，每组 scale 与零点各 2 字节：码流 8 MiB，131072 组参数共 0.5 MiB，总计 8.5 MiB，平均 0.53125 字节或 4.25 bit/权重。FP16 原权重为 32 MiB；同时保留原权重和制品至少占 40.5 MiB。padding、元数据索引、高精度残余和 workspace 另计。

容量不等于每轮流量。若每次先完整展开 32 MiB FP16 权重，再调用矩阵乘，需计展开写入和后续读取，以及压缩制品的读取；tile 内解量化只保存当前片段，但可能被不同输出 tile 重复执行。实际 DRAM 事务还受缓存命中、加载对齐和参数广播影响。

W4A16 可能在 tile 内解包到半精度后进入矩阵单元，也可能采用标量、查表或其他专用路径，没有自动保证 INT4×FP16 原生指令。计算账包括移位、符号扩展、参数索引、尺度乘法、类型转换、点积、补偿和 epilogue。

权重与激活均为整数零点格式时，同一组内点积为

s_x s_w[Σq_xq_w−z_wΣq_x−z_xΣq_w＋K_g z_xz_w]，

其中 K_g 是该组有效归约长度。固定权重的 Σq_w 可预计算，Σq_x 随输入变化。若尺度随 K 组变化，要分别缩放各组部分和再合并，不能先把所有整数和相加再乘公共尺度。整数中间结果、偏置和补偿的溢出界也要按实际归约长度计算。

准备成本包括校准前向、H 的累积、分解或求逆、参数拟合、搜索、打包和校验。H 累积主项约 O(m d_in²)，GPTQ 补偿与分解主项为 O(d_out d_in²＋d_in³)。固定网格的逐组扫描另为 O(N)，参数表为 O(d_out ceil(d_in/G))；它不增加按列重新拟合的扫描。H 在 d_in＝4096、FP32 时占 64 MiB，Hinv、因子、WW 和 E 另计，E 主项为 d_out·min(B,d_in) 个工作元素。实现可复用缓冲，但不能把同时存活的副本省略。

通信账取决于边界处实际传什么。传压缩权重或 KV 时，码、参数、有效长度和版本必须共同到达；接收端若先完整解码，通信减少不代表计算端读取也减少。张量并行的浮点输出 all-reduce 不会因权重变成 INT4 自动缩为四分之一。若一个逻辑组跨 rank，可保留全局组映射并复制所需参数，或重新选择对齐的分组形成新制品；每个 rank 的物理参数副本均要计容量。动态尺度若依赖跨 rank 的共同范围，还需归约统计量及其完成同步。

同步包括动态激活 scale 的 reduction、warp/CTA 间参数广播、跨组部分和合并、量化写入对 attention 的可见性，以及 kernel launch。小 batch decode 容易由启动和同步支配；长 prefill 更能摊薄准备和解包。共享同一带宽或计算资源的阶段不能同时领取各自的理想重叠收益，应沿真实依赖图估计。

Amdahl 关系中的 f_W 应是原关键路径中可被优化的权重阶段时间占比；只有在相应带宽和流量模型成立时，字节占比才能代理它。若 f_W＝0.3，且该阶段时间理想减半，其他 70% 不变，总加速为 1/(0.7＋0.3/2)≈1.176。这个条件化上界没有计新增解包和同步，不是目标机器的预测。

## 条件变化后的保留、调整与放弃

| 条件变化 | 保留的关系 | 调整对象与成本 | 放弃或改选条件 |
|---|---|---|---|
| 小 batch，权重带宽主导 | 压缩减少权重读取候选字节 | 比较 W4A16 的解包、参数访问和真实 dispatch | 新增转换超过读取节省时保留较高精度 |
| 大 batch，矩阵计算主导 | 同一权重能服务更多 token | 比较有适配整数或 FP8 矩阵路径的方案 | 低位权重路径不能有效使用计算单元时改选 |
| 长上下文，KV 主导 | 历史身份、头映射与分组仍须一致 | 评估 KV 量化和残余区，而非只降低权重位宽 | 权重降位已不能改变关键路径时停止继续降位 |
| G 变小 | 更局部的网格可能减少误差 | 重建 P 和 Q，增加组数、参数流量与对齐成本 | 参数或加载成为主项时增大组或换布局 |
| B 改变 | 冻结 P、H 和逻辑组身份不变 | 调整 E 与延迟更新，覆盖短末块和跨块组 | 暂存、访存或尾块浪费超过收益时改块宽 |
| 校准分布漂移 | 旧制品仍可按旧参数解码 | 重采统计、校准和独立质量评估；必要时改动态尺度 | 动态 reduction 太贵或质量仍不合格时放弃组合 |
| 参数存储精度改变 | 码必须由实际保存参数解释 | 使用新精度重新冻结参数并重跑补偿 | 不得只改 scale dtype 后沿用旧补偿结论 |
| 敏感层恢复高精度 | 模型消费者和输出接口保持一致 | 重算驻留、传输、kernel 切换和工作区 | 混合路径仍不满足质量与 SLO 时放弃该配置 |
| 目标设备或并行度改变 | 数值契约可保留 | 重核布局、组跨分片、指令、对齐及同步 | 无合法高效内核时采用成熟高精度路径 |

GPTQ 论文的 B＝128 是具体设置，不是最佳值定理。本节固定网格方案允许 G 与 B 不对齐；若改为组起点动态拟合，就必须另外处理尚未物化的块外补偿，不能沿用这里的状态证明。

## 诊断：竞争解释、独立参考与负对照

先比较同一码与参数的独立解码，再比较解量化参考与目标 kernel，最后比较量化模型与原模型质量。这三个边界分别定位表示/布局、执行数值和算法近似，不能用一个整模型平均指标替代。

| 观察 | 竞争解释 | 区分实验 | 反证后的修正 |
|---|---|---|---|
| 补偿记录正确，导出后重建值变了 | 组参数被覆盖、导出时再次舍入尺度、组轴错或重新拟合 | 保存各列补偿时的重建值，独立解码最终 Q/P；对 [1,4]、G＝2 注入逐列覆盖 | 解码不一致先修参数生命周期与导出，不归因于校准质量 |
| GPTQ 跨块后出现突变 | 块边界误作组边界、延迟更新漏算或末块宽度错 | 固定 P，取 G＝3、B＝2，比较从 W₀ 重解约束问题的参考；再改变 B | 因 B 改变而出现超出浮点解释的差异时，查组映射、E 切片和更新范围 |
| 补偿方向使受约束目标变坏 | 分解对象错误或修正符号反 | 用二维 H 复算最优剩余误差，并注入 chol(H) | 先修因子和符号，不把上升解释为低位量化必然代价 |
| 半整数码不一致 | tie 规则或舍入位置不同 | 固定 s＝1、z＝1、x＝0.5 比较两种位置 | 统一编码契约或禁止声称跨模式编码等价 |
| 填充改变点积 | 没有精确零码、错误零点或 mask 未消费 | 在 REAL 反例上比较实际掩码归约；将 ZERO 填充从 z 改为 0 | 修填充或消费掩码，不通过放宽容差接受状态错误 |
| 输出形状正确但值错 | nibble 顺序、有符号性、参数轴或置换错 | 独立解包已知码，单独改变一组尺度或一个 nibble | 解包失败修格式；解包通过而 kernel 失败查执行路径 |
| W4 比 W8 慢 | 解包、参数流量、占用率、fallback 或小 M 启动成本 | 固定质量与 shape，改变 batch/组长并记录实际内核、字节和时间线 | 字节下降而耗时不降时，调查新增成本，不只依据压缩比解释 |
| 低位质量突然崩溃 | 饱和、错误分组、校准漂移、KV 与权重组合误差 | 先固定制品验证执行，再逐层恢复高精度、分开启用 W/KV 量化 | 只有恢复相关因素能修复时才据此调整；其他解释保留待查 |

负对照必须进入被检机制。例如错误分解对象要进入实际分块补偿；参数覆盖要让已有码在最终表下被重新解释；掩码检查要实际遍历有效位置，不能直接把期望总和赋给“masked”结果。最终解码与补偿值的一致性只证明制品内部自洽，不证明相对 W₀ 的误差足够小。

随附 tools/check_k_alg_005_full.py 使用标准库和小型确定性矩阵，独立枚举网格和求解受约束二次问题；覆盖非单位尺度、多列组、不同输出行、跨块组、短末组、非零整数零点及参数覆盖负对照。它还保留舍入、精确零填充、饱和、signed INT4 小向量打包和容量算术检查。范围是软件算术模型，不是目标 CPU/GPU kernel、真实并行掩码、设备事务或模型任务质量。

## 组合轨迹：压缩权重、分页 KV 与 Attention

一次 W4A16 线性层先确定逻辑 W[r,j]，通过布局映射找到码，再通过 (r,floor(j/G)) 找到冻结参数。输出 tile 沿 K 读取压缩权重，在寄存器或共享存储中解包、重建，再与高精度激活相乘。若采用公开矩阵 API，仍须满足该 API 的 shape、地址对齐、leading dimension 和集体参与条件；fragment 内部映射未公开时不能按下标猜测行列。这里不交付某条专用 INT4 指令的 lane 映射。

按组整数归约时，跨输入 tile 的同组片段可以保留同尺度整数部分和，或分别缩放后合并；跨不同尺度组则必须保留各组单位。输出 bias 和残差合并也要与最终尺度一致。读取压缩码之前，加载转换和参数上传必须完成；解包缓冲只有在全部消费者结束后才能覆盖。完整展开路径另计高精度副本和写读交通。

分页 KV 另有逻辑 token 到物理页的映射，GQA 有 query head 到 KV head 的映射，量化再增加组到参数的映射。三者必须同时成立。设页长 16、跨 token 组长 32，一组横跨两页；迁移或复制其中一页时，需要保留该页元素对应的组参数，不能用目的页号替代逻辑组号。强制页组对齐是另一种选择，但需计尾部浪费。

一种完整的追加轨迹是：新 K/V 在私有可写区域产生 → 依据分组规则生成码与参数 → 等待码、参数和有效长度全部完成 → 发布可读视图 → attention 按页、head 和组身份读取 → 所有读者结束后才允许回收。跨 token 组尚未凑满时，可保留高精度尾部，凑满后封组；共享前缀的已发布组参数不可因私有追加而改写。若分支要求修改包含共享元素的组，应先隔离相关内容与参数，再发布新分支制品。取消发生在发布前可丢弃未发布结果；发布后的状态需等待在途读者结束才能复用物理资源。这是本章的组合设计推导，不归称为 FlashInfer 的通用缓存管理承诺。

FlashInfer 固定论文附录 F 描述的一条路径使用 FP8 KV 存储、FP16 query/output 并执行解量化；这里须与整条 attention 的 FP8 矩阵算术区分。若验证用高精度 KV 完成 prefill，只留下量化副本供后续 decode，单测首 token 没有充分消费量化历史。组合回归应跟踪固定前缀 logits、真实长生成以及任务质量；权重量化和 KV 量化的误差不会自动独立相加。

性能上分别报告持久字节、每轮实际读取/传输、转换时间、同步、峰值驻留和满足质量/SLO 的请求成本。减少逻辑字节但设备事务未降时，应修正访存解释；事务下降但时间不降时，继续区分转换、同步、计算和排队。局部算术检查不能替代这些设备证据。
