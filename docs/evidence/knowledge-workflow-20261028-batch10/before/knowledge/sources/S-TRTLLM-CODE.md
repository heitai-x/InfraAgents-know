## 来源支持的机制与算法

归档的执行器将调度、模型执行、采样和请求更新组织成后台迭代。前一批结果处理与当前设备工作可以部分重叠，但采样到后续输入的依赖和请求终止语义仍然存在。

请求完成后的传输管理专门处理发送与保存，不处理加载。第一次进入时保留请求与传输元数据，可释放其他已不需要的资源并保护待传 KV；每次开始增加计数，每个完成减少计数，全部结束后解除相应保护，且不覆盖已有错误状态。

```pseudocode
请求进入发送/保存阶段时建立保护和未完成使用者计数
每次实际开始传输登记一个使用者
接收对应完成事件后撤销该使用者
当计数归零时解除这一传输阶段的保护，保留错误状态
```

这是特定完成阶段的计数，不等于系统所有设备工作都由它跟踪。独立设计还需要迟到完成、代次与失败后的所有权规则；从该组件本身不能推出全局存储预取或恢复能力。
