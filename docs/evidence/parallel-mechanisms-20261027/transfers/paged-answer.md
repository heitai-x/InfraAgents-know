# 分页迁移练习：第一阶段答卷

作答日期为 2026-10-28。已读任务和当前分页正文；未读作者检查脚本、作者报告、其他答卷或上游实现。以下先保留公式、判断与可否定的解释，再独立执行小模型。此练习存在共享父上下文、无操作系统隔离和未固定推理预算，不能用于声称知识增益或真实 GPU 安全。

## 地址推导

位置 t=4 落在逻辑页 floor(4/3)=1，对应物理页2，页内位置 u=1。K 单页 stride 为 3×2×3×2=36 字节，V 为 3×2×5×2=60 字节。二者基址独立。

| 布局 | K：head1/channel2 | V：head1/channel4 |
|---|---:|---:|
| NHD | 2×36+2×((1×2+1)×3+2)=94 | 2×60+2×((1×2+1)×5+4)=158 |
| HND | 2×36+2×((1×3+1)×3+2)=100 | 2×60+2×((1×3+1)×5+4)=168 |

偏移都以对应池基址为零。不能将 dk=3 的 K stride 用于 dv=5 的 V。只改描述符而不重排字节会把不同 token/head 的值当作目标值；布局各自覆盖全部元素不等于同一字节位置含同一逻辑值。本例物理页不是逻辑顺序：第一个逻辑页来自5，第二个来自2。

## 所有权、快照与取消

A 发布新快照之后，B 继续拥有页5、2，A 拥有页5、7。R0 只读旧页5、2，R1 只读新页5、7，复制写者已完成且写入保留已交接。取消 A 后：

| 页 | 当前所有者数 | 在途快照读者数 | 写者/暂存保留 |
|---|---:|---:|---:|
| 5 | 1（B） | 2（R0、R1） | 0 |
| 2 | 1（B） | 1（R0） | 0 |
| 7 | 0 | 1（R1） | 0 |

此刻没有页可回收。若 R0 先结束，页5仍有B和R1、页2仍由B拥有，页7仍由R1读取；R1随后结束才使页7可回收，页5、2仍归B。若 R1先结束，页7立即满足回收条件；页5仍有B和R0，页2有B和R0；R0随后结束不撤销B。重复完成不能重复减读者，更不能在页7已换代分给其他请求后减少新生命期的读者。

R0 必须继续使用长度5、页表[5,2]；R1使用长度6、页表[5,7]。它们不应随当前A取消或新页表改变读取范围。取消撤销未来服务和当前逻辑拥有权，不证明已提交读者已经结束。

每 token K/V 总字节为 2×(3+5)×2=32；旧尾页有效2个token，COW读64字节、写64字节，追加token另写32字节，总逻辑交通160字节。每页对物理容量3×32=96字节；复制后旧/新快照并存共有3页对，即288字节。容量不是160字节交通，也不是按A/B映射重复计4页的384字节。metadata、填充、实际事务和缓存行为尚未计入。

## 容量与准备算例

13×5×96KiB=6389760字节（6.09375MiB）有效状态，两种页长相同。

| 项目 | P=3 | P=8 |
|---|---:|---:|
| 每请求页数 | 2 | 1 |
| 总页表项 | 26 | 13 |
| 分配字节 | 7667712（7.3125MiB） | 10223616（9.75MiB） |
| 浪费字节 | 1277952（1.21875MiB） | 3833856（3.65625MiB） |
| 页表项字节（每项4字节） | 104 | 52 |
| 设定准备成本 | 26×0.3=7.8μs | 13×0.3=3.9μs |

这里按“每处理一个页表项0.3μs”理解题设。P=8少准备3.9μs，却多分配2.4375MiB；其他准备项已按题设忽略。这不足以决定最佳页长：消费者事务、分叉COW、暂存峰值、实际请求长度分布、准入与共享边界都可能改变结果。

## 竞争解释与区分干预

1. 提前回收：取消A后只看所有者归零就重用页7，忽略R1仍在读取。预测错误随R1延迟和页7快速复用增强；保留各页到全部读票结束后应消除这条通路。检查 free/reassign 是否早于最后读事件，不能仅看取消时间。
2. 描述或结果归属失配：共享描述包被覆盖，或者按当前活跃batch行解释R0。即使旧数据页全部保留，R0也可能读取新页表/新长度或把正确数据交给错误请求。固定每份快照的独立描述、记录原行映射，并在不重用数据页时重现，能与提前回收分开。
3. 旧/重复完成误减新读者：R1第一次结束后页7已合法重用，重复旧事件又操作新代次。预测问题与重复通知、页代次回绕相关，而首次完成前保留页仍不足。给完成一次性票据和物理页代次，注入重复事件，看新请求的读者集合是否改变。
4. 越过末页有效范围：旧长度5只允许尾页2个token，却读取第3个旧字节。固定页面且禁用取消仍可由无效区poison触发，长度改成整页则模式改变。与仅随资源快速复用出现的解释不同。

这些机制可能并存，初始信息不能选唯一原因。应保存每个消费者的长度、页表、请求生命期、资源代次、领取/释放票据和实际数据参考；先用独立稠密逻辑内容定义期望，再控制取消、metadata和页复用的不同变量。
