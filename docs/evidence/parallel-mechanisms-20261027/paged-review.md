# 分页 KV：从逻辑坐标到共享状态生命周期的扩展复核

整理/检查日期为 2026-10-28。本轮只深化 [K-ALG-002](../../../knowledge/algorithms/paged-kv-capacity.md) 与两份来源说明：[PagedAttention](../../../knowledge/sources/S-PAGED.md)、[vAttention](../../../knowledge/sources/S-VATTENTION.md)。来源版本、归档字节和哈希保持原身份；本文不登记全库版本，主 Agent 统一登记。

## 发现的实际缺口与所作修改

原章已有页号公式、容量例和共享原则，但读者仍要自行补足字节 stride、具体布局、追加失败的回滚边界，以及快照/取消/回收间的完整时序。成本项分别存在，未串成可比较的同一候选。

本轮给出一条完整的映射：逻辑请求/位置/head/channel → 页表与代次 → NHD/HND 字节偏移 → 有效范围 → Attention 消费。P=4、Hkv=2、dₖ=dᵥ=4、FP16 的算例直接核对 K/V 地址；变长、空请求、满页和页尾空槽均有契约。

追加算法选择已发布有效内容不可变的具体方案，明确新页一次预留、旧尾复制保护、全部写入完成、完整描述准备、请求身份二次核验、发布与放弃。该方案每次触及未满尾页都 COW，成本较高，但便于证明旧快照稳定；正文同时解释独占尾页原地追加或只共享整页所需的不同证明条件。该算法是本库独立构造，未归给来源论文。

A/B 共享半满页、两份固定图包与取消的轨迹贯通了页所有者、旧/新快照、复制读者、数据就绪、结果归属和最终复用。复制完成但尚未发布的页继续持有写入保留权，取消不使在途读者消失，迟到/重复完成不能影响已复用的新代页。主机逻辑发布与设备可见性明确分开，不假定多字段 metadata 原子更新。

成本模型区分有效 KV、不同存活页、整个预分配池、metadata 预留、复制/gather 交通和关键路径。保留原32层例，并新增长度5/6/9、页长4/8的同条件推导：当前容量3.5/4 MiB、同时准备三条追加时峰值5/7 MiB、逻辑读写交通11τ/27τ。改变准备成本 α 会使页长选择反转；6 MiB 预算又会先排除峰值7 MiB的候选。合成带宽与准备数值均不称为实测。

诊断示例区分准入容量、消费地址/布局、复制/发布、准备四种解释，给出固定请求集合、固定只读状态、放开准入等不同干预；生命周期错误另用延迟读者、尾部 poison、请求槽复用和完成逆序区分。vAttention 说明补足每个区域分别映射/取整、后台准备不能取消当前轮就绪检查、驱动扩展的版本边界。

## 实际执行结果与边界

[CPU 检查报告](paged.json)绑定当前正文、两份来源说明与[检查脚本](../../../tools/check_paged_state.py)的 SHA。脚本实际通过55项作者侧检查，其中132种字节布局组合覆盖 NHD/HND、不同 dₖ/dᵥ、空/满/尾/多页和不同物理页顺序；期望值从逻辑张量直接构建，写入按物理轴枚举，读取按地址公式执行，不靠同一页表算法定义期望。

有限生命周期模型检查24种“旧/新快照均已启动”之后的取消/完成后缀排列，逐事件核对所有者、读票据、写入保留权、代次与独立逻辑内容。另检查准备不足原子失败、复制未完成/已完成未发布的保留权、复制途中放弃、请求槽复用、旧物理句柄、忙图包覆盖，以及两项故意破坏的长度提前发布/过早回收负对照。数量仅描述执行范围，不是模块质量分数。

该模型把主机协调区内操作作为原子事件，没有执行真实 GPU、驱动映射、graph、网络或真实并发 allocator；它不能证明设备内存可见性、所有线程交错、实际矩阵舍入或性能。合成成本算术不能代替目标硬件测量。此轮作者检查没有直接评估独立 Agent 构建、迁移、诊断和调整能力；交叉使用练习由主 Agent 另行记录，不能借本报告声称受控知识增益。
