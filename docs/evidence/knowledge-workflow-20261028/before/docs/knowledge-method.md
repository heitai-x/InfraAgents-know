# 知识库构建与修订方法

本库为 InfraAgents 从空工程构建、验证和持续优化完整推理系统提供机制、算法与设计理论。覆盖范围独立于某个 Task，包含模型、负载、算子、CPU/GPU 与其他平台、内存与存储、调度、通信、协议、观测及恢复。分类帮助阅读，不规定引擎的组件或施工顺序。

## 内容验收标准

读完相关内容后，Agent 应能回答：

- 这个问题的原因/动机（为什么会出现这个问题）、数学定义、输入输出和状态关系是什么？
- 哪些条件决定实现是否合法，哪些只是现有方案的选择？
- 算法具体怎样工作，数据怎样流动，状态怎样变化？
- 计算、访存、通信、准备、同步和驻留分别付出什么成本？
- 条件变化后，为什么应保留、调整或放弃这个方案？
- 怎样通过实现和实验区分竞争解释？

这些是相关知识链的质量标准，不是每份文件必须照抄的六个标题。前置知识可以链接，但本章承担的核心算法、推导与边界不能用链接或名词清单代替。数学定义与真实硬件限制可以确定；某个引擎采用的分层、布局、算法和优化顺序应作为带前提的选择解释。

## 正文与算法

正文以问题和机制展开：说明问题为什么出现，定义对象和合法性，展开算法、数据流与状态更新，推导成本与组合关系，用设定算例、反例和区分实验解释结论如何改变。篇幅与结构由内容决定，不规定候选数、反例数或统一段落数量。

实现逻辑可以转写为完整的算法伪代码，使用 pseudocode 标记的代码块。伪代码应给出输入输出、初始化、循环/分支、更新顺序和完成条件；正文说明正确性不变量、特殊输入与成本。调用一个未解释的库函数不能代替算法。现成 kernel、项目类结构、注册器、兼容分支和可执行命令保留在工程中。

公式须说明符号、单位、轴和假设。区分逻辑数据量、实际设备事务量、容量峰值和关键路径时间；重叠工作不能把全部耗时直接相加。模型结构、数值策略、硬件能力或运行规模改变后，重新检查依赖与成本。

## 来源阅读链

论文保留直接可读的原始 PDF、必要图片和出处；来源说明用自己的话展开算法、推导、论文结论及其条件，明确哪些是论文报告、哪些是本库计算。文档同样保留原文，提炼定义、语义、约束及其设计含义。

源码可以供知识编写者核对机制。交给 Agent 的内容应是经过核对的算法伪代码、数据流、状态关系与条件化事实，不能把整个实现文件称作知识原文。文档/源码混合资料按实际内容选择可读文档；文件扩展名、压缩包形式和仓库名称本身不决定知识价值。已有源码归档可以保留供溯源审计，其字节和哈希不因来源说明修订而改变。

正文引用需要带实质内容，再指向来源说明；来源说明指向可读论文或文档。必要内容离线可读，不依赖 Agent 联网补全。准确版本留作证据身份；只有影响本题合法性或成本的版本事实进入论证，不搬运与本题无关的参数和分支。

## 逐层阅读

阅读入口按主题地图、章节摘要与问题/前提、二级节结构、完整论证、来源原文展开。Agent 自主选择阅读深度；索引与检索结果提供相邻机制，不产生必读清单。读取按实际字符范围与冻结修订记录；读过摘要不等于读过整章。

## Base、观测和 workflow

Base 的来源事实受发布版本的时间上限约束；编辑日期不改变事实日期。新的整理和独立推导保留真实日期与依据，后续实验不能伪装成历史 seed。

运行观测保存环境、workload、测量方法、数值/单位/不确定性、实验证据与真实日期。机制知识解释因果、条件、预测和反例。Workflow 保存一类局部设计、诊断或验证问题的触发条件、前提、步骤、检查与退出/调整条件、成本和复用边界。三者相互引用，不能用一次成功代替机制解释或跨条件验证。

Evolution 提炼、Diagnostician 独立复核，沿已有发布和证据机制进入后续冻结、检索与读取。Workflow 为可选方法，不自动成为 Controller 的全局顺序。跨任务资格使用现有权威晋升机制，负面与不确定结果保留，不建立平行资格体系。

## 修订、覆盖和验证

已有技术对象优先深化原章；独立对象才新增章节。修订保存登记前正文与元数据的准确字节，更新 catalog、来源说明哈希、导航、时间审计、VERSION 与变更清单。已存在的来源归档保持原身份。

覆盖审计同时检查能力域、具体算法与跨机制组合，区分完整解释、仅提及、缺少推导、缺少证据和缺失；篇数和术语命中不是覆盖证明。结构/身份检查、独立算法算例、运行时读取/发布测试与真实构建效果分别报告。通过前几项不能声称已证明知识改善了 Agent 的系统设计或性能。

六项标准的具体追问、组合案例、来源核对和使用效果边界见[知识内容审查](knowledge-review.md)。[Attention 模块](attention-module.md)是内容深度的已完成样例；其算法、硬件映射与组合状态按主题选择展开，不规定所有专题复制同样的结构。逐篇扩展状态见[扩展状态](expansion-status.json)，导航登记不代表深度验收完成。
