# 知识库构建 workflow 的建立与首轮执行

日期：2026-10-28。用户要求把此前逐模块构建、审查和修订的过程确定下来并自动推进。本轮将现有六项质量标准接到实际队列与登记工具，保存交付 draft5 的准确基线，按全111章建队列，再执行具体专题的修订与验收。队列创建不代表所有内容已经完成。

## 实际交付

- [构建 workflow](../../knowledge-build-workflow.md)规定输入、作者产物、非作者审查、真实检查、使用练习、登记与冻结读取，复用[构建方法](../../knowledge-method.md)及[审查逻辑](../../knowledge-review.md)。
- [队列工具](../../../tools/knowledge_build.py)保留每轮问题、审查、执行日志和当前字节绑定；支持失败修订、轮数上限、后继批次与准确状态。工具不调用模型，编写和判断由实际Agent完成。
- [登记工具](../../../tools/knowledge_release.py)从本轮基线登记实际变化，保存旧正文/元数据、维护来源说明哈希、导航、时间审计及版本。旧版一次性重建脚本不参与本次登记。结构与冻结读取实际通过后才绑定验证报告。
- 本地技能 `infraagents-knowledge-build` 已建立，知识库 [AGENTS.md](../../../AGENTS.md)也指向同一入口，避免以后重新设计流程。它服务于知识编写，不改变推理系统Controller或活动Task。

## 分工与独立复核

`/root/paged_workflow_upgrade` 作者修订分页 KV；`/root/workflow_release` 实现登记工具后领取前缀缓存作者任务；`/root/workflow_forward_test` 在隔离临时知识库中前向测试流程并非作者复核分页；主Agent维护协调工具、队列、集成与登记。共享父上下文、同一文件系统和未固定推理预算均是实际条件，不声称盲审或受控知识效果。

独立前向测试发现并推动修复两处真实问题：后继批次继承修订状态后返回旧统计；失败轮通过重提同一审查可清空失败记录并绕过预算。保留的[初次结果](workflow-tests-initial.json)、[第二次结果](workflow-tests-second.json)、[最终复测](workflow-tests.json)和[前向测试说明](workflow-forward-test.md)分别说明发现、修复和实际测试范围。测试中的审查内容是特意构造的fixture，不是技术语义验收。

## 代表性内容修订

分页 KV 补足跨页物理源到同一共享tile的完整加载映射，以及独占原地追加/共享分叉COW与不可变方案的完整对照。原地资格要求实际读写字节范围不相交；逻辑mask不能代替这一条件。[作者记录](paged/author-review.md)与[非作者审查](paged/reviewer.json)说明原两缺口在声明范围内关闭。原55项模型与新28项模型真实通过，后者含140个加载情形、864个更新组合；仍不证明实际GPU同步、并发allocator或性能。

前缀缓存通过同一队列实际领取，补齐完整页链式身份与碰撞核验、共同可恢复位置、无末行logits的安全上界，以及保护命中→完整预留→真实计算→发布→缓存保留→取消/淘汰的连续操作。五页轨迹连接缓存引用、活动请求、在途读者与重新命中；排队和复用概率分别使恢复/留存选择反转。[作者记录](prefix/author-review.md)、[非作者审查](prefix/reviewer.json)及[37项模型检查](prefix/checks.json)保留具体内容和限制。检查含320个参数化请求，整数因果递推对照独立完整前缀闭式参考，未声称真实Transformer或Radix实现已运行。

## 首批实际完成结果

`register` 从draft5基线登记draft6，分页与前缀缓存均为revision5，准确旧revision4正文/元数据进入历史；其余109篇正文和登记不变。当前111章、115个来源、237份活动历史，来源说明及归档原字节未改。`verify-release`随后真实执行[结构检查](structural.json)与[冻结读取](reader.json)，通过后两项job才进入verified。结构issues为空、3288个本地链接核对通过；读取完整覆盖两章、全部23个二级节、9份来源说明并核对当前revision/SHA，四条源码归档路径继续拒绝。未调用模型或GPU。

workflow工具[25项行为测试](workflow-tests.json)、登记工具[14项隔离测试](release-tests.json)均通过；原35项[算例](examples.json)也实际通过。当前脚本和测试绑定与报告一致，失败历史保留。两章实际执行日志与保留审查位于各自ID目录；[登记回执](release.json)与VERSION绑定当前报告。编写检查见[authoring.json](authoring.json)，仅证明其声明的编码、链接和编译范围。

本轮全库队列的结果是2项完成、109项尚未在本轮验收，不代表全库只有两项已有深度证据。全库建设状态仍有98项深度待复核，其余保留此前范围内的审查。后继批次继承未完成ID与问题，已完成内容不会因队列换批而重复增revision。内容接受与Agent使用效果分别保留；本轮没有新增learner任务，队列的使用效果字段仍为unassessed。

## 证据边界

确定化的是范围、产物、状态推进和证据核对；技术内容是否充分仍需逐题判断。没有模型API调用、后台驻留服务、自动远程发布或活动Task切换。一次运行的本地完成状态不等于完整推理系统或全库知识均已验收。设备结果、使用练习和知识版本对照各自保留实际范围。
