## 适用边界

不是所有稠密模型或 MoE 的通用优化；预测漏掉非零贡献可以改变函数和质量。原文所述带宽/速度仅用于其硬件与实验，本库不作为新任务参数。

seed 不表示当前 Task 上已实测有效；归档完整与编辑复核完成是两项不同事实。来源时间不证明模型训练实际使用该资料。

## 整篇复核后的补充边界

§8.2 指出大 batch 或长 prompt 下联合激活稀疏性下降，CPU 可成为瓶颈；§8.4 明确预测器可能遗漏活跃神经元，结果有质量波动。论文的端到端速度、硬件比较和有限任务分数不作为所有模型的无损性或新任务性能保证。
