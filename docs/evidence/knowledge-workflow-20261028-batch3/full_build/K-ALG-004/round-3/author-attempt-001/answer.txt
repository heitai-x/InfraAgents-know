  "chapter": "# K-ALG-004：Attention 的 IO、在线 softmax 与分块归约\n\n精确 attention 可以通过改变数据流避免存储完整分数矩阵；主要乘加、跨存储层级的交通、归约顺序与片上驻留分别决定成本。在线 softmax 的关键是保存可合并的统计量，并为每个块、每一行完整定义这些统计量，包括没有任何可见项的情况。\n\n## 问题、函数与状态\n\n对一个 head，令 Q ∈ ℝ^(L×d)，K ∈ ℝ^(S×d)，V ∈ ℝ^(S×dᵥ)，缩放为 a，位置偏置为 bᵢⱼ，合法 key 集合为 Aᵢ ⊆ {0,…,S−1}。定义：\n\nzᵢⱼ = a qᵢ·kⱼ + bᵢⱼ，\n\npᵢⱼ = exp(zᵢⱼ) / Σ_{k∈Aᵢ} exp(zᵢₖ)，\n\noᵢ = Σ_{j∈Aᵢ} pᵢⱼvⱼ。\n\n不可见位置不进入分子和分母。本章讨论无 dropout 的推理前向；要求可见分数和参与计算的 V 有限。输入含 NaN、正无穷或计算溢出时，应拒绝或进入另行定义的特殊值路径，不能依靠普通 max 平移自动修复。用负无穷表达屏蔽时，应先把它解释成不可见关系，而非可见的普通分数。\n\n本章规定空行输出零向量、空行标志为真、可选自然对数 LSE 为 −∞。这是明确选定的接口契约，不代表所有后端都有相同行为。d、dᵥ 和块大小为正整数；L=0 返回空输出，S=0 时所有 query 行为空行。L 与 S、d 与 dᵥ 均不要求相等。\n\n状态分三层。逻辑状态包括 Q/K/V、绝对位置、可见集合与 query head 到 KV head 的映射；数学归约状态是逐行最大值 m、归一化质量 ℓ 和未归一化加权和 U；执行状态包括 tile 缓冲、就绪事件、最后读者与槽位代次。数学统计量足以恢复输出，却不能证明某个异步加载已经完成。\n\n直接实现先生成 L×S 分数，再生成概率矩阵，最后乘 V。最终只需要 L×dᵥ 输出，中间矩阵却可能反复跨 HBM 边界。分块使局部分数和概率在片上消费；它不自动减少 QK 与 PV 的乘加，也不消除作为输入提供的逐元素偏置或 mask。\n\n## 合法条件与设计轴\n\n任何分块或分区都必须保持：每行处理的 key 子集互不重叠，并集恰好为 Aᵢ；偏置、scale、位置和 head 映射保持原函数；分子与分母使用相同可见性和最大值尺度。分区重复会重复计入贡献，遗漏会改变函数。不同 query 行可以有不同的空块，不能仅凭整个 tile 存在可见项就认为所有行都非空。\n\n因果、窗口和稀疏规则应从逻辑位置推导。L≠S 时不能默认 query 行号就是 key 的绝对位置。只在输出前乘零不能修复已经错误计算的 softmax 分母；遍历全部稠密 tile 后加 mask 也不等于跳过无效矩阵工作。\n\n可选轴包括 query/KV 切分、寄存器/共享存储/HBM 驻留、单程/两程归约、分区合并以及各阶段精度。query 块在外使本块归约状态持续驻留，KV 块在外则复用 K/V、重读 Q 和输出状态。两者可以保持同一函数，交通和并行度不同。本文的完整单程算法采用 query 块在外，不把它称作所有 FlashAttention 版本共同的循环顺序。\n\nGQA 需要显式保持 query head 到 KV head 的映射。把共享 KV 展开可以数学等价，却增加物理副本和流量。窗口、分页或量化必须分别解释其改变的是可见集合、地址表示还是数值；删除模型仍要求的 key 属于另一个近似函数。\n\n## 在线归约的状态与完整算法\n\n对已经处理的可见集合 T，非空状态定义为：\n\nm = max_{j∈T} zⱼ，ℓ = Σ_{j∈T} exp(zⱼ−m)，U = Σ_{j∈T} exp(zⱼ−m)vⱼ。\n\n空状态定义为 E=(−∞,0,零向量)。非空集合的最大项贡献为 1，故在本章有限输入域内 ℓ>0；空与非空不靠一个未初始化的最大值来猜测。\n\n合并两个非空、不重叠集合时，令 m′=max(m₁,m₂)，r₁=exp(m₁−m′)，r₂=exp(m₂−m′)，则：\n\nℓ′=r₁ℓ₁+r₂ℓ₂，U′=r₁U₁+r₂U₂。\n\n这由 exp(z−m′)=exp(mₖ−m′)exp(z−mₖ) 逐项得到。E 是合并恒等元；必须在求指数前处理空状态，避免 −∞−(−∞)。实数域中合并可交换、可结合，浮点实现只要求符合约定容差。\n\n```pseudocode\n输入：Q[L,d]、K[S,d]、V[S,dv]，a，偏置表示 b，可见性表示 A\n      正整数 Br、Bc；可选 LSE 输出\n输出：O[L,dv]、empty[L]，以及请求的 LSE[L]\n\n函数 合并(X1=(m1, ℓ1, U1), X2=(m2, ℓ2, U2))：\n    若 ℓ1=0 且 ℓ2=0：返回 (−∞, 0, 零向量[dv])\n    若 ℓ1=0：返回 X2 的副本\n    若 ℓ2=0：返回 X1 的副本\n    m新 = max(m1, m2)\n    r1 = exp(m1−m新)；r2 = exp(m2−m新)\n    返回 (m新, r1ℓ1+r2ℓ2, r1U1+r2U2)\n\n对 q0=0,Br,2Br,… 且 q0<L：\n    R = [q0, min(q0+Br,L))\n    只载入 R 内真实 Q 行\n    对每个 r∈R：X[r] = (−∞, 0, 零向量[dv])\n    对 k0=0,Bc,2Bc,… 且 k0<S：\n        J = [k0, min(k0+Bc,S))\n        载入 J 内真实 K/V；取得本 tile 所需偏置与可见性数据\n        对每个 r∈R：\n            B[r] = (−∞, 0, 零向量[dv])\n            C = {j∈J：j∈A[r]}\n            若 C 非空：\n                对 j∈C：z[j] = a·dot(Q[r],K[j])+b[r,j]\n                mb = max(z[j]，j∈C)\n                对 j∈C：w[j] = exp(z[j]−mb)\n                lb = Σ(j∈C) w[j]\n                Ub = Σ(j∈C) w[j]·V[j]\n                B[r] = (mb, lb, Ub)\n            X[r] = 合并(X[r], B[r])\n    对每个 r∈R：\n        若 X[r].ℓ=0：\n            O[r]=零向量；empty[r]=真；若请求 LSE，则 LSE[r]=−∞\n        否则：\n            O[r]=X[r].U/X[r].ℓ；empty[r]=假\n            若请求 LSE，则 LSE[r]=X[r].m+log(X[r].ℓ)\n        写回该行的输出与请求的统计量\n```\n\n每个块的每行都先构造完整 B[r]=E，只有存在可见项时才覆盖；随后每行都执行合并。因此有效块之后出现空块时，m、ℓ、U 三个分量保持不变。只设置 mb=−∞ 而不设置 lb、Ub，会消费上一块残留或未定义值。最终 ℓ=0 分支无法修复已经发生的错误合并。\n\n每完成一个 KV 块，X[r] 都代表已处理可见集合的统计量，这是逐步检查的不变量。尾块只处理真实范围，越界 key 不进入集合；空行不求最大值、指数或对零的除法。硬件采用填充 tile 时仍须保护输入地址，并保持同样的归约身份。\n\n上述算法保留局部 Ub 以直接表达合并。实际融合时可以避免第二份输出 tile：先求 m新，把旧 U 按 exp(m旧−m新) 缩放，再令 Pⱼ=exp(zⱼ−m新)，将 PⱼVⱼ直接累加进 U；ℓ 同样更新。旧状态为空时旧贡献系数取零，本块为空时直接保持旧状态。这个实现选择决定后面的驻留账能否省去独立 Ub，不能只在容量公式中把它删掉。\n\n## 两程与 split-K 的数据流\n\n两程法先求完整行的归一化统计量，再重算分数并形成输出。它使统计阶段与加权阶段分开，但需要额外的 QK 计算和 K 读取；第一程不需要读取 V。\n\n```pseudocode\n对每个 query 块：\n    第一程：初始化逐行 (m,ℓ)=(−∞,0)\n        遍历 KV 块，只读取 K 及必要偏置/可见性\n        构造本块完整空或非空 (mb,ℓb)\n        按在线合并公式更新 m、ℓ\n    第二程：初始化 U=0\n        对非空行遍历相同的可见集合\n        重新读取 K、必要偏置/可见性与 V，重算 z\n        按第一程最终 m 累加 U += exp(z−m)·V\n    非空行输出 U/ℓ；空行输出零，LSE=−∞\n```\n\n两程之间若输入、偏置或可见集合变化，就不再是同一个函数；统计阶段完成不表示第二程所需数据已就绪。它不保证总峰值一定更小，第二程仍要容纳输出累加和输入 tile，应分别列活跃集合。\n\nsplit-K 将 KV 范围分给多个任务，每个任务产生逐行 (mₚ,ℓₚ,Uₚ)，再用同一公式合并。几何分区非空，不保证某行在该分区有可见项；这种局部状态仍为 E。\n\n```pseudocode\n把 [0,S) 划成互不重叠且覆盖完整的分区 P1…Pk\n对每个 query 块、每个分区 p：\n    在 Pp 内运行单程算法，只产出逐行 (mp,ℓp,Up)，不做最终除法\n    完成后发布本分区状态；局部空行发布 E\n等待所有必要分区状态可消费\n对每行：\n    X=E\n    按确定归约树合并全部局部状态\n    非空时输出 X.U/X.ℓ；否则按空行契约输出\n```\n\n不能直接平均各分区已经归一化的输出，因为它们的全局质量通常不同。可以改用局部 Oₚ 与自然 LSEₚ 合并：先取 M=max LSEₚ，以 exp(LSEₚ−M) 为权重；空分区权重为零。但这是一种不同的状态接口，底数、空标志和精度必须同时约定。\n\n短 query、长历史时，split-K 可以增加并行任务；历史短或设备已饱和时，状态写读和最终合并可能超过收益。单设备跨 CTA 的部分状态交换是设备存储通信，不是网络流量。跨设备沿 KV 分区时，同一合并关系仍成立，但还要传递或复制 Q、交换统计量并建立完成边界；不能把单设备 IO 公式直接当成多卡总成本。\n\n## 条件化计算与交通账\n\n对完整稠密前向，主要乘加约为 F=2LSd+2LSdᵥ，乘和加各计一次 FLOP。还需按处理的分数数量付偏置、mask、指数与行归约成本，并按块付旧 ℓ/U 重标度成本。若整个无效块确实跳过，应按实际执行块重算；仅设置 mask 的稠密矩阵指令仍可能执行填充工作。\n\n标准物化路径的中间交通至少包括写 Z、读 Z、写 P、读 P。Z/P 的存储字节分别为 sZ、sP 时，这四项为 2LS(sZ+sP)，而不是无条件的 4LS 个同类型元素。softmax 多次读取、独立 mask kernel 和 GEMM 内部重读还可能增加交通。\n\n对本文 query 块在外、归约状态全程驻留且无 spill 的单程路径，令 G=ceil(L/Br)，各张量元素字节为 sQ、sK、sV、sO。仅 Q/K/V/O 主项为：\n\nD_QKVO = Ld·sQ + GSd·sK + GSdᵥ·sV + Ldᵥ·sO。\n\n它包括输入读取和输出写入，不是全为读取；它也不是总 IO。假设每个 query 块访问全部 K/V，每个对象按指定次数发出逻辑访问，忽略 cache、对齐、事务放大和尾块填充。稀疏跳块、跨 head 复用、循环顺序或资源溢出改变后，应重新列账。\n\n| 另外需要计入的对象 | 声明表示后的逻辑交通 | 条件与准备成本 |\n|---|---|---|\n| 显式逐元素偏置 | 单程、每个位置读取一次时为 LS·sb | 任意 bᵢⱼ 不能当成免费生成；广播偏置按实际索引与重读次数计 |\n| 显式布尔 mask | 每位置 sm 字节时为 LS·sm | 每行独立按位打包为 L·ceil(S/8) B；若先打包，另计原表示读取、打包写入与准备 |\n| 结构偏置或可见性 | 无须读取 L×S 矩阵，但需参数/位置读取和生成指令 | 因果、规则窗口或可公式生成的偏置可走此路径；不能外推到任意显式矩阵 |\n| 稀疏块表、页表、长度和量化尺度 | 按各任务实际消费的条目数×条目宽度计 | 扫描、排序、压紧、传输与重复取表另列，唯一表容量不等于总读取 |\n| 最终行统计量 | 输出自然 LSE 时加 L·sLSE 写入；空标志按其表示另计 | 纯推理无消费者时可不写；后向、合并或诊断实际需要时不能省略 |\n| split-K 局部状态 | 全部状态经 workspace 各写读一次时为 2kL·(sm+sℓ+dᵥsU) | 还要计分区 Q 重读、最终归约和阶段完成边界 |\n\n同一个加性输入若同时表示偏置和屏蔽，不要重复记两份矩阵读取；应按实际读取的对象计。反之，偏置与布尔 mask 分别存放，就分别加账。显式输入由前驱生成时，还要在完整调用口径中计其写出、驻留和生成成本；单程 attention 不物化中间矩阵，不能消除前驱已经定义的输入。\n\n两程法若 Q 保持驻留，主要矩阵工作变为 4LSd+2LSdᵥ；K 相对单程多读 GSd·sK，V 仍只在第二程读取。需要两次消费的显式偏置和 mask 通常也增加一遍读取；如果另存统计量或跨 kernel 执行，再计状态写读与 Q 重载。不能笼统说两程把 K/V 都多读一遍。\n\nsplit-K 若每个分区独立读取 Q，相对不拆分增加约 (k−1)Ld·sQ。局部状态峰值为 kL·(sm+sℓ+dᵥsU)，合并工作随 (k−1)L(dᵥ+1) 增长，还包括最大值、指数和最终除法。不同 query 块的归约可以独立推进，但消费者必须等待其所需分区发布，不能把 launch 返回当成计算完成。\n\n## 一个明确输入表示的 IO 算例\n\n设 L=S=4096，d=dᵥ=64，单 head，Q/K/V/O 均按 FP16 两字节存取，b=0，可见性为无需矩阵输入的全可见关系，不保存 LSE 或空标志到 HBM。主要矩阵工作为 4×4096²×64=4,294,967,296 FLOPs。\n\n若标准路径 Z/P 都存 FP16，四项中间交通为 4LS×2=134,217,728 B，约 134.2 MB；这只是中间项，标准路径的 Q/K/V/O 交通还要另加。若 Z/P 存 FP32，这一项翻倍，不能仅由输入 dtype 推断。\n\n本文单程路径取 Br=128，G=32，则 K/V 请求为 32×4096×128=16,777,216 个元素；Q 读取和 O 写入共 524,288 个元素。D_QKVO=34,603,008 B，约 34.6 MB。上述标准中间项与单程主项是不同分项，不能直接把两者的比值报告成完整实现加速比。\n\n在相同调度下增加显式 4096×4096 偏置：FP16 另读 33,554,432 B，主项加偏置为 68,157,440 B；FP32 另读 67,108,864 B，合计为 101,711,872 B。再增加独立的每位置一字节 mask，应另加 16,777,216 B；若按行紧密位打包，则读取 2,097,152 B，解包指令另计。保存 FP32 自然 LSE 则另写 16,384 B。这些数字说明：消除分数和概率中间量后，总交通仍可能包含显式输入的 LS 项。\n\n所有字节均为设定下的逻辑访问，MB 使用十进制。cache 可能吸收重读，不合并访问可能放大事务，实际 HBM 字节及耗时需设备观测。\n\n## 片上容量、准备与关键路径\n\n驻留按同时活跃对象计。采用前述直接向 U 累加的融合组织，取 Br=Bc=64，d=dᵥ=64，Q/K/V 为 FP16，分数或概率共享一份 FP32 tile，U、m、ℓ 为 FP32。Q、K、V 各 8192 B，分数/P 为 16384 B，U 为 16384 B，m/ℓ 为 512 B，总逻辑活跃量为 57,856 B。\n\n这个数成立的条件是分数存储可在指数变换后复用为 P，并且没有独立 Ub tile。若逐字实现局部 Ub 与旧 U 同时保留的伪代码，要另加 16,384 B。K/V 双缓冲再增加 16,384 B；融合组织对应 74,240 B。若流水另保留下一块 FP32 分数，还需再加 16,384 B。不能把这些不同生存期的候选混成同一容量数字。\n\n逻辑活跃量跨寄存器与共享存储分布，不能拿总和直接除某一层容量。实际寄存器、共享分配、对齐、barrier、地址、转换临时量和 spill 由映射与编译决定。更大 Br 减少 K/V 轮次，同时扩大 U/分数状态并减少独立 query 任务；更深流水增加预取窗口，也可能降低驻留。\n\n准备包括描述符、稀疏索引、页映射、布局转换、量化参数和候选选择。应说明它按形状复用、每层重做还是每 decode 步重做。首次编译/调优、稳定执行和完整服务调用分别计时；不把源级融合当成所有准备均免费。\n\n理想时间下界至少受矩阵工作/有效矩阵吞吐、实际边界字节/可持续带宽、非矩阵工作/对应吞吐约束。能够重叠的部分取资源约束下的关键路径，串行依赖才相加。同步与 launch、资源争用、尾部不均衡使实际时间高于这些下界。单设备片上共享不产生网络流量，但跨 CTA workspace、跨设备 KV 或卸载链路各有独立交通账。\n\n## 数值路径、底数与反例\n\n实数重排等价不保证逐位一致。分块、归约树、点积格式、exp 近似、概率转换、PV 累加和输出舍入都影响数值。FP32 accumulator 不能描述整条路径，概率可能在参与 PV 前已转成较低精度。参考应固定输入、scale、偏置、位置与可见集合，再按明确容差比较；NaN 和身份错误应单独失败。\n\n以 2 为底维护时，令 t=z/ln2，保留 mt、ℓ=Σ2^(t−mt)、U=Σ2^(t−mt)V。合并因子应为 2^(mt旧−mt新)，自然 LSE 为 ln2·(mt+log₂ℓ)。自然域与 2 的域混用会改变函数，不能解释成普通舍入。\n\n两块分数为 0、2，对应 V 为 1、0，正确输出为 1/(1+exp(2))≈0.1192029。第二块最大值上升后，旧 ℓ 和 U 都乘 exp(−2)。若同时把二者误乘
