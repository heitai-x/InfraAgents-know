## 从模型预测到下一步状态

扩散模型的输出可能预测噪声 ε、原始样本 x₀ 或速度 v；同样 shape 的输出不代表同样含义。令 aₜ 为训练噪声过程的累计 alpha，当前样本 xₜ=√aₜ·x₀+√(1−aₜ)·ε。归档 DDIM 实现先将所选预测表示换成共同的 x₀ 与 ε，再进行下一步更新。

噪声预测给出 x̂₀=(xₜ−√(1−aₜ)·ε̂)/√aₜ；直接样本预测给出 x̂₀ 并反推 ε̂；速度预测给出 x̂₀=√aₜ·xₜ−√(1−aₜ)·v̂、ε̂=√aₜ·v̂+√(1−aₜ)·xₜ。这些表示必须与模型训练目标一致。

```pseudocode
按离散时间策略确定本次更新的前一时间点，取得两个累计 alpha
将模型输出转换为共同的原始样本估计和噪声估计
按明确策略裁剪或阈值化样本估计；需要时从裁剪后的值重算噪声
计算本步方差与确定性方向，形成下一步样本
随机项启用时生成或接收指定噪声，并按方差尺度加入
```

令前一时间点为 t′，σ²=η²·(1−aₜ′)/(1−aₜ)·(1−aₜ/aₜ′)，则更新为 xₜ′=√aₜ′·x̂₀+√(1−aₜ′−σ²)·ε̂+σz。η=0 时这一步没有新增随机噪声，仍依赖初始噪声和模型数值路径。归档实现按训练步数与推理步数的整数比确定回退步距；其他时间表不能未经核对直接替换。

## 成本与合法比较

少求解几步会减少模型调用，但也改变质量/成本关系；预测类型、时间表、裁剪、guidance、初始噪声与随机流都属于比较条件。把噪声预测误作样本预测，会在 shape 完全相同时改变函数。固定同一模型输出与噪声，可以逐步对照 x̂₀、ε̂ 和更新结果，区分求解器语义错误与模型误差。见[图像扩散](../models/image-diffusion.md)。此处是归档算法与独立代数解释，不是质量或性能实测。
