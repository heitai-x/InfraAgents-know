# K-ALG-009：异构状态缓存：层组、恢复位置与联合分配

混合模型的缓存是多类状态的联合系统，统一的是逻辑恢复位置，物理块形状可以不同。

## 将缓存描述成状态族

全注意力保存越来越长的 KV；窗口注意力只需直接可见的最近历史；MLA 保存压缩 latent 与位置分量；SSM 保存递归状态和局部卷积历史。encoder context 又是固定只读状态。用统一的“每层同样 KV 页”表示会掩盖长度、形状和更新方式的差异。

可以按状态类型、dtype、每 token 字节、块长、层数和保留规则分组。对组 g，token block 长 Pᵍ、每 token 全组字节 cᵍ，则块容量为 Pᵍcᵍ；递归组的检查点则按一次完整状态的字节计。总容量是各池驻留块之和，加上共享元数据和临时分叉。

## 物理池的三种组织

| 组织 | 好处 | 代价 |
|---|---|---|
| 每状态族独立池 | 布局直接，生命周期清楚 | 某池闲置而另一池耗尽 |
| 同字节尺寸统一块池 | 容量可跨族调剂 | token 块长不同，映射复杂 |
| 大块内子分配 | 兼容不同尺寸 | 碎片、回收和对齐账务增加 |

若为了统一字节块取各组单位尺寸的最小公倍数，必须计算真实 LCM。384 与 512 的 gcd 是 128，LCM 为 1536，而非乘积 196608。这还仅是两个单位大小的共同倍数，不说明它就是最佳页：层数、对齐要求、窗口长及内核支持可能让统一策略不合算。用更大块减少元数据时，要同时计算尾部浪费和回收粒度。

## 恢复状态是集合问题

对每一状态族定义可恢复位置集合 Rᵍ。模型可恢复位置属于所有 Rᵍ 的交集。全注意力页可能覆盖连续前缀，递归状态只保存在稀疏检查点，窗口状态还需包含恢复点之前的完整可见窗口。一个 token 前缀哈希命中并不构成全模型恢复资格。

例如全注意力已有位置 0–1023，递归检查点仅有 512 与 768，窗口池只保留 640–1023 且窗口 128。768 可恢复需要相应窗口历史存在；512 即使有递归检查点，也缺少窗口内容。最长可继续的公共位置由这些条件共同得出。

## 联合分配与淘汰

一次请求推进需要多个池都获得资源。若先占住 A 池再等待 B 池，而另一个请求反向占用，会造成容量僵局或饥饿。设计可以先计算完整资源向量并原子预留，或让失败预留可完全回滚。这里的原子性是调度事务语义，不要求一个硬件原子指令。

淘汰时也要维护可恢复组合。删除一个共享前缀的递归检查点，可能让大量保留 KV 失去继续执行价值；只按单池 LRU 看不出这种损失。对状态包按可恢复位置计价，比简单追求各池局部命中率更接近真实重算收益。

## 一个混合状态包的完整容量

以下为结构设定：8 层全 attention、8 层窗口 attention、16 层递归层；attention 每层 Hkv=8、d=128、K/V 为 2 字节，当前前缀 4096 token，窗口 256。全 attention 每 token 的 8 层共 32 KiB，保留前缀占 128 MiB；窗口层共占 8 MiB。递归层每层 4096×16 个 FP32 状态、另保留 3×4096 个 BF16 卷积历史，16 层共 4 MiB+384 KiB=4.375 MiB。完整可恢复状态主项为 140.375 MiB，另计页尾、metadata、RNG、在途对象与恢复暂存。

该例中删去递归的 4.375 MiB 虽只节省少量 bytes，却可能使保留的 136 MiB attention 状态无法从原位置继续。跨池淘汰要考虑一份状态的删除对整个恢复包的影响。保留两份不同位置的递归检查点也不意味着全模型有两处可恢复点，窗口历史与完整 KV 必须分别覆盖。

## 跨层卸载与恢复事务

按层调度可在执行当前层时预取下一层的状态；对单步 decode，每层只需自己的状态到达即可计算，但下一请求步仍依赖所有层的该步更新。恢复包可以逐对象传输，发布“模型可从 p 继续”的资格却需要全部必需对象到齐、验证身份、建立可见性并完成联合容量预留。这样允许传输流水，同时保留清楚的最终提交边界。

只读全 KV 旧前缀、会覆盖的环形窗口、递归与卷积状态，分别需要 append-only 范围、稳定窗口快照和步骤快照。不能先复制一部分递归层、让源继续更新，再把剩余层拼成一个看似完整的检查点。可暂停于同一完成位置，或让后续写入与被复制快照分离；选择由额外容量与停顿目标决定。

目标先为各池及转换工作区预留资源，失败时撤销本次尚未发布对象；源在接管完成前保留恢复能力。若只成功收到全 KV、窗口或递归之一，应明确缺失集合并选择补传、从更早共同点重放或终止。已有完整状态被回收、迟到 DMA 写入复用槽、一次重试重复增加引用，都是必须独立验证的失败窗口。

性能以恢复到第一个正确继续步骤的时间计，不以最早完成的单池传输计。观测各池占用、可恢复共同位置、不可用残片与重算长度；当稀疏检查点使命中回退很远时，增加检查点可能比多保留单池 KV 更有价值。对很少复用的工作负载，快照成本也可能超过节省的重算。
