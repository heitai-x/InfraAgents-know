# K-ALG-006：投机解码：分布保持、状态提交与收益模型

投机解码用较便宜的过程提出多个候选，再由目标模型并行验证，把单条请求的部分串行步骤换成并行宽度。收益来自每轮确认多个输出；代价包括草稿、未采用的验证计算、状态恢复、额外驻留和对其他请求的挤占。决定后续历史的是确认路径，物理写入过缓存并不等于可以提交。

## 问题、分布契约与状态

设已确认前缀为 H，目标在前缀 h 下规定的下一 token 分布为 p(·|h)，实际草稿提议分布为 q(·|h)。链式回合的名义候选预算为 γ≥0；未截短时产生 x₁,…,xγ，并取得 γ+1 个条件分布：pᵢ=p(·|H+x₁:ᵢ₋₁)，qᵢ=q(·|H+x₁:ᵢ₋₁)。首次拒绝前接受 n 个候选时，输出 x₁:ₙ 加一个修正 token；全部接受且未终止时，再从末端分布产生 bonus token。无提前停止时，回合产出 ℓ=n+1。遇到终止、输出预算或目标非法草稿后缀时，实际候选、输入行和所需分布分别截短，不能继续把它们都计为 γ。

输入包括目标与草稿各自的模型、adapter、数值配置、采样变换，确认前缀及模型状态，γ 或树预算、grammar 状态、随机流和输出预算。输出包括确认 token、共同提交后的状态、临时对象的回收责任，以及接受长度和成本观测。

分布契约需要区分两种一致性：

- pᵢ 必须来自规定的目标采样契约；qᵢ 必须准确描述实际产生候选的提议过程。二者分别绑定各自稳定的模型、adapter、精度和变换，不能在生成候选后用另一个 q 计算接受率。
- pᵢ、qᵢ 对应同一逻辑条件前缀，并在可比较的 token 空间上定义。相同模型、精度、temperature 或截断方式均为可选配置，不是分布保持的必要条件。不同 tokenizer 需要先建立明确的提议及概率映射，不能直接比较同编号 token。

目标的 temperature、惩罚、top-k/top-p、grammar 及其顺序共同定义 p；草稿可以采用不同变换，但接受与残余修正必须使用变换后的实际 q。已确认且尚未终止的前缀若没有可归一化的目标合法质量，应进入规定的失败或恢复分支，不能静默抽取非法 token。草稿提出目标概率为零的 token 可以合法发生，接受概率为零即可；其后的草稿前缀不可因此被要求也具有目标分布。

请求状态至少区分：已确认 token 序列及长度 L；所有必要层状态共同有效的输入消费边界 K；物理预留和存活对象的容量 A。全 attention 模型中，K 表示前 K 个 token 的全层 KV 可见；递归模型则要求对应位置的完整递归、卷积和窗口状态。通常 0≤K≤L。一个新输出 token 可能已经 known，却尚未作为模型输入，因此没有自己的 KV。

容量 A 按物理对象并集计字节，不能与 token 长度直接比较。共享前缀只计一份；预留池及池内对象不能重复计量；在途读者仍占用的拒绝页也不能提前扣除。

正确性要求同时保持目标输出语义、条件前缀、位置与行映射，以及 KV/递归状态、grammar、输出游标的共同提交边界。随机流还要保证提议、接受和重采样所需的独立性；不能把随机数计数简单等同于已输出 token 数。

## 接受、残余修正与支持集

以下推导在精确概率算术下成立。设 p、q 是同一有限 token 空间上的任意归一化分布。先提出 x∼q，对实际提出的候选计算

 a(x)=min(1,p(x)/q(x))。

候选来自 q，所以求比值的位置必有 q(x)>0。若记录的 q(x)=0，却声称该候选由 q 抽得，说明提议记录与实际过程不一致；这与允许词表其他位置 q(u)=0 是两回事。

令 β=Σᵤmin(p(u),q(u))，Z=Σᵤ[p(u)−q(u)]₊=1−β。拒绝时从完整 token 空间上的残余分布

 r(u)=[p(u)−q(u)]₊/Z

抽取修正 token。接受分支给 u 的质量为 min(p(u),q(u))；拒绝分支给它的质量为 Zr(u)=[p(u)−q(u)]₊，两者之和正是 p(u)。因此不要求 q 覆盖 p 的正支持。q(u)=0 且 p(u)>0 的质量通过残余分支恢复，不能把残余归一化范围截成草稿候选集合。

反例可以直接算清：p=(1/2,1/2)、q=(1,0)。草稿总提出 a，以 1/2 接受；拒绝概率为 1/2，残余分布必选 b，最终仍为 p。确定性 lookup 的单点提议或截断草稿因此不会仅因支持较小而非法。

两个边界进一步区分该协议与普通拒绝采样。互斥支持时 β=0，所有候选被拒绝，r=p，仍保持分布，但没有候选接受收益。p=q 时 β=1，拒绝事件概率为零，不应计算或采样除以零的残余分布。有限精度实现若在此时进入拒绝分支，需要检查舍入、概率记录或采样比较，不能以任意 fallback 掩盖不一致。

greedy 可直接逐位比较目标 argmax：匹配则保留，首次不匹配输出目标 argmax，全部匹配则从末端分布取 bonus。目标平局规则、禁用 token 和停止规则必须固定。temperature=0 应有明确的 greedy 定义，不能通过除以零实现。也可把确定性 argmax 表达为单点概率分布，但实现必须保留同样的平局语义。

精确分布等价不保证相同 seed 下文本逐 token 相同。提议、接受和重采样改变随机数消耗路径；seed 不能单独保证跨执行路径、平台或版本逐位一致。真实并行前向还可能改变浮点归约顺序：应声明目标参考函数及数值合同，不能把精确概率证明当作任意低精度实现的逐位证明。

## 输入行、可见 KV 与输出 logits

必须分别回答四个问题：本行输入哪个 token；本行读取哪些 KV；本行输出哪个条件分布；验证一个候选应该取哪一行。

令 H 长 m，root 表示确认前缀末行。链式候选 xᵢ 的输入行位于逻辑位置 m+i−1，读取确认前缀和 x₁,…,xᵢ，包含自身 KV；该行输出 pᵢ₊₁ 所需的原始 logits，而不是 pᵢ。验证 x₁ 用 root 的 logits，验证 xᵢ（i>1）用 xᵢ₋₁ 行的 logits。未截短时，xγ 行提供全部接受后的 bonus 分布所需 logits。原始 logits 的产生与按某个前缀形成合法概率分布是两个阶段；后者只在该条件前缀可达且需要继续采样时执行。

树中令 A(v) 为不含 v 的严格祖先路径，row(v) 为候选输入行。该行的合法可见集合是 H∪A(v)∪{v}，逻辑位置为 m+depth(v)−1。它输出 p(·|H+A(v)+v) 所需 logits。验证 v 则取父节点行的输出；若父节点是 root，就取确认前缀末行的输出。兄弟、堂兄弟和后代均不可见。不同分支同深度可以具有相同逻辑位置，物理行号不等于位置编码输入。

以下逐层关系解释为什么屏蔽自身 key 无法把节点行变成父行。以常见的 pre-norm decoder block 为例，候选 v 的初始 hᵥ⁰ 来自 token embedding 和该模型的位置规则。第 l 层先从 hᵥˡ 经归一化、投影和位置处理得到 Qᵥˡ、Kᵥˡ、Vᵥˡ；历史 KV 来自此前在同层计算的相应前缀状态。对可见集合 M(v) 计算

 sᵥᵤ=Qᵥˡ·Kᵤˡ/√d，wᵥᵤ=softmaxᵤ∈M(v)(sᵥᵤ)，aᵥ=Σᵤ∈M(v)wᵥᵤVᵤˡ。

随后经过输出投影、残差以及模型规定的归一化和 MLP，得到下一层输入 hᵥˡ⁺¹。各候选在每一层先从该层输入产生自己的 Q/K/V，再按可见集合计算输出；下一层消费这些输出。不能把某层祖先的最终 hidden 当作所有层的 KV。不可见位置应从归一化集合排除或采用等价加性遮罩，仅将 score 乘零不能保证概率为零。

即使排除自身 K/V，节点 v 的 embedding、query 和残差仍含 v；同时遗漏自身还破坏正常 causal attention。因此修复 logits 偏移应改父行索引，不能修改 mask 来伪造父前缀。完成全部必要层后，末层 hidden 经模型规定的 final norm 与 LM head 生成下一位置 logits，再在需要该分布时按对应父前缀应用目标采样变换。

这也固定了未截短回合的计算口径：若 root logits 与全部 H 的状态已有效，γ 个链候选只需新增 γ 个模型输入行，却可取得 γ+1 个条件分布。若上一轮新输出的末 token 尚无状态，则还要计算该 root 输入行，新增行为 γ+1。树有 N 个非 root 候选时对应 N 或 N+1 行。已有完整 KV 却缺少兼容 root logits 时，可在私有写区使用 H 的前 m−1 个状态重算末 token；不能重复追加它或覆盖共享页。缺失更长状态后缀时，应先按已知 token 完成必要 prefill。约束路径截断后的实际输入行数按下一节的 s 计量。

## 链式回合与共同提交

下述算法把 root 准备与候选事务分开。root 准备只消费已经确认的 token，可以独立推进 K；候选计算的状态在接受决定前保持临时。

先区分三种状态。已确认前缀本身没有合法延伸且请求尚未终止，是目标生成合同的真实失败。草稿某个 token 不被目标 grammar 允许，则它在合法父前缀下的目标概率为零，必被拒绝；它之后的 grammar 死前缀不需要目标分布。grammar 已接受当前文本也不必等于终止：例如允许 a 与 ab 时，在 a 后仍可继续；只有 EOS 或声明的实际停止规则结束生成。

本章选择先检查目标 grammar 路径、截短模型输入，再延迟形成目标概率分布。路径检查完整消费每个候选的 token 展开，保留仍可完成的解析配置；不只是检查首字符。首次非法候选 j 仍保留 xⱼ 与实际 qⱼ，用其父分布 pⱼ 验证和修正，但不把 xⱼ 或其后缀送入目标前向。于是只需输入 x₁:ⱼ₋₁；pⱼ 来自 root 或 xⱼ₋₁ 行。合法终止候选则保留自身输入行，在它之后停止准备；这是便于提交该候选全层状态的选择，不能再消费其后继分布。非法判定先于终止判定，非法 EOS 也不能直接结束目标请求。

令 g≤γ 为实际生成的草稿数，c≤g 为保留到首次非法候选、目标终止候选或列表末尾的扫描长度。若第 c 个候选非法，目标候选输入数 s=c−1；否则 s=c。即使原始模型可以对任意 token 串产生 logits，也不能因此对 grammar 死前缀归一化。对 grammar 合法但被目标其他变换置零的候选，同样在接受扫描时拒绝，不再构造其后继目标分布。

```pseudocode
算法 链式投机一轮
输入：非空确认前缀 H，目标/草稿各自的配置，状态 S，候选预算 γ≥0，剩余输出预算 M≥0
输出：确认输出、共同状态、待回收对象

准备 root：
  若输入为空，按模型合同补 BOS 或拒绝请求
  若 M=0 或请求已终止，直接结束，不准备后续分布或候选
  用已确认 token 补算缺失的目标状态后缀
  若状态完整但缺少兼容 root logits：
    使用 H 去掉末 token 的历史，在私有写区重算末 token
  等全部必要层完成后，保留 H 的完整状态和 root logits
  保存共同起点 S0；此时 K=|H|
  用 H 的正式 grammar 与目标变换形成 p₁，并保留以供复用
  若该非终止前缀没有可归一化的目标合法质量：返回真实失败，不产生输出

草稿：
  candidates、q_records ← 空；草稿私有状态从 H 准备
  对 i=1..min(γ,M)：
    若草稿已终止或合法提议过程没有后继：停止本轮提议
    h ← H + 已生成候选
    用草稿自己的配置与私有状态产生实际 qᵢ
    校验 qᵢ 非负、归一化且可在共同 token 空间解释
    从 qᵢ 抽取 xᵢ
    记录 xᵢ 及足以恢复该次完整 qᵢ 的信息
    推进草稿私有状态；不得推进正式输出或正式 grammar
    若 xᵢ 触发草稿自己的终止规则：立即停止，不构造后续 q
  g ← 实际候选数；γ=0 或无提议时允许 g=0
  数值错误、错误身份或伪造的 q 不属于正常的提议停止

检查目标路径：
  G ← S0 的目标 grammar 私有副本；c←0；s←0；末候选非法←假
  依次检查实际候选 xᵢ：
    c ← i
    若完整目标 grammar 转移非法或转移后无可完成配置：
      标记 xᵢ 在合法父状态 G 下的目标概率为零
      保留 (xᵢ,qᵢ) 和父状态 G；末候选非法←真
      不建立它的后继 grammar，不检查其后缀；停止路径检查
    保存合法转移后的私有 grammar 状态；G←该状态；s←i
    若该合法候选触发目标 EOS、实际停止规则或输出预算：
      标记目标终止边界；停止路径检查，不准备后继状态
  无候选时 c=s=0
  其余草稿候选仅为已生成但不会被目标消费的临时对象

目标前向：
  只将 x₁:s 的 s 个输入行放入临时区
  每层为 xᵢ 构造 H + x₁:ᵢ 的可见集合，包含自身
  按逐层 hidden→Q/K/V→attention→下一层 hidden 计算
  保存所需原始 logits 或可恢复 logits 的 hidden，不预先变换全部后缀
  验证 x₁ 的来源为 root；验证 xᵢ 的来源为 xᵢ₋₁ 行
  即使 x_c 非法，验证它所需的父行仍然存在；不需要 x_c 输入行
  等待完成证据覆盖实际执行行的必要层、状态及所需输出
  实际执行失败、身份失效或已取消时：不发布候选结果，保留 S0 并排空使用者

接受：
  n←0；t←不存在；接受候选终止←假
  对 i=1..c：
    此时只有此前候选全部接受，才到达当前父前缀
    i=1 时复用 p₁；否则按该父前缀的目标变换和合法 grammar 形成 pᵢ
    可达且非终止父状态若无合法质量：按目标合同返回真实失败
    确认记录的 qᵢ(xᵢ)>0
    U←与提议及此前接受判断独立的均匀随机数，取值于 [0,1)
    若 U < min(1,pᵢ(xᵢ)/qᵢ(xᵢ))：
      n←n+1
      若该候选触发目标终止或输出预算：
        接受候选终止←真；停止扫描，不产生 bonus
    否则：
      在完整 token 空间形成 R=norm([pᵢ−qᵢ]₊)
      该可达拒绝分支要求残余总质量大于零
      从 R 抽取 t；停止扫描，不构造 pᵢ₊₁ 或更后分布
  若没有拒绝且没有接受候选终止：
    n=0 时复用 p₁；否则从 xₙ 行形成其后继目标分布
    从该分布抽取 bonus t；不为 t 准备后继分布

提交：
  known ← H + x₁:ₙ + t（若存在 t）
  从所有必要层选取恰好消费 H + x₁:ₙ 后的状态
  对 append-only KV，逻辑有效边界 K ← |H|+n
  对递归/窗口状态，恢复该边界的快照或从共同起点重放
  grammar 从起点沿确认输出推进，输出游标推进相同 token 序列
  根据确认输出记录实际终止原因；草稿私有终止不自动终止目标请求
  提交本轮随机流计数与请求代次，保持后续随机数独立
  t 若存在，已确认但尚未作为输入；此时 K=|known|−1
  若接受候选自身终止且无 t，则 K=|known|
  其余候选状态立即失去逻辑可见性，最后使用者结束后才回收物理空间
```

草稿停止只结束本轮提议，不取消目标校正。草稿在自己的约束下无后继时，可以用已经生成的 g 个候选继续验证；g=0 退化为直接目标采样。草稿自己的终止 token 若在目标下非法，应被拒绝；若在目标下合法但并不触发目标停止，全部候选接受后仍可产生 bonus。停止规则、EOS 是否占逻辑输出预算及是否显示为文本，由目标输出合同固定，不能由草稿决定。

一个确定性反例可以验证顺序。取合法 H，目标 grammar 只允许下一个 token 为 a，因此 p₁=(1,0)；草稿无此约束，q₁=(0,1)，γ=2，已经提出 b,b。目标路径检查在首个 b 截断，得到 g=2、c=1、s=0。p₁ 来自 root，a₁(b)=0；用严格比较 U<0 必然拒绝。完整残余为 norm((1,0)−(0,1))₊=(1,0)，输出 a。known 变为 H+a，K 仍为 |H|，grammar 只确认 a；两个 b 都不能发布。不构造或消费 p(·|H+b)，因此该死前缀无法阻止可达的修正分支。若先对全部草稿后缀做 grammar 归一化，就会在输出 a 之前失败，这是必须被检查拒绝的错误变体。

γ=0 退化为从 root 分布产生一个普通目标 token。n+1 产出适用于存在修正或 bonus 的回合；若已接受候选本身触发终止，产出为 n，不再加一。接受的终止候选在本算法中已有全层输入状态，可以 K=L；从修正或 bonus 抽出的终止 token 仍未作为输入，可以 K=L−1。若请求已经结束且只需返回输出，没有必要为后者补算 KV。

设 H 长 5，候选为 x₁、x₂、x₃，root logits 已保存且目标路径未提前截断。新增输入行为 3：x₁ 行产生 p₂ 所需 logits，x₂ 行产生 p₃ 所需 logits，x₃ 行产生 p₄ 所需 logits。若只接受前两个，用 x₂ 行形成 p₃，与 q₃ 修正得到 t。提交后 known 长 8，K=7；保留 x₁、x₂ 的全层 KV，丢弃 x₃，t 等下一轮输入。将 K 写成 8 会跳过 t 的模型计算；提交 x₃ 则会读取错误分支。下一轮通常需计算 t 这个 root 行，再验证新候选，该成本不能遗漏。

对递归或混合模型，“接受两个”必须选取消费两个候选后的完整状态。只把消费三个后的长度改小不能恢复递归张量；窗口槽若已覆盖旧值，也需要快照或可重放起点。若完整递归/卷积状态大小为 Bₛ，逐候选保存 s 个额外边界的驻留约为 sBₛ，还产生写流量；仅保留起点则减少快照，但接受后需重放 n 步。两种选择按接受分布和实际状态读写成本比较。

随机状态不能机械地回退到“与普通解码消耗相同的随机数数目”。一种实现是为请求、回合及角色分配独立随机子流，记录实际消耗计数；被丢弃草稿已消耗的随机数可以保留为已消耗。若回退随机状态后重试，还必须避免反复使用同一随机结果造成条件选择偏差。grammar 与模型路径需要恢复，随机计数则遵循明确的随机协议。

提交应在同一请求状态事务内发布：先确认全层状态、保留路径、grammar、随机协议状态和输出均就绪，再允许下一轮读者读取。取消立即撤销未来提交权，但不自动终止已提交的设备工作。旧代次完成不能重新获得提交权；物理页、图缓冲和传输源须等待各自最后读者结束。共享前缀的可变尾页需要私有写区或写时复制。

## 树形验证与可实现的选择协议

树 attention 只负责同时计算各条路径的目标状态，不自动证明路径选择保持分布。对每个孩子独立执行链式接受公式，再任选一条通过路径，通常会改变输出概率。树还需规定候选生成、顺序、重复候选、拒绝后的分布更新以及回退规则。

下面给出一个完整且保守的协议：将已建好的每个父节点的孩子看作有序的、互异的确定性提议，每次提议的 q 是该 token 的单点分布。树可以来自草稿模型或 lookup，但验证随机数独立于建树随机数；孩子顺序不能根据尚未消费的验证随机数挑选。本协议是本章的推导，用于明确一种合法实现，不声称等同于 EAGLE 的具体重采样实现。

在父路径下令初始工作分布 r=p。依序尝试孩子 token c：以 r(c) 接受；若拒绝，将 c 的质量删除并重新归一化，即 r←norm([r−δc]₊)。若所有孩子都拒绝，从最终 r 抽一个 token 并结束本轮；若接受孩子，则进入该孩子，使用其输入行输出的下一位置目标分布继续。叶子没有孩子，直接从叶子行分布抽 bonus。

证明可按固定孩子顺序展开。到达第 j 个孩子前的生存质量为 1−Σₖ<ⱼp(cₖ)，当前 r(cⱼ)=p(cⱼ)/(1−Σₖ<ⱼp(cₖ))，因此在该孩子处输出 cⱼ 的无条件质量是 p(cⱼ)。全部拒绝后的质量为未列孩子集合的目标总质量，乘最终残余分布正好恢复这些 token 的 p。拒绝概率为零的分支不可进入。每一父路径上都恢复目标条件分布，递归后便恢复整条输出序列的目标分布。

```pseudocode
算法 树形目标前向与有序单点提议验证
输入：H、root logits、有限候选树 V、父指针、每父节点的孩子顺序
输出：确认路径、最终修正/bonus token、共同状态

检查树：
  父指针必须无环且连到 root
  同一父节点下按 token 去重，保留规定顺序
  建立 node→输入行、父节点→logits 行、逻辑深度→位置的映射
  按目标 grammar 检查各父路径；非法边的后代不准备后继 grammar 或目标分布
  合法终止节点不扩展；非法孩子仍可在合法父分布下以零概率接受

目标前向：
  对保留的候选输入节点 v，允许读取 H、严格祖先及自身的 KV
  每层从本层输入 hidden 产生所有保留候选的 Q/K/V
  用构造的可见集合实际执行 attention，产生下一层输入
  经所有必要层与 LM head 得到每节点之后的原始 logits
  等全层状态与所需输出共同完成；保持所有候选状态临时

选择：
  u ← root；path ← 空
  循环：
    只有当前父路径可达且未终止，才应用该路径的目标变换形成 r
    chosen ← 空
    按顺序遍历 u 的孩子 v：
      c ← token(v)
      U ← 新的独立均匀随机数，取值于 [0,1)
      若 U < r(c)：chosen ← v；停止孩子循环
      否则：
        r ← norm([r−δc]₊)
        此拒绝事件若可达，归一化总质量必须大于零
    若 chosen 为空：
      t ← 从 r 抽样；停止选择循环
    path 追加 chosen
    若 chosen 的 token 触发终止或输出预算：结束且不抽额外 token
    u ← chosen

提交：
  从所有必要层共同选取 path 对应的状态及路径顺序
  known ← H + path 的 token + t（若存在 t）
  t 若存在则尚未作为输入，不具有自己的 KV
  恢复并提交同路径 grammar、随机协议状态和输出
  未保留节点及后代失去可见性；最后使用者结束后回收
```

例如 root 有孩子 A、B，A 有孩子 C。A、B 的输入行都读取 H 和自身；C 读取 H、A、C。A 与 B 都由 root 分布验证，C 由 A 行分布验证。若路径为 A、C，则 C 行提供后续分布。全层提交只收集 A、C 的状态，不能因物理行连续而收集 A、B。

上述树协议不消费原始草稿 q 的概率，只把树作为确定性候选列表。若要利用其他多候选提议协议取得更高接受收益，必须另行解释其实际提议分布及逐次残余更新，不能将本协议的证明移用于任意 top-k 树。

## 草稿来源与条件化成本

独立小模型增加草稿权重加载、驻留及可能的跨设备传输；n-gram 或 prompt lookup 将草稿降为查找和复制，但匹配、建树、概率记录及验证仍有成本，不能严格称为零成本。确定性 lookup 可以用单点 q，由完整残余修正保持目标分布，接受收益取决于目标给该候选的概率。

EAGLE v1 在 LM head 前的目标特征上进行草稿自回归，并输入提前一步的已采样 token，使下一特征预测能区分采样造成的不同路径。它以树 attention 验证候选，并在各层递归应用采样或分布修正。该来源支持特征草稿和树预算的机制，不取消父行 logits、实际分布和共同提交要求。其链式接受率与树形产出不能混用；树处理更多 token，MoE 验证还可能触及更多专家权重。

设 D(γ)、V(γ)、H(γ) 分别为同一回合的草稿、目标验证及管理成本，单位为时间。若这些阶段在该测量范围内串行，单位确认 token 时间约为 (D+V+H)/E[ℓ]；若存在重叠，应使用实际依赖关键路径，不能把重叠时间直接相加。只有在相同请求集合、质量、batch 条件与 SLO 下优于普通目标解码，才构成收益。

在固定 γ、没有提前停止的范围内，不依赖 i.i.d. 假设的产出恒等式为

 E[ℓ]=1+Σᵢ₌₁^γP(n≥i)。

若各步接受事件可用独立、固定接受率 α 近似，则 E[ℓ]=Σᵢ₌₀^γαⁱ=(1−α^(γ+1))/(1−α)，α=1 时为 γ+1。真实接受事件依赖前缀和草稿误差，应记录接受长度分布与逐深度生存概率。EOS、输出上限及短请求会截短产出，不能继续无条件套用长生成公式。对包含提前停止的本章状态机，可统一写 ℓ=n+Iₜ，Iₜ 表示是否实际输出了修正或 bonus；据实际分布取期望，不再强行令 Iₜ=1。

论文的简化墙钟模型设一次验证与一个普通目标步耗时相同、草稿每步耗时为目标的 c 倍，得到 S=E[ℓ]/(1+cγ)。在该模型中 α>c 时 γ=1 已有收益，但不意味着更大的 γ 总更好。真实模型应改用 S=E[ℓ]/(d(γ)+v(γ)+h(γ))，各项均以同条件普通目标步时间归一化。

算术量需按输入行重新列账。令 B 为每个目标输入行的近似算术量，R 为本回合补算 root 的行数，则未截短链式目标新增量约为 (γ+R)B，另加草稿和 attention 随长度变化的部分。R=0 表示已保存 root logits，典型跨回合状态 R=1；树将 γ 换成实际输入节点数。论文在其 γ+1 次目标求值口径下得到算术量因子 (γĉ+γ+1)/E[ℓ]，ĉ 为草稿与目标每步算术量比。不能把这个公式误写为“已有 root logits 时仍需 γ+1 个新候选输入行”，也不能在 R=0 的局部回合里漏掉产生 root 的前次工作。

路径截断后，草稿按实际 g 个提议列账，目标新增输入按 s+R 行列账，目标概率变换按实际到达并消费的父分布数列账，root 的 p₁ 形成后复用。首个目标非法候选 j 对应 s=j−1；本算法保留合法终止候选自身输入行，所以终止位置 τ 对应 s=τ，但不归一化其后继分布。此前已经生成的草稿后缀仍付草稿成本；已经提交执行的额外模型行或图 padding 也必须照实计费，不能因后来丢弃而从记录中删除。若选择另一种提前提交全部原始行、只延迟概率变换的实现，语义可保持，但输入行、KV、完成等待和峰值容量须按那条实际路径重新计算。

| 类别 | 同一候选上的成本与条件 |
|---|---|
| 计算 | 实际 g 个草稿提议；s+R 或实际树节点数加 R 个目标输入行；attention、LM head、实际消费分布的接受与残余归一化。目标已饱和时额外行会挤占其他请求。 |
| 访存 | 目标权重可能在多行间复用；每行仍读其可见 KV，并写临时候选 KV。链中 s 行的可见对数为 sm+s(s+1)/2，树中为实际输入节点上的 Σᵥ(m+depth(v))，均是逻辑配对数，不等于 DRAM 事务。 |
| 通信 | 分设备草稿传输候选、概率或特征；目标 TP/EP 的通信随实际行数与专家集合变化。词表分片的残余质量需全局归一化，不能各片独立归一化后拼接。 |
| 准备 | lookup、建树、目标 grammar 路径检查、父行映射、mask、packing、图桶、快照和草稿启动。路径检查仅遍历到首次非法或实际终止位置；固定形状仍须记录有效行与真实物理执行范围。 |
| 同步 | 草稿依赖、目标实际执行范围的全层完成、接受扫描、共同提交及最后使用后回收。同请求的确认依赖不能由异步接口消除。 |
| 驻留 | 草稿权重、实际提议记录、候选 KV、特征、快照、logits、mask 和 workspace；共享对象按并集计量，驻留可能降低最大 batch 或触发驱逐。 |

对全 attention 模型，设每 token 全层 KV 字节为 BKV=2ΣₗHkv,ₗdₗbₗ，bₗ 是每元素实际存储字节，另计量化元数据。链式候选的临时 KV 约 sBKV，树按实际输入节点计；接受 n 个时，约 nBKV 进入可见历史，其余等待安全回收。root 准备另按是否新增或私有重算计量。递归快照、窗口保护和分页碎片不能混入这个理想 KV 公式。

完整残余需要全 token 空间上的 p、q，但不强制永久保存所有浮点向量。保存 g 个实际提议的全分布约占 O(g|𝒱|) 元素；也可保存足以恢复实际分布的 logits/变换记录，拒绝后重算，或利用单点、稀疏 q。仅保存候选自身的 qᵢ(xᵢ) 不足以计算一般完整残余。重算必须重现原提议分布。目标可保留全部实际输入行 logits，或保留必要 hidden 后选择性计算 LM head，二者交换驻留与计算。稀疏 q 不允许忽略目标在其支持之外的残余质量。

设定算例：普通每 token 10 个时间单位，γ=4 时一轮草稿 8、验证 13、管理 3、平均产出 3，则单位成本为 24/3=8，吞吐比为 10/8=1.25。batch 扩大后普通目标单位成本降为 6，同配置反而变慢；平均产出若升至 4，也仅为 24/4=6、刚好打平。这是合成计算，不是设备测量。

## 预算调整与失效条件

保留的是目标契约、父前缀和共同提交规则；调整的是草稿来源、γ、树宽、图桶及状态恢复策略。可以按近期接受长度分布与实际关键路径成本比较候选，在低接受收益、目标 batch 已饱和或草稿争用关键资源时降低预算或关闭投机。

深度增加提高连续覆盖机会，也增加首次拒绝后的浪费；宽度增加扩大某个父路径的候选覆盖，同时增加验证行、logits 和无效分支。递归模型可能因快照写流量而偏好较浅候选，长上下文可能因 attention 读量而偏好更小树。模型、adapter、精度或目标变换改变后，需要重新验证分布身份并重新估计成本；仅接受率下降不意味着协议非法，但旧运行点可能失去收益。

目标 grammar 与草稿约束差异变大时，可以让草稿采用兼容约束以减少必拒候选，或提前进行廉价路径检查；这改变的是成本和接受收益，不是要求二者必须采用相同变换。频繁接近 EOS 或输出上限时，应缩短候选预算。若使用固定图桶，仍保留真实路径边界；图多算的行不能进入分布消费或正式状态。

多请求服务应比较整体 goodput、尾延迟、公平性和容量。单请求多产出几个 token，可能同时推迟其他请求或降低最大并发。固定图地址只保证存储地址稳定，不保证 row、mask、父映射及代次内容正确。故障恢复从共同确认路径继续，旧候选和旧完成通知不能重新成为历史。

## 竞争解释与区分实验

先固定目标采样契约、输入与输出工作量、缓存条件、到达轨迹和计时完成点。累计 kernel 时间不是端到端关键路径，相同 seed 的单条文本也不是分布参考。

| 竞争解释 | 区分实验与预测 | 反证后的修正 |
|---|---|---|
| 草稿与目标不接近 | 对相同目标分布使用相同提议分布，理论上无拒绝；比较接受长度及草稿耗时 | 若接受长度已高而仍慢，转查验证、管理和资源争用；只换成同模型却保留不同变换不构成 p=q 对照。 |
| 残余或提议记录错误 | 小词表精确枚举一般分布、单点 q、互斥支持及 p=q；与直接目标序列分布比较 | 缺失草稿支持之外的目标质量时修残余范围；候选 q 与记录 q 不一致时修提议身份。 |
| 不可达 grammar 后缀被提前处理 | 目标首步只允许 a，草稿提出 b,b；严格参考在 H+b 请求分布就报错。正确回合输出 a，只消费 root 分布，K 不增加；提前处理后缀的变体必须失败 | 若确认起点本身无合法质量，保留真实失败；若只有必拒后缀失败，修路径截断和分布形成顺序，不能解除 grammar 或反复回到 S0。 |
| 终止与接受状态混同 | 分别构造已接受且仍可继续的 grammar、接受 EOS、bonus EOS、草稿私有停止和长度停止，记录实际 q、目标输入行与分布访问 | 在 accepting 状态提前结束时修终止谓词；EOS 后继续访问分布时修停止顺序；修正/bonus 被计为已输入时修 K。 |
| mask 错误 | 用逐路径串行前向作参考，将实际 packed 可见集送入玩具 attention；分别注入兄弟泄漏和遗漏自身 | 若 hidden、KV 或后续分布发生分歧，修可见集；集合成员检查本身只能证明局部拓扑。 |
| logits 一步错位 | 保持正确 mask，单独将验证索引从父行改为节点行；比较每个候选之前的条件分布 | 输入行输出正确、验证分布错误时修父行映射，不能靠屏蔽自身补救。 |
| 回滚或状态压紧错误 | 固定接受路径，将 packed 全层 KV 与该路径串行前向逐层比较；枚举 n=0 到全部接受 | token 相同而后续状态不同，应查全层收集、递归快照和窗口恢复。 |
| 验证或 batch 饱和 | 固定请求轨迹扫描 γ、宽度和 batch，分别记录 root 准备、验证、接受产出及其他请求等待 | 小批有益而大批失效时动态减预算；接受率不是充分解释。 |
| 准备、通信或驻留限制 | 固定候选，改变建树/图路径、草稿设备或快照方式，记录关键路径和物理容量 | 时间没有随被干预阶段变化时，不能继续把主因归给该阶段；实际事务与逻辑字节分开报告。 |

配套检查以精确有理数枚举单步协议和跨回合固定长度序列；独立参考只按目标条件分布逐 token 展开，不使用投机接受结果。它还检验一般期望长度恒等式，并故意替换接受规则、残余分布和条件前缀，要求参考实际发现偏差。有序单点树协议另以直接目标概率为参考，不复用其残余选择结果。

grammar 检查另执行候选准备、目标路径检查、按需分布访问及状态提交的有限流程模型。有限语言目标参考由前缀后继表定义，非法前缀或已终止状态不提供分布；直接目标轨迹参考独立扫描可完成词串。确定性 b,b 反例要求输出 a、只访问起点分布、无目标候选输入行、K 不增加，并以闭式递归状态核对保留边界。第二位置非法、草稿停止、目标停止、接受且可继续、零候选、零预算、接受 EOS 与 bonus EOS 分别检查访问轨迹。故意提前处理全部后缀的变体必须真正触发严格参考的死前缀错误。这些流程分支检查不把固定 uniform 当作统计采样证明；概率保持由前述精确质量检查承担。

树形模型检查使用两层、单头、二维的确定性 CPU 玩具前向，实际执行 Q/K/V 投影、softmax attention、残差与非线性更新。packed 版本消费实际构造的可见索引和节点到物理行映射；参考版本对每条路径重新执行普通串行 causal 前向。比较范围包括节点输出、验证候选的父行分布和逐层状态。兄弟泄漏、遗漏自身、节点行代替父行三个负对照必须产生参考可检出的差异，不能只靠插入并查询集合成员获得成功。

这些检查不执行真实目标模型、CUDA、DMA、图重放、词表分布式归约或 GPU 计时，也不证明任意 grammar 编译器、随机流实现、取消同步或知识使用效果。真实设备仍需检验数值合同、完成证据、实际事务量、资源争用和性能。论文报告只支持其来源条件，不能写成本库实测。
