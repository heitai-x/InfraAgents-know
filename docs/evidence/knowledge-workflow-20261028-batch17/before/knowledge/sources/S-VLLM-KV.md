## 来源支持的机制与算法

归档区分完整块命中、新计算、新命中的本地状态、外部已算状态、额外预留和 encoder 状态。命中范围最多到请求末 token 之前，以便取得 logits；只复用完整块时，重新计算可能超过一个 token。全序列可容纳性检查是准入条件，不是所有后续分配已经成功的证明。

```pseudocode
匹配可复用的完整本地缓存块，得到可恢复 token 范围
按状态族释放不再需要的范围，并检查本次需要的可用块
保护新命中的本地块，为外部状态建立必要目标容量
为本轮新计算与额外预留分配状态
按完成与验证范围发布可复用内容；未完成传输可以延迟发布
```

源码相对论文多出的价值是这些状态不能混为一类长度：已分配的外部目标尚未可读，预留 token 尚未确认，投机部分不能全部发布为已验证前缀。块粒度与窗口/层组共同决定实际容量。
