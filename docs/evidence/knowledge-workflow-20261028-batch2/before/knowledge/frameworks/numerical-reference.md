# K-FW-002：数值参考：误差尺度、条件数与首次分歧

一个有解释力的数值参考保持任务函数和输入一致，再分层衡量实现重排与近似产生的差异。

## 等价的层次

实数代数等价、有限精度容差一致、greedy token 一致、随机分布一致和任务质量达标是不同目标。矩阵融合和归约重排可能满足数值容差但不逐位一致；量化本身改变表示；投机随机解码可能保持分布但不保持相同 seed 的轨迹。测试应先明确需要哪一种关系。

逐元素容差常写为 |x−y|≤atol＋rtol|y|。接近零时相对误差不稳定，极大值时只用绝对容差又不合理。最大误差、平均误差和分位数揭示不同问题；NaN、Inf 与 shape/位置错误应单独分类，不能被平均值淹没。

## 从 logits margin 推导输出敏感性

若参考 logits 最大与次大间隔为 Δ，每项误差绝对值均小于 Δ/2，则 argmax 保持。Δ 很小时，极小数值差异也可换一个 token，随后自回归前缀改变并放大整段文本差异。因此“第 100 个 token 不同”可能源于第 1 个微小分歧，也可能是缓存错误，需要固定前缀逐步对照。

softmax 对输入平移不变，但对尺度敏感；归一化层在方差很小时对 epsilon 和累加精度敏感。长点积的误差取决于值分布、消去和归约顺序，不只取决于长度。用更高精度参考时还应确认它执行同样的位置、mask 和参数化。

## 首次分歧是一条因果线索

比较链可从 processor 输出、embedding、每层 hidden、Q/K/V、attention、FFN、最终 logits 到采样。最早产生差异的边界缩小了候选原因；后层的大差异往往是传播结果。对于缓存路径，可比较一次全前缀前向与同一前缀的分块/逐步执行，它们共享语义但经过不同状态管理路径。

输入的极短、跨页、跨窗口、长历史和异构 batch 揭示不同结构边界。它们应来自实现中的状态转换，而非只随机抽几个常见长度。数值参考越独立于被测调度和索引逻辑，越能发现共同错误。

## 把误差来源与验证对象对应起来

| 改动 | 首先保持的对象 | 需要增加的验证 |
|---|---|---|
| 分块、归约或融合重排 | 相同数学函数、输入和参数 | 逐层误差、极值、不同 shape 与累加顺序 |
| 权重/激活量化 | 固定量化码、尺度与零点下的函数 | 解包/补偿参考，再独立评估相对原模型的质量 |
| KV 低精度或裁剪 | 明确的新状态近似定义 | 长历史、多轮与分布外输入的累积质量变化 |
| 近似激活或 attention | 声明的近似函数 | 输入范围、敏感层和任务级质量，而非仅输出 shape |
| 随机采样或投机 | 规定的概率分布与支持集 | 小分布精确推导、统计频率和非法 token 检查 |

量化内核可以精确执行一个有损模型；这时“相对量化参考正确”和“相对原模型质量可接受”都需要通过。反过来，平均任务分数接近也不能掩盖某个模型输入上的索引错误。两类误差应保留独立证据。

## 容差来自误差尺度，不能用来修补状态错误

对有限精度求和，在常用浮点模型且不发生溢出等异常的条件下，误差界会随项数、单位舍入误差和项绝对值之和增长；相消会使相对误差显著放大。因此应同时检查绝对误差、相对误差、归约长度和参考值尺度，不能所有层共用一个未经解释的阈值。

NaN、Inf、越界位置、错误可见集合和错误模型版本首先属于契约问题。更宽容差不会使它们变成合法近似。高精度参考也要使用相同 epsilon、位置参数和激活定义；把参考函数改成另一个更“精确”的数学函数会引入新的差异来源。

固定前缀的逐步 logits 对照用于定位，真实自回归生成用于检验误差传播与质量；两者不能互相替代。长期状态测试还要跨越页重用、窗口回绕、缓存淘汰、取消和请求交错，观察误差是否只在特定状态转换后出现。

## 质量与性能同时保留不确定性

近似方案的校准集、开发集和最终保留评估集应分开。对话、长文档、不同模态或罕见 token 的质量退化可能被总体平均掩盖，需按真实目标保留关键分层。将质量门槛与性能比较联合记录，避免根据同一小集合反复选择阈值后再声称无损。

[实验统计](../tools/statistical-experiments.md) 说明重复与区间的条件；[正确性 oracle](../tools/correctness-oracles.md) 说明独立参考的组成。数值容差通过、质量满足、性能改善分别是三项结论，各自的验证范围都必须保持可见。
