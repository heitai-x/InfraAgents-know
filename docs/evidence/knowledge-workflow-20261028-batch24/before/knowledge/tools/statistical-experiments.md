# K-TOOLS-007：性能实验：独立重复、效应量与尾部证据

性能结论要同时回答改了多少、波动来自哪里，以及结论适用于哪组条件。更多计时样本只有在增加了与问题相关的信息时才提高可信度；同一进程内反复测量不能自动替代重启、重新构建或不同时间段的重复。本章把实验视为有状态的数据生成与归约过程：先固定比较对象，再定义估计量，按层级安排独立重复，保留失败与尾部，最后在独立保留集上验证。设定算例、成本账和检查模型是推导，不是目标设备实测。

## 比较对象、估计量与实验账本

令候选 g∈{A,B}，独立运行或区组 b，请求或迭代 j，指标为 Y_{g,b,j}，单位与时间域预先声明。比较合同 C 至少包含版本与制品身份、硬件与配额、模型与数值设置、输入输出分布、缓存与预热状态、质量门槛、测量事件边界、到达模型、完成与失败规则。输入是 C、候选集合、预算、层级结构和决策阈值；输出是逐请求事件、效应量及其区间、尾部证据、失败账、停止决策及未验证边界。

实验计划从 PLANNED 经合同与制品检查进入 READY，执行时为 RUNNING；请求业务结果分别保留 COMPLETED、FAILED、TIMED_OUT、REJECTED 和未完成状态。质量采用通过、失败、未知三态。分析成功产生 ANALYZED；区间不能合法构造时为 UNRESOLVED，仍保留已有点估计与失败原因。独立保留验证完成后，才按相同合同给出相应范围内的 VERIFIED。业务完成不等于物理资源已经排空，分析完成也不等于候选质量通过。

效应量可以定义为差值 Δ=μ_A−μ_B，或均值比 θ=μ_A/μ_B。对于延迟，负差值或小于 1 的比值表示 A 更快。两种量的单位不同：差值保留 ms 等指标单位，比值无量纲。比值要求总体分母非零；有限样本给出一个正分母点估计，并不证明分母不确定性可以忽略。

均值比、逐请求比值平均与分位数比不是同一估计量。取 A=[1,9]、B=[2,8]，均值比为 1，逐对比值平均为 (1/2+9/8)/2=0.8125。报告加速比须说明方向、聚合顺序和分母。吞吐须声明完成窗口、失败和未完成工作；goodput 只计满足正常完成、质量、延迟与输出范围等联合条件的结果，不能只选快速成功的请求。

## 合法性：哪些条件决定结论可比较

合法比较首先要求对象一致：版本、硬件配额、模型、输入输出分布、缓存条件、质量标准和测量事件相同，或把变化明确列为研究因素。请求发出、首内容到达、最终响应到达、应用提交与设备完成是不同边界。把预打包移出计时可以研究稳态，但必须另报一次性成本，不能直接支持冷启动更快的结论。

客户端单一时钟下，可定义 TTFT=首个有效内容到达时间−请求发出时间、请求延迟=最终响应到达时间−请求发出时间。只有逐 token 到达确实可观测且输出 token 数 n>1 时，TPOT=(末 token 时间−首 token 时间)/(n−1)。若只能观察多 token chunk，就应报告明确的 chunk 指标，不能补造逐 token ITL。首内容改善与完整请求改善需要分别验证。

其次要求估计量合法：配对单位是真正独立的运行或区组，而不是同一运行内强相关的 token；分位数有明确定义；失败、超时、拒绝与未完成请求保留在 offered 账中。若 SLO 要求在 deadline 内成功，超时和质量失败按该定义计入，不能删除后只对快请求求 p99。仅成功请求上的平均延迟可以作为条件指标，但不能冒充全部 offered 请求的性能。

统计条件必须显式：独立重复、相应层内的可交换性与平稳性、有限方差、解析方法所需的正态或渐近依据、有效配对、无未建模 carryover，以及合法停止规则。t 区间、层级 bootstrap、经验分位数与零超限上界各有前提。重采样保留已声明的相关结构，不会自动修复漂移、遗漏随机因素或没有观测到的稀有事件。

随机种子与确定性配置只能控制特定执行路径中的随机性，不保证跨版本、平台和 CPU/GPU 逐位一致；确定性算法还可能更慢。搜索后的结论需要独立验证：探索集与保留集分开，候选确定后冻结代码、配置和制品身份，报告试过的候选范围。持续查看直到恰好显著再停止，会改变固定样本区间的含义；需要预先设计停止方案或使用适当的序贯方法。profiling 的同步、额外复制和影子参考会扰动执行，诊断运行与正常性能运行分开报告。

## 完整算法：分层设计、执行、估计与停止

实验层级通常为环境或时间段、进程或模型实例、请求或迭代。设第 r 个独立运行有 n 个请求，运行均值为 Ȳ_r。两层模型可写为 Y_{r,j}=μ+U_r+ε_{r,j}。若 U_r 独立且方差为 τ²，残差在给定运行下独立且方差为 σ²，并满足模型中的独立条件，则

Var(Ȳ)=τ²/R+σ²/(Rn)。

内层请求数 n 只压低第二项；若 τ² 远大于 σ²/n，增加同一进程内重复会产生看似稳定、但覆盖条件很窄的均值。应先用分层预实验辨别主要变异，再按方差与重复成本分配预算。

```pseudocode
算法 DesignAndAnalyzeExperiment
输入：候选集合 G，比较合同 C，层级 L，预算，接受区域 A，置信水平 1−α，独立保留集 V
输出：效应量与区间、尾部证据、失败账、决策及未决原因

1 固定 C：制品、硬件、模型、输入输出分布、缓存、质量、测量事件与到达模型
2 固定估计量：本算法展开均值差或均值比；声明各层权重、方向与单位
3 确定独立单位、嵌套结构、配对层，以及实际可以交换或重采样的单位
4 用独立预实验估计各层方差和成本；预实验不进入最终保留验证集
5 根据预算与方差分配外层运行和内层请求，冻结停止规则与分析方法
6 若目标为均值比，另冻结分母可信下限 ε_B≥0，单位与 B 相同
7 对每个独立区组：
     随机或均衡安排 A/B 顺序；按合同重置状态并记录准备成本
     执行完整轨迹，记录 offered、准入、首内容、完成、失败、超时与质量
     保留全部 offered 请求，禁止按快慢或成功状态事后删除
8 计算逐请求资格：合法准入且正常完成 ∧ 质量通过 ∧ 延迟通过 ∧ 输出范围通过
     质量未知保持未知；未完成不补造完成事件
9 按冻结的人口和权重生成各候选的运行指标，核对有限值、配对及独立性
10 按估计量分支：
     均值差且配对差值满足 t 区间前提：使用配对差值 t 公式
     均值差但上述解析前提不足：在重采样前提成立时使用层级 bootstrap，否则未决
     均值比：计算两个均值后相除，使用层级 bootstrap 传播双方不确定性
       原始或重采样分母≤ε_B、出现非有限比值或其他有效性条件失败时，区间未决
     不得把差值 t 区间当作比值区间，也不得只将 A 的区间除以 B 的点估计
11 计算经验尾部分位数；只有满足二项式前提时才计算零超限上界
12 在 V 上重测冻结候选与基线，使用同一合同和预先指定的分析
13 质量和 SLO 通过且整个效应量区间落入 A，才支持相应性能决定
     跨越决策边界时增加有效独立重复或报告未区分；质量失败则排除
14 返回原始事件、运行身份、聚合定义、区间方法、未决原因与适用范围
```

接受区域须与量的方向和单位匹配。例如，延迟均值差要求至少降低 δ_abs>0 ms，可设 A=(−∞,−δ_abs]；均值比要求至少相对降低 δ_rel∈(0,1)，可设 A=(−∞,1−δ_rel]。区间包含零或 1 与是否超过值得维护的收益阈值是不同问题。若目标是实际等价，应另设等价区域，并判断整个区间是否落入该区域。

## 层级重采样与均值比的完整分支

重采样首先复制独立单位的结构，再重新计算被冻结的统计量。不能把所有请求打散后重采样，否则运行间放置、构建和环境差异会被抹掉。时间相关的请求需要已说明的块重采样，或把完整时间轨迹作为更高层单位。

这里先展开两层、外层配对的方案。每个区组 r 有 A、B 两条运行记录，μ̂_g=(1/R)Σ_r Ȳ_{g,r}，其中 Ȳ_{g,r} 是该运行中合同所定义指标的平均。这个估计量给运行等权；运行长度不等时，它不同于把所有请求池化后的均值。若选择请求加权，原始和每次重采样都必须重新计算相应总和与总权重，不能在两种口径间切换。

每次重采样先抽 R 个区组索引 r₁,…,r_R，同一索引同时选择 A 与 B。随后每个被抽中的区组副本独立产生自己的内层抽样。若内层存在合法的共同请求配对，就共同抽请求索引；若只在运行层配对，两候选在该区组内分别抽请求。相同位置编号本身不能建立内层配对。

```pseudocode
算法 PairedHierarchicalEffect
输入：配对区组 Y[A][r]、Y[B][r]；配对层；估计量 mode∈{DIFFERENCE,RATIO}
      重采样次数 M，α，各层冻结权重，分母可信下限 ε_B
输出：点估计、区间或 UNRESOLVED、重采样诊断

检查非空数据、有限值、配对身份与相应重采样前提
按冻结权重计算 μ̂_A、μ̂_B
若 mode=RATIO 且 μ̂_B≤ε_B：返回点估计未定义或不可信，区间 UNRESOLVED
point ← μ̂_A−μ̂_B 或 μ̂_A/μ̂_B
若独立外层单位不足以支持当前推断：保留 point，区间 UNRESOLVED
初始化 replicas、denominators、invalid 为空

for k in 1..M:
    有放回抽取 R 个共同区组索引
    初始化本次区组指标 A*、B* 为空
    对每个被选区组的副本：
        若内层真实配对：抽共同请求索引，同时取得两个候选的对应观测
        否则：在两个候选各自合法的内层单位中独立重采样
        按冻结权重归约本副本的两个运行指标，分别追加到 A*、B*
    μ*_A ← 按冻结外层权重归约 A*
    μ*_B ← 按冻结外层权重归约 B*
    若 mode=DIFFERENCE：保存 μ*_A−μ*_B
    否则：
        保存 μ*_B 到 denominators
        若 μ*_B≤ε_B：记录本次 invalid，不执行除法
        否则计算 θ*_k=μ*_A/μ*_B；非有限结果同样记录 invalid
        只有合法 θ*_k 才有数值，但不得删除 invalid 后重新解释样本人口

若存在 invalid：返回 point、诊断及区间 UNRESOLVED
若分布退化且没有独立的已知恒定机制依据：返回 point 及区间 UNRESOLVED
排序全部合法 replicas，取预先指定的 α/2 与 1−α/2 经验分位数
返回 point、百分位区间、M、权重、配对层与分母诊断
```

分母规则是本章选择的保守有限区间输出策略，不是普遍的比值区间定理。ε_B 应在看结果前由测量分辨率、数值误差与最小可信基线尺度等依据确定；不能看到某次失败后降低它。ε_B=0 只排除非正分母；需要排除正但不可信的微小分母时，应采用有依据的正下限。本章这个分支限定于非负性能指标且正分母的比值；带符号指标的跨零比值或可能无界、分裂的置信集合，需要另行展开适当方法，不能直接套本算法。

只要原始或任一次重采样分母不满足该规则，就保留失效次数、分母范围与原因，停止发布这个有限百分位区间。不能夹紧分母、把除零改成零或无穷后继续排序，也不能丢弃失效副本、重新抽到足够多合法副本。这些做法改变了重采样分布。全部分母通过有限次抽样的检查，也不证明总体分母远离零；若测量分辨率、独立基线证据或分母分布仍不足以支持稳定性，结论仍未决。

例如，两个外层区组各只有一个观测，A=[2,2]、B=[0,2]，原始均值比为 2/1=2。外层抽两次有四个等概率有序结果：两次选第一个区组时分母为零；其余三个结果的比值为 2、2、1。因此不能删除那个零分母副本后报告一个看似正常的有限区间。把零改为微小正数，也不能忽略其相对测量精度是否可信。这个小模型用于说明分支，不推荐以两个区组建立正式统计结论。

若 A、B 完全独立，则分别在两棵层级树中抽样，再在同一重采样编号下计算两均值及其比值；不能人为引入配对。更多嵌套层按相同规则递归处理：在实际共同的配对节点使用共同索引，其下非配对子树独立抽取。每层都保留其身份、重复次数和权重，直至叶观测，随后从叶向根归约。

百分位区间是带条件的近似推断。所有层均重采样可能对部分层级方差产生保守或其他有限样本偏差；只重采样上层、保留完整下层是另一种需要论证的选择。少量独立块、强漂移、极端长尾或重采样退化都会限制有效性。增加 M 只减少有限次重采样带来的数值近似误差，不增加真实独立运行，也不会补出未出现的尾部机制。

## 配对差值、区组与运行层方差

对可重复的请求轨迹，可在同一时间区组内运行 A/B，并随机或均衡安排先后，以控制环境漂移。令 D_b=Y_{A,b}−Y_{B,b}，d̄=(1/n)Σ_bD_b，s_D²=(1/(n−1))Σ_b(D_b−d̄)²。在固定 n≥2、D_b 独立同分布于正态分布、方差有限且严格为正、配对合同有效、无未建模 carryover 与选择性停止时，均值差的精确区间为

d̄ ± t_{1−α/2,n−1}s_D/√n。

非正态但满足相应渐近条件时，可把它作为近似方法，但当前 n 是否足够仍需依据，不能用统一样本数门槛保证。这个公式仅用于配对均值差；没有定义均值比区间。分别对 A、B 构造 t 区间，再任意相除端点，也没有自动得到声明置信水平的比值区间。

设定 n=16、d̄=−2 ms、s_D=1 ms，使用自由度 15 的双侧 95% 临界值约 2.131，区间约为 [−2.53275,−1.46725] ms。这是给定统计量的代数算例，不证明真实差值正态，不保证长尾数据覆盖率，也不是未来单请求延迟的预测区间。

一个反驳“iid 足以保证小样本 t 区间”的有限离散反例是：D 以 0.99 概率等于 −2 ms，以 0.01 概率等于 98 ms。总体均值为 −1 ms，方差为 99 ms²，样本可以独立且没有 carryover。16 次全为 −2 的概率为 0.99^16≈0.851458；此时样本标准差为零，机械计算得到 [−2,−2]，不覆盖均值 −1。因此这种机械区间的覆盖率至多为 1−0.99^16≈14.8542%，远低于 95%。观察到 s_D=0 不证明总体方差为零，本章分析路径将它标为退化、推断未决。

该反例不是设备实验。遇到近似依据不足，应增加真正独立且覆盖稀有事件机制的重复、改进分层设计或报告未决；对已经观测到的 16 个相同值做普通 bootstrap，仍只会产生相同值，不能创造未出现的长尾证据。

设 R 个独立运行，每运行 n 个请求，运行均值为 Ȳ_r，总均值为 Ȳ，则均值方差的运行层估计为

S_run²=(1/(R−1))Σ_r(Ȳ_r−Ȳ)²，V̂ar(Ȳ)=S_run²/R。

它不自动赋予小 R 的 t 区间精确覆盖率。非平衡运行还要先决定目标是运行等权还是按请求量加权。

两个运行各 1000 个请求，运行内分别恒为 100 和 200。运行均值样本方差为 5000，均值方差估计为 2500，标准误为 50。若平铺 2000 个请求并错当独立样本，均值方差为 2500/1999≈1.2506，标准误约 1.118。增加同一运行内请求不能消除运行间放置和环境差异。两个运行只是揭示平铺错误的算例，不是推荐的正式重复数。

若两方案改变后续生成内容，应区分固定前缀计算对照与真实生成质量、性能对照。固定前缀适合定位同输入执行差异；真实生成还要检查输出长度、停止原因和质量，不能用一个平均耗时相互替代。

## 尾部、失败与零超限上界

p99 依赖尾部的少量样本。对非空样本排序后，nearest-rank 定义为 Q_p=X_{(ceil(pn))}，0<p≤1。插值分位数是另一合法定义，须单独声明。100 个请求的经验 p99 只有有限尾部信息，重复报告多个小数位不会增加精度。空样本分位数未定义，不能默认为零。

超时是被删失或失败的观测，不应悄悄删除。若 SLO 要求在 deadline 内成功，超时和质量失败按该定义计入。对预定阈值下 n 个独立同分布请求，观察到零超限时，单侧置信度 1−α 的超限率上界为

q_U=1−α^{1/n}，

由零超限概率 (1−q)^n 反解。n=100、α=0.05 时约为 2.95%；零失败 100 次不能支持真实超限率低于 1% 的同等置信结论。若真实 q=0.01，零超限概率为 0.99^100≈0.366，远大于 0.05，因此这种观测不能在 95% 置信下排除 1%。突发相关、负载漂移或选择性停止会破坏这个二项式算例的前提。

服务试验还应展示 offered load、队列增长、完成数和错误数。有限时间内的 goodput 不代表长期稳定；若队列持续增长，窗口结束时尚未完成的请求是关键证据。只报告快请求的 p99、只保留成功请求或提前关闭窗口，都会制造虚假提升。

## 搜索后的验证与停止条件

从许多候选中挑最好的结果，会同时挑中有利噪声。探索轨迹、形状与调参集应和最终保留验证分开；确定候选后冻结代码与配置，在独立运行上重测，并报告试过的候选范围。失败的正确性检查不能因为性能好而被排除。

设定四个候选真实性能相同，观测噪声各自独立且等概率取 +1 或 −1。选择最大观测值时，全为 −1 的概率为 1/16，此时最大值为 −1；其余 15/16 的最大值为 +1。因此选中值的期望噪声为 (15/16)−(1/16)=0.875，而单个候选的期望噪声为零。这是枚举推导，不是实测。

停止条件围绕实际决策设置：质量通过且 SLO 不退化时，收益是否超过值得维护的最小幅度。区间跨过决策边界表示证据不足，应增加有效重复或说明未区分，而不是采用单次最好值。持续查看直到显著需要相应序贯方法，不能沿用固定样本覆盖率解释。

发布结论保留原始事件、运行身份、失败样本、聚合定义和不确定性。一次局部 kernel 对照只支持该 shape 与条件；知识库是否提高 Agent 设计能力，还需要固定任务、模型和预算，比较知识条件并隔离各自运行学习。

## 条件化成本：计算、访存、通信、准备、同步和驻留

实验成本与候选收益分别列账。计算包括被测执行、质量评价与统计分析；配对差值摘要为 O(R)，排序分位数约 O(N log N)，层级 bootstrap 每次遍历 N 个观测时为 O(MN)，最终排序 M 个副本另需 O(M log M)。检查分母是每个比值副本归约后的 O(1) 操作，不应通过删除它来节省分析成本。

访存包括原始事件、逐请求时间戳、快照、重采样索引和数据副本。可以用索引或逐层累计代替复制全部数值，但必须保留层级、配对、权重和可复算原始证据。原始事件通常需要 O(N_events) 驻留；顺序处理副本时，暂存一个计划与 M 个统计量即可，保存所有重采样数据则可能增至 O(MN)。

通信包括分布式时间同步、结果汇总与跨节点日志。跨域时间相减需要校准：若同一物理时刻 t_B=t_A+δ，δ∈[δ_lo,δ_hi]，A 发送读数 a、B 接收读数 b，则经过时间属于 [b−a−δ_hi,b−a−δ_lo]∩[0,∞)。空交集意味着身份、校准或事件语义不相容；往返时间除二不等于去程。

准备包括编译、构建、加载、预热、缓存填充与环境重置；同步包括排空在途请求、设备完成、质量评价完成和日志刷新；驻留包括模型实例、缓存、原始事件、保留集和快照。它们可能影响被测系统，应隔离或计入。提前停止日志与资源账会遗漏慢请求或排空成本。

一个可加成本模型是

C_exp=Σ_g[R_g(c_build+n_g c_meas+c_warm+c_teardown)+c_analysis+c_storage]。

共同区组的共享环境成本只计一次。各项须使用可相加的成本单位；墙钟时间有重叠时应沿依赖和竞争资源计算关键路径。设 R=2、n=10、c_build=100、c_meas=1、c_warm=5、c_teardown=2、c_analysis=10、c_storage=3，总成本为 247；忽略构建则误算成 47。该算例核对账法，不是真实报价。

重复分配也可以由这个成本关系推导。在两层方差模型中，设每个独立运行固定成本 c₀>0，每个内层观测成本 c₁>0，可用于采样的总预算为 T。连续近似取 R=T/(c₀+nc₁)，则

Var(Ȳ)≈(τ²+σ²/n)(c₀+nc₁)/T。

当 τ²>0、σ²>0 时，对 n 求导，得到内层候选 n*=√(σ²c₀/(τ²c₁))。它揭示固定准备越贵越值得在一次运行内多测，外层变异越大越值得多做独立运行。实际次数为整数，应检查邻近可行整数、预算和足够的外层信息，而非机械取整。τ²=0 或 σ²=0 时不能除零套公式；应回到预算边界与方差模型。预实验估计接近零也不证明对应随机因素不存在。这个推导不直接给出尾分位数或均值比的最优设计。

## 条件变化后的保留、调整与放弃

| 条件变化 | 保留的关系 | 调整或放弃的依据 |
|---|---|---|
| 候选数增加 | 搜索范围记录与独立验证 | 冻结最终候选后重测；探索集区间不能作为选择后的最终证据 |
| 到达率或突发增加 | offered 账、完成窗口与失败记录 | 重算排队、尾部和容量，不能只报成功者 |
| 历史或输出长度改变 | 请求身份与逐请求资格 | 重核人口、输出范围、工作量和完成窗口；token 不能自动作为独立样本 |
| 硬件、版本或配额改变 | 比较合同与估计量定义 | 重建基线、区间和适用域，旧结果不能直接外推 |
| 缓存或预热改变 | 冷热边界与一次性成本 | 分别报告冷启动、热启动和稳态 |
| 失败率或超时增加 | 失败、删失和未完成账 | 按相同 SLO 合同重算资格，不能删除失败样本 |
| 质量门槛改变 | 质量三态与独立评价 | 重新评估，未知不能当通过 |
| 层级或运行长度改变 | 独立单位与嵌套结构 | 重定权重、方差和预算；不能在运行等权与请求加权间静默切换 |
| 差值改为均值比 | 原始配对与候选指标 | 更换区间分支，传播双方均值不确定性，并重新确定分母可信域 |
| 分母接近零或测量分辨率改变 | 原始数值与失效副本记录 | 重新设计测量或增加独立证据；不能夹紧、删副本或套差值 t 公式 |
| 统计假设不满足 | 效应量目标与原始证据 | 仅在相应条件成立时改用层级或块重采样，否则未决 |
| 停止规则或测量工具改变 | 停止合同及正常、诊断路径的区分 | 重新核对区间含义、同步、复制与扰动 |

## 竞争解释、区分实验与反证修正

| 观察 | 竞争解释 | 区分实验与反证后的修正 |
|---|---|---|
| 均值更稳但区间不覆盖 | 内层重复增加，外层变异遗漏 | 固定总预算增加独立运行，对照运行层方差；外层主导时停止堆叠内层请求 |
| p99 改善但均值不变 | 尾部样本少、选择性停止或删失 | 固定观察窗口、保留全部请求并增加独立块；尾部证据不足则撤回改善结论 |
| 吞吐增加但 goodput 不增加 | 超时、质量失败或输出范围失格增加 | 按相同资格账关联逐请求结果；合格完成数下降时撤回容量结论 |
| 配对与非配对结论不同 | 配对单位错误、carryover 或时间漂移 | 随机或均衡 A/B 顺序，检查顺序效应与差值相关；无合法配对时重建设计 |
| 搜索后收益消失 | 选择偏差或探索集泄漏 | 冻结候选后在独立保留集重测；跨决策边界时报告未区分 |
| 区间异常窄 | 请求被平铺，运行层方差遗漏 | 保持原始数据，分别按运行层和错误平铺法归约；差异支持修正独立单位 |
| 均值比区间随聚合顺序变化 | 实际计算了逐对比值平均 | 用 A=[1,9]、B=[2,8] 固定输入；应得到均值比 1，得到 0.8125 则修正统计量 |
| 比值重采样在强配对数据上产生额外波动 | A/B 索引被独立打散 | 用已知逐对 A=2B 的正值模型；合法共同索引始终给 2，破坏配对则违反该不变量 |
| 删除少量副本后比值区间正常 | 分母接近零，条件化筛选制造有限区间 | 固定并枚举小数据的抽样计划；存在失效分母时要求未决，不重新抽样补足 |
| 零失败被解释为极低真实失败率 | 二项式人口、独立性或停止前提不满足 | 核对固定样本设计和独立块；即使 iid，100 次零失败也不能排除 1% |
| profiling 显示改善，正常路径无改善 | 同步、额外复制或影子参考扰动 | 分开运行与计时，正常路径不改善则撤回实际收益结论 |
| 队列增长但完成吞吐高 | 快请求完成，积压未计入 | 检查窗口末在途请求、offered 数与队列斜率；持续增长时不能声称稳定容量 |
| 质量通过但输出变短 | 裁短输出、提前停止或长度合同变化 | 检查长度分布、停止原因和输出范围；失格结果不能计入 goodput |

诊断须提出可否定预测。一次时间测量不能确定原因；应控制输入，只改变能区分解释的条件。负对照固定任务标准，主动构造缺失响应、提前结束且仍有在途请求、只保留快请求或跳过真实模型路径等轨迹；测量链必须拒绝或明确记录缺失。原始证据不足以重建指定统计量时，结论是未测得，不能用另一个聚合量替代。

## 针对知识库作用安排受控构建实验

以下是研究者可选择的对照设计；具体 Agent 条件是本章推导，不归称为来源论文的实验，也不是 Agent 构建系统必须执行的流程。研究知识条件时可比较无知识、旧 seed、扩充 seed；研究运行学习时可另设 learned 条件。每组固定实际角色模型、任务语义、可用工具、基础代码起点、外部资料权限和预算口径，批次开始前冻结知识版本与评价器。各组拥有独立案例与发布状态，防止先运行的组向后运行的组泄漏经验。

主要结果包括固定预算内完整引擎的成功交付率、到第一个合格系统的成本、到目标性能的成本，以及合格系统端到端表现。固定预算完成率中，未交付均计为不成功并保留原因。若另分析到达合格系统的时间，仍可能完成、且仅因统一的预定时间窗结束而停止的运行，可以记为行政性右删失；崩溃或不可恢复失败应另列失败事件，不能任意按独立删失处理。其他资源预算导致停止时也须解释机制。不能只平均成功任务完成时间而不说明选择范围。独立重复单位是完整构建运行，不是同一次运行中的多个工作项。

检索命中、正文读取与知识使用声明检查访问链路；预期设计改变是否进入实现需要另行核对。若扩充组减少无效实验，且相同验收标准下实测总成本或到达合格系统的成本下降，可以支持构建成本改善；仅减少实验次数并不充分，因为剩余实验可能更昂贵。交付率提高但消耗更多资源时，应展示权衡，不能只报告最好轨迹。

扩充内容中的示范任务与算例不应成为唯一最终测试集。开发与独立保留场景分开，按模型结构、硬件、负载和状态交互报告实际改变的条件。硬件无法全部交叉时报告实际测试子集，避免由单设备结果外推跨平台收益。

## 检查覆盖与未验证边界

配套检查 `tools/check_k_tools_007_full.py` 为 Python 标准库、确定性、离线、只读检查，输入为脚本内固定的有限数据。它区分配对均值差与均值比，核对给定 t 临界值的摘要算术、n<2 与 s_D=0 边界、有限离散长尾反例、运行层与错误平铺的方差差异、零超限上界、nearest-rank、搜索选择偏差、实验成本和合同声明检查。它消费外部给定的 t 临界值，不实现任意自由度的 t 分位数求解。

均值比部分实现运行等权、两层且内外均配对的重采样归约。它穷举小数据的全部有序抽样计划，并与独立的精确有理数、多项式计数参考比较整个经验分布；另核对已知 A=2B 的配对不变量。数值边界实际输入原始零分母、重采样才出现的零分母、低于可信下限的正分母、单一外层单位与退化分布。零或不可信分母必须使有限区间返回未决，不能以一个布尔声明代替数值判断。

负对照实际计算逐对比值平均、破坏 A/B 配对、把零分母结果补成零、错误分位数索引及错误平铺标准误，并要求对应参考或不变量检出错误。固定种子抽样路径也执行相同比值归约；穷举和固定种子均不测量统计覆盖率。合同检查仅拒绝实际传入的缺质量门槛和丢失败声明，不声称实现了完整请求账本审查器。

这些是主机算术与有限统计模型检查，不是 GPU、CPU package、整机电表或真实服务实测，不证明目标设备事务量、同步、重叠、尾延迟或吞吐。两层配对检查不覆盖独立候选树、仅外层配对、更多嵌套层、时间块重采样或请求加权实现；它也不证明真实统计区间在漂移、自相关、强偏态或稀有尾部条件下的覆盖率。真实质量评价、工具解析、生产到达轨迹、保留集隔离与序贯停止的执行，以及知识对 Agent 构建能力的因果效果仍需相应证据。脚本实际执行状态由绑定当前脚本与输入的真实记录承担，正文不预写通过结论。
