# K-ALG-024：多样本与搜索分支：父子状态、评分与共同提交

一个请求可以产生多个候选前缀，但独立多样本、beam search 与投机树具有不同的输出契约。共享不可变前缀可以减少重复计算和驻留；分支之后的概率、可变状态和提交资格仍由各自路径决定。系统必须回答：一个 token 由哪个父前缀预测，它自己的状态是否已经计算，以及哪些候选最终成为正式历史。

## 分支对象、目标与合法条件

设根前缀为 x，长度为 L；p(v|h) 表示在前缀 h 下，经过声明的 temperature、惩罚、grammar、截断和归一化之后，实际用于生成的目标分布。若搜索采用原模型概率或其他评分，必须另外声明，不能把不同分布的分数混用。

每条分支 b 至少保存稳定身份、父分支、分叉位置、普通 token 路径 y_b、模型及表示身份 η、状态代次、累计评分、grammar、随机状态、终止原因，以及共享状态和私有增量的句柄。还需要三个不同边界：

- n_b=L+|y_b|：分支已经选择的普通 token 数。beam 中这些 token 仍可能被后续搜索淘汰。
- k_b：模型已经实际消费并产生完整可用状态的 token 数。
- o_b：已经对外发布且按服务协议不能撤回的输出边界。

刚采样出的普通 token 可以推进 n_b，却尚未作为模型输入计算，此时通常 k_b=n_b−1。树节点已经计算但未被选择时，存在候选状态，也不能据此推进正式历史。EOS 是终止事件，不追加普通文本；它是否计分、占哪一种长度预算，必须在契约中明确。

| 方式 | 输出目标 | 不能据此推断 |
|---|---|---|
| 独立多样本 | 从规定分布得到 B 个独立样本 | 再取最高分样本仍服从原单样本分布 |
| Beam search | 按规定评分、宽度与平局规则保留候选 | 等价于随机采样，或者保证找到全局最优完整序列 |
| 投机树 | 用候选计算减少目标模型串行验证轮次 | 可以在目标验证后任意选择最高分分支而保持目标分布 |

合法执行要求以下关系同时成立：分支的父路径和模型身份正确；每个 query 只看本路径合法历史；共享内容只读，首次冲突写入先隔离或 COW；logits、采样参数、grammar、页表、随机状态和输出目标按同一个逻辑分支映射；正式提交只发布同一确认边界的状态；回收同时满足逻辑所有者消失与物理使用结束。batch 行号、物理地址和引用计数不能分别替代分支身份、内容身份和设备完成证据。

随机独立性与固定 seed 的轨迹复现也应分开。若共享随机流提供不重复、满足所需联合独立性的随机抽取，并且分配过程不窥视未来随机值，分配给不同样本仍可得到所需的独立联合分布。按 batch 行分配会使重排或取消改变具体随机数归属，通常破坏的是调度无关的固定 seed 轨迹，而不自动破坏分布独立性。反之，复制相同 RNG 状态并让两条分支消费相同位置，可能让它们逐步重复，明确破坏独立样本契约。

将随机身份绑定请求、逻辑分支、位置、采样用途和抽样序号，是实现调度无关轨迹的一种选择；子流导出必须避免复用并满足所需统计质量。普通 seed、不同 seed 或一个哈希名字都不单独证明这些性质。固定平台上的确定性配置也不保证跨版本、CPU/GPU 或全部算法逐位一致。

## Beam 的评分、完成集与跨轮推进

普通累计目标分数为 s(y)=Σ_i log p(y_i|x 串接 y[0:i])；EOS 完成再加 log p(EOS|x 串接 y)。比较使用累计分数，不能只比较最后一个 token 的条件概率。

本节明确选择一种双集合 beam：活跃集 A 最多保留 K 条，完成集 F 另外最多保留 K 条；EOS 不占活跃槽。这是一个搜索定义，不等同于把 EOS 与普通候选合并后总共只留 K 条的变体。默认活跃键为累计分数降序，完成键也为累计分数降序；可以替换为预先声明的固定键 R_A、R_F。每个键还接上确定的全序 T，例如完整事件路径的字典序、终止原因和稳定身份。

若采用长度处理，必须声明作用于活跃剪枝、最终选择或两者，以及长度是否包含 EOS。例如本章允许把 m 定义为新增普通 token 数加 EOS 事件数，并按 s/max(1,m)^β 排序，β≥0。它会改变搜索结果。完成候选的键在后续轮次不能变化，否则以前被截去的完成项可能重新变好，旧的前 K 集不再充分。

设 H≥0 为最多新增的普通 token 数。达到 H 时直接以 LIMIT 完成，不再抽样或计入一个假想 EOS；grammar 是否已接受另外记录，长度终止不等于语法完成。零概率或非法项不产生候选。

```pseudocode
算法 BeamStep
输入：根 x，活跃集 A_t，完成集 F_t，K≥1，普通长度上限 H≥0
      固定评分键 R_A、R_F，全序 T，grammar 与实际目标分布规则
输出：A_{t+1}、F_{t+1}，保留候选的 parent/token/state 映射及失败原因
1 校验身份、路径、评分契约；C_live←空；C_end←空；F_work←F_t 的候选视图
2 对每条 h∈A_t：
3     若 |y_h|≥H：把 (h,LIMIT,grammar是否接受) 加入 F_work；继续
4     若 h 有 pending token：先隔离写区，消费该 token，完成全部必要层
5     取得恰好对应 x 串接 y_h 的 logits；按该路径的规则形成 p_h
6     若合法集合为空或概率无效：记录 h 失败；继续
7     对每个 p_h(v)>0 的普通 token v：
8         c.path←y_h 串接 v；c.parent←h；c.score←s_h+log p_h(v)
9         c.grammar←从 h 的 grammar 完整消费 v；c.pending←v
10        c.state←h 的已计算状态只读视图；v 自身尚未被消费
11        若 |c.path|=H：把 (c,LIMIT,grammar是否接受) 加入 F_work
12        否则把 c 加入 C_live
13    若 p_h(EOS)>0 且 grammar 可结束：
14        将同一文本路径、score=s_h+log p_h(EOS)、reason=EOS 的记录加入 C_end
15 F_work←F_work∪C_end
16 对 C_live 按完整路径和计算身份去重，保留键最优项，再按 (R_A,T) 取前 K
17 A_{t+1}←上述结果
18 对 F_work 按 (完整路径,终止原因,计算身份) 去重，保留键最优项
19 F_{t+1}←按 (R_F,T) 从去重后的 F_work 取前 K
20 为保留项建立父状态引用和私有元数据；淘汰项解除逻辑引用，物理回收另等完成
21 返回两集合与映射；若二者均空，返回明确失败
```

这里旧完成结果、入口处已达到长度限制的结果、普通扩展刚达到限制的结果和本轮 EOS 全部进入同一个 F_work，再统一去重、排序和截取。固定完成键下，保留旧 F 的前 K 足够：以前已经排在至少 K 个完成项之后的对象，不会因增加新完成项进入前 K。

完整搜索初始化为 A_0={空新增路径，分数 0，根状态}、F_0=空，重复上述步骤，直到活跃集为空，再返回完成集或其中第一项。H=0 直接得到长度终止，不消费随机数，也无须为了结束去计算下一行 logits。此有限长度算法不依赖启发式提前停止；若要提前停止，必须证明所有活跃路径的最优可能最终键都不超过当前返回阈值。长度归一化下未来键可能改善，不能直接把当前累计分数当成同一个停止界。

完成分支可以仍有 pending token；若只返回文本，不必为它补 KV。若保留为后续请求的可恢复状态，就必须报告真实 k，并在继续前补消费。流式发布则还受 o_b 约束：无法证明搜索不会替换某段文本时，延迟发布，或采用明确允许修订的协议。

## 父子可见性与逐层树前向

树根代表已计算的 x，普通节点 n 保存父节点 par(n)、token τ(n)、深度 d(n) 和唯一执行行。兄弟的 token 必须可区分；相同父前缀下重复 token 可以合并，但要同时合并其提案概率质量。定义 A(n) 为从根之后到 n、包含 n 自己的节点链。

节点输入的绝对位置是 L+d(n)−1。它的当前行 attention 允许看根前缀和 A(n)，包括自己；不能看其他分支。节点 token 的概率来自父前缀分布 p_par(n)(τ(n))，而节点自身计算得到的 p_n 用于预测其后续 token。这是概率与 KV 的一步偏移。

例如根有 A、B 两个子节点，A 有 C、D，B 有 E：

| 行 | 位置 | 可见候选 KV | 验证本行 token 的分布 |
|---|---:|---|---|
| A | L | A | p_root |
| B | L | B | p_root |
| C | L+1 | A、C | p_A |
| D | L+1 | A、D | p_A |
| E | L+1 | B、E | p_B |

同深度节点可具有相同逻辑位置，却占不同物理槽。把展平行号当作位置，或者把展平前缀当作可见历史，都改变了模型函数。

下面展开确定性推理、因果 self-attention Transformer 的树前向。每个正常层的归一化、残差、MLP、位置变换和 head 映射严格服从固定模型图；不启用会随 batch 改变语义的随机操作。设层数为 J，h_n^0 为 token embedding 与规定位置输入。一个标准 attention 层中，q_n、k_n、v_n 来自本层输入的规定变换，attention 为

z_n=Σ_{u∈prefix∪A(n)} softmax_u(q_n·k_u/√d) v_u。

分母覆盖整个合法集合，不能先对根和候选分别归一化再相加。

```pseudocode
算法 TreeForward
输入：已计算根 x 的每层 KV 与有效范围，根下一 token logits
      普通候选树 T，固定模型图与位置规则，独立候选写区
输出：每节点下一 token logits，以及各节点完整路径的全层状态视图
1 校验树无环、父节点存在、节点身份唯一；保存执行行到节点的逆映射
2 若根 KV 完整但缺少末行 logits：
      从安全的前一计算边界重放根末 token，隔离写区并取得正确根 logits
      空根使用模型规定的起始输入或起始分布；不能凭空选择一个末行
3 对每个 n：position[n]←L+d(n)−1；h^0[n]←模型规定的 token/位置输入
4 为候选分配私有 KV 槽；所有本轮有效长度仍标记为候选
5 对层 ℓ=1…J：
6     从 h^{ℓ−1}[n] 产生本层 q[n]、k[n]、v[n]，执行规定的位置变换
7     把 k[n]、v[n] 写入该层 n 的私有候选槽
8     建立本层投影写入到 attention 读取的完成/可见性依赖
9     对每个 n：读取根本层 KV 与 A(n) 的本层 KV
10        用完整合法集合计算 attention，再按模型图完成输出投影、残差和 MLP
11        得到 h^ℓ[n]；完成后才允许下一层消费
12 对每个 n：最终归一化与 LM head 产生 logits[n]
13 按 x 串接 path(n) 的 grammar、惩罚和采样配置形成 p_n
14 当所有必要层的 KV、logits、描述和复制均完成后，标记节点状态 ready
15 返回根分布、节点分布、完成票据和路径状态视图；不发布为正式历史
```

同一层所有候选的 K/V 都由该层输入独立投影产生，所以 Transformer 可以沿网络层执行一次树前向；祖先的同层 attention 输出不是后代同层投影的输入。下一层仍必须等待上一层输出。某叶的可提交状态视图由根 KV 和它的祖先链在每层的 KV 共同组成，不能只拿叶行，也不能把整棵树展平后用一个总长度提交。

页化实现先把逻辑节点映射到本层候选槽，再由页号和页内偏移定位物理地址；mask 或祖先索引决定读取哪些槽。压紧只改执行映射，父指针、位置、输出路由和句柄必须一起重映射。首写若落在共享尾页，先分配、复制有效内容并等待完成；不能修改根的已发布快照。

这份并行数据流不直接证明覆盖式递归层可用同一个 attention mask 执行。混合模型若要树计算，必须在每一递归层按父边取得准确快照：state_ℓ[n]←Consume(h^{ℓ−1}[n],state_ℓ[par(n)])，根父状态为消费 x 后的该层状态；兄弟写入不同副本。卷积历史与窗口覆盖同样要按父边保留。这样会有树深度依赖与每节点快照成本；可结合[递归块完整单步算法](../models/recurrent-hybrid-state.md)实现，或放弃批量树计算，沿各条路径重放。只缩短一个长度字段不能恢复被覆盖的状态。本章随章数值检查限于两层标量 attention 模型，不验证递归块或真实 checkpoint。

## 独立样本与分布保持的树验证

独立多样本先建立 B 个分支身份，引用同一只读根状态，分别保存 grammar、输出、终止原因和随机位置。B=0 可以按接口约定返回空结果，负数应拒绝；若任务要求至少一个样本，应在入口拒绝 B=0。首次追加执行私有写入或 COW。共享随机流或逻辑子流都需满足前述联合分布契约；要求调度无关轨迹时，按逻辑身份分配抽取。已完成、取消和 padding 行不再消费正式采样位置。

树形草稿与验证协议应分别定义。EAGLE v1 用目标模型特征和提前一步的已采样 token 构造特征草稿，并以树 attention 验证候选；它说明每层递归应用投机采样，不替本章规定具体候选归一化或事务对象。

下面给出一种可独立实现的合法构造，而非复述 EAGLE 的完整多候选实现。先固定有限候选树及每个内部节点的提案分布 Q_n，之后才使用本轮验证随机抽取。Q_n 在其普通子节点 token 与可选 EOS 上归一化，其他词表项为零。它可以由草稿概率在选定支撑上截断后重新归一化得到，但必须保存这个实际 Q_n；不能仍用截断前的 q 计算接受比。树构造使用独立草稿随机状态，不能预看本轮验证抽取来选择 Q。

每到一个父前缀，从 Q_n 抽一个候选，按 min(1,p_n(c)/Q_n(c)) 接受；拒绝时从完整词表的正剩余分布重新抽样，并结束本轮。接受普通节点后沿该边继续；叶节点直接从 p_n 抽一个 bonus 事件。该协议每层只尝试一个子节点，其他已计算兄弟可能全部浪费；更复杂的逐兄弟重试必须另推导拒绝后的提案与目标更新，不能静默加进本算法。

设 β=Σ_v min(p(v),Q(v))，则接受输出 v 的质量为 min(p(v),Q(v))，拒绝概率为 1−β。正剩余总质量也为 1−β，因此最终输出质量为

min(p(v),Q(v))+(1−β)·max(p(v)−Q(v),0)/(1−β)=p(v)。

p 与 Q 支撑不同是合法情况：Q(v)=0、p(v)>0 的项由剩余分布覆盖；Q(v)>0、p(v)=0 的提案必拒绝。只有被抽到的 c 才执行比值，此时 Q(c)>0。p=Q 时拒绝事件概率为零，不应归一化全零剩余向量。实际数值路径若出现不一致，应报告错误，不能临时改成 argmax 或丢弃质量。

```pseudocode
算法 VerifyTreePath
输入：ready 的树与 p_root、各 p_n、各 Q_n；根 grammar γ0、旧评分 s0
      本轮剩余普通 token 预算 M≥0；验证 RNG 快照 R0；草稿完成后的 RNG R_draft_next
输出：候选交付单 Receipt，或失败；不修改正式状态
1 n←根；a←空节点路径；γ←γ0 的私有副本；s←s0；R←R0 的私有副本
2 while |a|<M：
3     若 n 无普通子节点且无提案 EOS：
4         用 R 的下一抽取从 p_n 选择 t；转步骤 11
5     用 R 的下一抽取从 Q_n 选择 c，再用下一抽取选择 u∈[0,1)
6     若 u<min(1,p_n(c)/Q_n(c))：
7         若 c=EOS：t←EOS；转步骤 11
8         s←s+log p_n(c)；γ←完整消费 c；a←a 追加对应子节点；n←该子节点
9         继续循环
10    否则：r(v)←max(p_n(v)−Q_n(v),0)，在完整词表归一化
          若剩余总质量非正：返回数值/协议失败
          用 R 的下一抽取从 r 选择 t；转步骤 11
11    s←s+log p_n(t)
      若 t=EOS：验证 γ 可接受；reason←EOS；pending←空
      否则：γ←完整消费 t；reason←ACTIVE；pending←t
      返回 Receipt(a,t,L+|a|,γ,s,R,R_draft_next,reason,根身份与代次,完成票据)
12 预算耗尽：返回 Receipt(a,LIMIT,L+|a|,γ,s,R,R_draft_next,LIMIT,身份与票据)
```

这里每次提案抽样和接受抽样均消耗一次抽取，即使提案是点质量；这是为了明确轨迹而选定的消耗契约，其他消耗规则也可以声明。叶抽样和拒绝修正各消耗一次；M=0 不消费验证随机数。EOS 加入目标评分，但不推进普通 token 数或普通 grammar 字节。评分始终加目标 p 的对数概率，不能把接受率、Q、剩余分布或验证路径的联合概率当作输出路径评分。

交付单中的 R 是验证真正消耗后的状态，包括拒绝掉的提案和接受抽取。它与已经确认了多少个 token 不存在简单的一一对应。草稿 RNG 也必须显式交付，或按独立、无可变游标的计数器协议定义。不能从 a 的长度猜测下一随机位置。

修正或 bonus token 即使恰好等于某个已计算兄弟，本构造仍把它保守地视为 pending，不提交该 token 的状态。若要复用其预计算状态，需额外核对父前缀、模型、位置、全层完成与提交资格，再改变交付单的计算边界。

## 共同提交、失败与下一轮输入

正式状态保存根输出、模型消费边界、pending、grammar、评分、草稿与验证 RNG、代次和终止原因。提交接收上述交付单，而不是只接收一串 token。模型状态、grammar 与输出覆盖的长度可以不同，但它们必须描述同一条已确认路径及其真实计算进度。

```pseudocode
算法 PrepareAndPublish
输入：旧正式快照 Old、Receipt、候选全层状态视图及资源票据
输出：新正式快照，或发布前失败时仍为 Old
1 校验 Receipt 的请求、根 token 身份、模型、代次及当前提交权
2 校验 a 是树中从根出发的连续父子路径，全部使用的候选状态 ready
3 H_new←Old.H 串接 a 的普通 token
4 若 t 为普通 token：H_new←H_new 串接 t；pending_new←t
  若 t=EOS 或 LIMIT：pending_new←空
5 k_new←|Old.H|+|a|；选择根状态加 a 的各层 KV 路径视图
6 对覆盖式状态取得同一 k_new 的准确快照；缺少时从受保护起点重放 a
7 从 Old.grammar 重放本轮普通输出；核对等于 Receipt.grammar
8 从相应父前缀 p 重新累计本轮目标评分，包含声明的 EOS 项；核对 Receipt.score
9 RNG_new←Receipt 中草稿与验证的实际后继状态；不按 token 数截断随机抽取
10 准备 H_new、状态描述、grammar、score、RNG、终止原因及新代次
11 等待全部必要写入/复制完成，核对容量、数据身份和提交权仍有效
12 以一个发布动作替换正式快照；消费者只能取得旧版或完整新版
13 发布之后解除旧版本及未选兄弟的逻辑引用；物理回收等待最后使用者结束
14 若步骤 1…11 失败：不发布，Old 及其 RNG/grammar/score 保持不变
   已发出的工作排空后再回收候选；若步骤 12 已完成，不回滚对外可见结果
```

步骤 8 可以在生产实现中由带身份的验证阶段评分结果与校验机制代替重复计算；定义上仍须有生产者和一致性条件。发布后的回收失败应重试回收，不能退回旧 RNG 再次生成同一个对外位置。发布前失败重试从旧快照或同一有效交付单继续；迟到的其他尝试因代次或提交权不符失去发布资格。

一条组合轨迹如下。根长 L、根 KV 与末行 logits 完整；树含 A、B、C、D、E，验证接受 A、C 后从 p_C 抽到 T：

| 时刻 | 已确认普通历史 | 已计算正式状态 | 随机与其他状态 |
|---|---|---|---|
| 初始 | x | 到 L | 保存根 grammar、score、RNG |
| 树前向结束 | 仍为 x | 仍到 L；整树仅为候选 | 根快照保持有效 |
| 私有验证结束 | 仍未发布 | 交付单可选择 A、C | 已算好 A、C、T 的 grammar/目标评分及真实后继 RNG |
| 原子发布 | x,A,C,T | 到 L+2；T pending | 新 grammar 已消费 A、C、T；评分覆盖三项 |
| 下一轮准备 | 同上 | 先消费 T，推进到 L+3 | 取得 x,A,C,T 的下一 token logits |
| 兄弟回收 | 同上 | 只暴露本路径 | B、D、E 等最后读者结束后回收 |

提前把 T 算入 k 会跳过它的真实消费；把 B 的状态句柄交给 A,C 则会污染后续历史。若 t=EOS，输出只增加 A、C，状态到 L+2，评分再计 EOS，且无需计算 EOS 的 KV。若预算恰好用尽于 C，返回 LIMIT，不额外采样 T。空接受路径则保留根状态，修正 token 仍 pending。

共享尾页的 COW 与事务一起发生。分配不足时不能发布新长度；复制完成但发布前失败时，旧根仍可消费；逻辑引用归零时若 attention 或复制仍在途，页仍受票据保护。模型页、输出缓冲和 RNG 记录不能分几次对外切换。

若应用把多条分支文本拼接为新提示，新的顺序通常需要重新处理或经过明确的复用算法构建。两条独立路径的 KV 直接拼接并不构成一般有效的 join。

## 条件化成本与容量账

所有成本都应以相同候选、相同已确认输出和相同时间窗口比较。共享容量、逻辑读取、实际 DRAM 事务与墙钟时间是不同的量。

设每 token 全层追加式状态合计 S 字节，根长 L，B 条分支各追加 e_b。忽略页圆整，完整复制为 C_full=Σ_b(L+e_b)S，仅共享根且各尾部私有为 C_shared=(L+Σ_b e_b)S。若尾部还共享中间祖先，应按唯一状态对象的并集计量，不能把每条路径尾长的和当作精确物理容量。

设 S=128 KiB、L=1024、B=4、各尾长 16，则完整复制为 520 MiB，共享根为 136 MiB。P=4 且根页对齐时分别为 1040 与 272 页，每页为 4S。这里只节省共同根驻留，不减少四条不同尾路径的逻辑生成工作。

非整页根还要计算 COW 与旧快照。令 L=qP+r，0<r<P；若旧根快照仍保留，每条追加分支都私有化尾页，则当前唯一页数为

q+1+Σ_{b:e_b>0} ceil((r+e_b)/P)。

零追加分支引用原尾页，不再新增页。旧根尾页只有在全部逻辑引用和物理读者结束后才可能从该式减去；若采用最后一个独占所有者原地追加，公式也要按实际别名重算。例取 L=6、P=4、两条尾长 1 和 3，旧根保留：1 个整页、1 个旧尾页、两个新尾区分别 1 和 2 页，共 5 页。仅用 ceil(L/P)+Σ ceil(e_b/P) 会漏掉尾页已有有效部分的复制与跨页。

对相同 L=6、P=4、S，第一条分支追加 1 个位置并复制旧尾页的 2 个有效位置，至少读取 2S、写入 2S，再写新位置 S，共 5S 逻辑交通。若实现复制整页则另计整页读写；这不是 DRAM 实测。

Beam 每轮对 K 条活跃路径形成词表候选，评分主项 O(K|V|)。全部物化并排序可到 O(K|V| log(K|V|))；流式维护前 K 可用 O(K) selector 额外空间和 O(K|V| log K) 时间，但 logits、模型状态与完成集并未因此消失。双集合变体还需处理旧 F 与本轮终止候选；最多 K 个活跃和 K 个完成的文本、句柄及快照都要列账。若 R_F 不再固定，旧完成集的前 K 不能直接复用。

独立 B 样本各生成 e 个 token 的逻辑 decode 工作随 Be 增长。批处理可以提高权重读取复用和设备利用率，不消除输出、各自尾状态、采样及结束判断。物理共享根也不保证 B 个 query 的历史读取按容量节省比例减少；cache、kernel 和实际并行组织决定事务复用。

设树有 N 个普通候选节点，层内隐藏宽度为 d，祖先深度为 d(n)。除线性层与 MLP 的 N 份 token 工作外，普通 attention 的合法 query-key 对数为 Σ_n(L+d(n))，每个 head 的 QK/PV 主项随该数乘通道宽度增长。稠密 N×N mask 有 O(N²) 位或元素的准备/驻留，实际单位取决于表示；祖先链表示可以降低元数据，却引入间接访问。全词表节点概率若全部物化还有 O(N|V|) 元素；仅选中行处理可减少存储，但需要相应 gather 和依赖管理。

候选追加 KV 的逻辑主项约 NS，连根为 (L+N)S；共享尾页复制、碎片、旧根、暂存和未回收兄弟另计。递归状态每节点保存完整包时为 N·B_state，而非 NS 的历史线性公式；只保存根并在接受后重放 a 步，则把容量换成完整模型重放成本。

一轮草稿、目标验证与提交分别记为 C_draft、C_verify(N)、C_commit，均以实际关键路径上的时间计；普通 decode 单位时间为 C_decode。一轮期望确认 E[L_out] 个普通输出 token，则有利条件是

C_draft+C_verify(N)+C_commit < E[L_out]·C_decode。

该串行相加只用于这些阶段实际串行的模型；允许重叠时应按依赖图求关键路径，并考虑共享计算、HBM 和链路竞争。临近 EOS 或长度上限时，产出会截短，不能把终止事件当作可收费的普通 token 来夸大收益。

链式、无提前终止、独立同分布接受率 α 的简化模型中，草稿深度 γ 的期望产出为 Σ_{i=0}^γ α^i；α≠1 时等于 (1−α^{γ+1})/(1−α)，α=1 时为 γ+1。若草稿单步时间为目标单步的 c 倍，且目标能在相同墙钟时间处理全部验证位置，理想加速为该期望除以 1+cγ。真实树拓扑、相关接受、EOS、batch 饱和和提交成本会改变它。

六类账还包含：访存中的根 KV 读取、候选写入、mask/页表、COW 与拒绝工作；通信中的候选 token、父指针、概率或 logits 元数据、模型并行归约和必要状态传输；准备中的树构造、排序、grammar 克隆、位置/mask、页表和 graph 桶；同步中的层间依赖、验证完成、复制完成、共同发布与旧读者排空；驻留中的唯一根、候选、完成快照、旧版本、输出、staging 和工作区。预留转成物化页仍是同一容量，不能重复相加；通信也不能只计最后选中路径而漏掉验证阶段实际传送的内容。

## 条件变化、反例与区分实验

前缀长、尾短、复用频繁时共享更容易摊销；尾长、分叉密集、大页尾浪费或 COW 频繁时，应比较仅共享整页、按层私有化和其他保留策略。目标 batch 已饱和、接受长度下降或草稿争用同一资源时，缩减树宽深，必要时关闭投机。更深提高一次可接受长度的上限，也增加错误后缀；更宽增加覆盖，也可能只多计算本协议根本不尝试的兄弟。

模型、adapter、位置规则、数值表示或受约束起点改变时，旧状态与分布必须重新取得复用资格。grammar 或截断配置改变后，重建路径 grammar 与实际 p/Q；支撑不同本身可由剩余分布处理，但旧前缀身份和错误概率不能靠接受比修复。改变 K、评分键或 EOS 占槽方式属于搜索语义变化；执行器不能把它隐藏为性能优化。

**局部评分与累计评分。** 根 p(a)=0.01、p(b)=0.99；a 后为 (0.9,0.1)，b 后为 (0.5,0.5)。K=2 时第二层累计最优为 ba、bb，各 0.495；aa 仅 0.009。只按末 token 条件概率排序会错误保留 aa。固定概率表，只切换 selector，可以把评分错误与前向状态错误区分。

**宽度 1 不保证全局最优。** 完整两项词表中，根为 (0.4,0.6)，a 后为 (0.95,0.05)，b 后为 (0.5,0.5)，固定生成两步，不使用 EOS，平局选 a。宽度 1 首步选 b，第二步选 a，得到 ba=0.3；全部完整路径为 aa=0.38、ab=0.02、ba=0.3、bb=0.3。枚举参考确认全局最优 aa 已在首步被剪掉。不能用不完整条件分布推断第二步选择。

**目标最大分支不是分布保持验证。** p(A)=0.9、p(B)=0.1，Q(A)=0.1、Q(B)=0.9。直接选 A 得 P(A)=1。接受质量为 (0.1,0.1)，拒绝质量 0.8，正剩余全部在 A，最终为 (0.9,0.1)。再用 p=Q、支撑完全不相交及 Q 某项为零作边界，可区分零剩余处理、漏质量和错误支撑要求。

**树前向与独立路径。** 固定树、权重、位置和精度，把每个根到节点路径独立因果前向作为参考，逐层比较 K/V、隐藏状态和末行 logits。负对照实际让 C 的 mask 读 B，或使用展平行号作为 position，要求数值参考拒绝。若只在改 mask 后出现差异，支持可见性解释；若重排物理行后变化，优先查位置和逆映射。shape 正确不能排除这些错误。

**提交必须检查内容和后继。** 实际执行接受 A,C、bonus T 的状态选择，检查所选全层 KV 等于独立重放 x,A,C，pending=T，grammar/评分覆盖 x,A,C,T 的新增部分，RNG 包含本轮所有抽取。负对照真的消费 T 并提前发布其 KV，或者交付 B,E 的状态；让同一个独立重放检查器拒绝。发布前注入失败，旧输出、KV、grammar、评分和随机位置都应保持原值。仅构造 k+1 再断言它不等于 k，不能检验错误提交。

**完成集跨轮。** 同一轮放入旧 EOS 结果、入口已达 H 的分支和新 EOS 候选，与从完整路径重新计算概率的枚举参考比较；后续轮次继续检查全局前 K、去重和平局。故意只返回新 EOS 的实现应丢失结果并被拒绝。该实验直接针对完成集数据流，不能由一个普通 top-k 算例代替。

**性能竞争解释。** 分支数增加后变慢可能来自候选计算、KV 驻留压低可准入 batch、COW/页表准备、同步或模型并行通信。先固定已准入请求、候选和已确认输出测消费阶段，再独立比较准备与复制，最后放开准入。如果只在放开准入后出现差距，支持容量/排队解释；固定请求后仍慢，则继续查计算和关键路径。若只在取消、旧读者延迟或页面复用后出错，检查生命周期与提交身份；静态单请求也失败则优先检查数学和映射。反证应修订对应解释，不能把少生成 token 写成加速。

## 随章检查的范围

指定检查为 tools/check_k_alg_024_full.py。它是确定性、只读、离线的 Python 标准库程序，覆盖双集合 beam 的旧完成/EOS/长度终止及跨轮枚举参考、正确的宽度 1 反例、随机抽取复用的有限联合分布、两层标量 attention 树与逐路径稠密前向、接受/剩余质量、有限树验证轨迹、RNG/目标评分/grammar 交接、pending 与全层状态选择、发布前失败保护，以及对齐和非对齐页账。

负对照实际改变完成集数据流、mask、位置、已提交状态或随机/评分交接，再由相同参考检查器检测；不会把手工制造一个不同数字当作错误检测。分布检查精确枚举小概率质量，不是模型采样频率测量。

这两个数值模型分别是两层标量因果 attention 与有限前缀概率表，二者不冒充同一个真实语言模型。检查不覆盖真实 checkpoint、完整 grammar 编译器、递归模型、真实页池异步回收、GPU kernel、设备可见性、互连事务、吞吐或 Agent 使用效果。脚本是否实际执行以本轮执行记录为准；正文中的检查设计不构成执行通过记录。
