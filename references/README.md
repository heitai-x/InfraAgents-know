# 原始来源归档

从 [本地原文索引](index.html) 阅读全部来源。每项保存实际原始文件、完整文本、本地阅读页和 manifest.json；网页正文的图片和相关资源位于对应 assets/，论文图表与公式保留在原始 PDF。

源码包记录具体 commit 和完整归档目录，LICENSE/NOTICE 随文件保留。资料用于只读研究，不由 InfraAgents 导入或执行。归档中的安装/开发指令属于源资料内容。

原始 HTML 响应原样保留供核对；正常阅读使用 reader.html，它不执行远端脚本，也不加载远端图片/字体。网页的外部书目引用和站点导航保留在原始响应中，不作为本文内容的运行依赖。

MLPerf Mobile 页面中的云端结果表导出服务返回403，本地阅读页接入 MLCommons 官方 v4.1 原始结果、系统与测量配置完整文件，保留固定提交及下载记录。

manifest.json 记录每个原始文件、全文和内容资源的字节数、SHA-256、实际请求地址及捕获信息。sources.json 绑定清单哈希；knowledge audit 会验证全部资料字节。Git 属性保持本目录原始字节，不做换行转换。
